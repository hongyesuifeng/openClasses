# 平台抽象层

平台抽象层（PAL）是 Cocos Creator 实现跨平台运行的关键基础设施，它将平台相关的功能（音频、输入、屏幕适配等）抽象为统一接口，使上层代码无需关心具体平台差异。

## 目录

- [01-PAL 架构](./01-pal-architecture.md) - 平台抽象层设计与核心模块
- [02-JSB 原生绑定](./02-jsb-binding.md) - JSB 桥接机制与原生 C++ 层

## 核心概念

### PAL 架构

```
┌─────────────────────────────────────────────────────────┐
│                 TypeScript 游戏代码层                     │
├─────────────────────────────────────────────────────────┤
│                   cocos/ 引擎模块                        │
├─────────────────────────────────────────────────────────┤
│                    PAL 抽象层                            │
│                                                         │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │  Audio   │ │  Input   │ │  Screen  │ │ System   │  │
│  │  音频     │ │  输入     │ │  屏幕    │ │ Info     │  │
│  └────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘  │
│       │            │            │             │         │
│  ┌────┴────┐  ┌────┴────┐  ┌───┴────┐  ┌────┴────┐   │
│  │Web/Native│  │Web/Native│  │Web/    │  │Web/Native│   │
│  │/Minigame│  │/Minigame │  │Native  │  │/Minigame│   │
│  └─────────┘  └─────────┘  └────────┘  └─────────┘   │
├─────────────────────────────────────────────────────────┤
│                平台运行时环境                             │
│  Browser · iOS · Android · Windows · macOS · 小游戏    │
└─────────────────────────────────────────────────────────┘
```

### JSB 桥接架构

```
┌───────────────────────┐
│   TypeScript 层       │
│   (cocos/ 引擎代码)    │
├───────────────────────┤
│   JSB 绑定层           │
│   (自动生成的桥接代码)  │
├───────────────────────┤
│   C++ 原生层           │
│   (native/ 引擎代码)   │
├───────────────────────┤
│   平台 SDK             │
│   (OpenGL/Metal/D3D)  │
└───────────────────────┘
```

## 核心文件

| 文件 | 路径 | 说明 |
|------|------|------|
| PAL 根目录 | `pal/` | 平台抽象层 |
| PAL 音频 | `pal/audio/` | 音频 PAL |
| PAL 输入 | `pal/input/` | 输入 PAL |
| PAL 屏幕适配 | `pal/screen-adapter/` | 屏幕 PAL |
| PAL 系统信息 | `pal/system-info/` | 系统 PAL |
| 平台核心 | `cocos/core/platform/` | 平台 API |
| 原生层 | `native/` | C++ 原生实现 |
| 系统信息 | `cocos/core/platform/sys.ts` | sys 全局对象 |
| 屏幕管理 | `cocos/core/platform/screen.ts` | screen 管理 |
| 调试 | `cocos/core/platform/debug.ts` | 日志系统 |
