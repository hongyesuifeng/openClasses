# 资源管理

资源管理系统负责游戏中所有资源（纹理、材质、预制体、场景等）的加载、缓存、释放和依赖管理。它是游戏运行效率的关键基础设施。

## 目录

- [01-AssetManager 核心](./01-asset-manager.md) - 资源管理器设计与加载接口
- [02-Bundle 资源包](./02-bundle-system.md) - 资源包系统与多包管理
- [03-加载流水线](./03-loading-pipeline.md) - 加载流程、工厂模式与释放管理
- [04-资源类型系统](./04-asset-types.md) - Asset 基类与各类资源

## 核心概念

### 资源管理架构

```
┌─────────────────────────────────────────────────────────┐
│                    资源管理架构                           │
│                                                         │
│  ┌──────────────────────────────────────────────────┐   │
│  │          AssetManager (全局单例)                   │   │
│  │                                                  │   │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐       │   │
│  │  │ Bundle 0 │  │ Bundle 1 │  │ Bundle N │       │   │
│  │  │(resources)│  │(远程包)  │  │(动态加载) │       │   │
│  │  └──────────┘  └──────────┘  └──────────┘       │   │
│  │                                                  │   │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐       │   │
│  │  │ Factory  │  │ Pipeline │  │ Release  │       │   │
│  │  │ 资源工厂  │  │ 加载管线 │  │ 释放管理 │       │   │
│  │  └──────────┘  └──────────┘  └──────────┘       │   │
│  └──────────────────────────────────────────────────┘   │
│                                                         │
│  ┌──────────────────────────────────────────────────┐   │
│  │               资源缓存系统                         │   │
│  │  UUID → Asset 实例 (全局唯一)                      │   │
│  └──────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 加载流程

```
用户请求加载
    │
    ▼
AssetManager.loadAny()
    │
    ├── 解析路径 → UUID
    │
    ├── 查询缓存 (命中则直接返回)
    │
    ├── 未命中 → 创建 Task
    │   │
    │   ▼
    │   Pipeline 执行
    │   ├── 下载阶段 (download)
    │   │   └── 从 Bundle/网络/本地获取原始数据
    │   │
    │   ├── 解析阶段 (parse)
    │   │   └── 将原始数据解析为中间格式
    │   │
    │   └── 创建阶段 (factory)
    │       └── 根据类型创建 Asset 实例
    │
    └── 缓存并返回 Asset
```
