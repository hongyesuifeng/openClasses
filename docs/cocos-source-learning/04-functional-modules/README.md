# 功能模块

功能模块在渲染系统之上提供了动画、物理、音频、输入、粒子等游戏核心功能。这些模块基于引擎的组件系统（Component）设计，每个模块都可通过挂载组件到节点上来使用。

## 目录

- [01-动画系统](./01-animation-system.md) - 动画剪辑、骨骼动画、补间动画
- [02-物理系统](./02-physics-system.md) - 刚体、碰撞器、物理引擎后端
- [03-音频系统](./03-audio-system.md) - 音频播放与管理
- [04-输入系统](./04-input-system.md) - 键盘、鼠标、触摸输入
- [05-粒子系统](./05-particle-system.md) - 粒子发射与渲染

### 组件化设计

所有功能模块都遵循 Cocos 的组件化模式：

```
Node
 ├── Animation (动画组件)
 ├── RigidBody (物理刚体)
 ├── BoxCollider (碰撞器)
 ├── AudioSource (音频源)
 └── ParticleSystem (粒子系统)
```

## 核心文件

| 文件 | 路径 | 说明 |
|------|------|------|
| 动画剪辑 | `cocos/animation/animation-clip.ts` | 动画数据 |
| 动画状态 | `cocos/animation/animation-state.ts` | 播放状态 |
| 动画管理器 | `cocos/animation/animation-manager.ts` | 全局管理 |
| 补间动画 | `cocos/tween/tween.ts` | Tween 动画 |
| 物理框架 | `cocos/physics/framework/` | 物理抽象接口 |
| 物理规格 | `cocos/physics/spec/` | 物理接口定义 |
| 音频源 | `cocos/audio/audio-source.ts` | 音频播放 |
| 输入管理 | `cocos/input/input.ts` | 输入系统 |
| 粒子系统 | `cocos/particle/particle-system.ts` | 粒子管理 |

4. 理解输入系统的事件处理机制
5. 理解粒子系统的模块化设计
