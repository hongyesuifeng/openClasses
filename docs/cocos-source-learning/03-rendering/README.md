渲染系统是 Cocos Creator 引擎最复杂的部分，负责将场景中的可视对象绘制到屏幕上。

## 核心概念

### 渲染架构

```
┌─────────────────────────────────────────────────────────┐
│                    渲染架构分层                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │          渲染场景 (Render Scene)                 │   │
│  │   Camera / Model / Light / Skybox               │   │
│  └──────────────────────┬──────────────────────────┘   │
│                         │                              │
│                         ▼                              │
│  ┌─────────────────────────────────────────────────┐   │
│  │          渲染管线 (Render Pipeline)              │   │
│  │   Forward / Deferred / Custom                   │   │
│  └──────────────────────┬──────────────────────────┘   │
│                         │                              │
│                         ▼                              │
│  ┌─────────────────────────────────────────────────┐   │
│  │          GFX 抽象层                              │   │
│  │   Device / Buffer / Texture / Shader            │   │
│  └──────────────────────┬──────────────────────────┘   │
│                         │                              │
│         ┌───────────────┼───────────────┐              │
│         │               │               │              │
│         ▼               ▼               ▼              │
│  ┌───────────┐   ┌───────────┐   ┌───────────┐        │
│  │  WebGL    │   │  WebGL2   │   │  WebGPU   │        │
│  └───────────┘   └───────────┘   └───────────┘        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 渲染流程

```
每帧渲染流程：

Director.tick()
    │
    ▼
Root.frameMove(dt)
    │
    ├──► 更新场景数据
    │    - 更新变换矩阵
    │    - 视锥剔除
    │    - 距离剔除
    │
    ▼
Pipeline.render(camera)
    │
    ├──► Shadow Pass     ─── 阴影贴图
    ├──► GBuffer Pass    ─── 几何缓冲（延迟渲染）
    ├──► Lighting Pass   ─── 光照计算
    ├──► Opaque Pass     ─── 不透明物体
    ├──► Transparent Pass─── 透明物体
    └──► PostProcess Pass─── 后处理
    │
    ▼
Device.present()  ─── 提交到屏幕
```
