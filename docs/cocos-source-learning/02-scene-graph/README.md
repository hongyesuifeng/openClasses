场景图系统是 Cocos Creator 的核心架构，采用组件化设计，实现了节点-组件模型。

## 核心概念

### 组件化架构

```
┌─────────────────────────────────────────────────────────┐
│                      Node (容器)                         │
│  - 层级关系 (parent/children)                           │
│  - 空间变换 (position/rotation/scale)                   │
│  - 生命周期管理                                          │
│                                                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐     │
│  │ Component 1 │  │ Component 2 │  │ Component 3 │     │
│  │ (Sprite)    │  │ (Animation) │  │ (Script)    │     │
│  └─────────────┘  └─────────────┘  └─────────────┘     │
└─────────────────────────────────────────────────────────┘
```

### 设计原则

1. **组合优于继承**：功能通过组件添加，而非继承
2. **单一职责**：每个组件只负责一个功能
3. **松耦合**：组件间通过消息通信
