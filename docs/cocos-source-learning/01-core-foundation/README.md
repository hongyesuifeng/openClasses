## 核心概念

### 1. 数学库

引擎提供了完整的 2D/3D 数学库：

```
Vec2 / Vec3 / Vec4  →  向量运算
Mat3 / Mat4         →  矩阵变换
Quat                →  四元数旋转
Color               →  颜色表示
Rect / Size         →  2D 尺寸
Ray / Plane / AABB  →  几何计算
```

### 2. 事件系统

基于观察者模式的事件分发机制：

```
EventTarget ← Eventify ← CallbacksInvoker
     ↓
  所有需要事件的类
```

### 3. 内存管理

通过对象池优化内存分配：

```
Pool<T>         →  通用对象池
RecyclePool<T>  →  可回收池
CachedArray<T>  →  缓存数组
```

### 4. 调度器

管理定时任务和帧回调：

```
Scheduler
    ├── 定时器 (schedule)
    ├── 帧回调 (update)
    └── 优先级队列
```
