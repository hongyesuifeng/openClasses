## 前置知识

### 必备技能
- **TypeScript**：引擎使用 TypeScript 开发，需要熟悉 TS 语法
- **JavaScript**：理解原型链、闭包、异步编程
- **面向对象编程**：理解类、继承、多态、接口
- **游戏开发基础**：了解游戏循环、场景、组件等概念

### 推荐了解
- **图形学基础**：顶点、片元、着色器、渲染管线
- **设计模式**：组件模式、观察者模式、对象池模式
- **线性代数**：向量、矩阵、四元数

## 学习建议

### 阅读源码的技巧

1. **从入口开始**：先理解 `game.ts` 和 `director.ts`，掌握引擎启动流程
2. **跟踪调用链**：使用 IDE 的"转到定义"功能，跟踪函数调用
3. **断点调试**：在关键函数设置断点，观察运行时状态
4. **修改测试**：尝试小范围修改代码，观察行为变化
5. **写注释**：在阅读时添加自己的理解注释

### 推荐的调试配置

```json
// .vscode/launch.json
{
    "version": "0.2.0",
    "configurations": [
        {
            "type": "chrome",
            "request": "launch",
            "name": "Debug Cocos",
            "url": "http://localhost:7456",
            "webRoot": "${workspaceFolder}",
            "sourceMaps": true
        }
    ]
}
```

### 学习优先级

根据你的目标选择重点：

| 目标 | 重点章节 |
|------|----------|
| 游戏开发者 | 场景图 → 功能模块 → UI系统 → 资源管理 |
| 渲染工程师 | 核心基础 → 渲染系统 → 高级主题 |
