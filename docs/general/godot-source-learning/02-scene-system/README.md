# 场景系统

场景系统是 Godot 引擎的核心架构层，基于节点-场景树模型组织游戏世界中的所有对象。理解场景系统是深入学习引擎其他模块的基础。

## 核心概念

### 节点-场景树架构

```
┌─────────────────────────────────────────────────────────┐
│                  SceneTree (主循环)                       │
│                                                         │
│   ┌─────────────────────────────────────────────────┐   │
│   │           Viewport (根视口)                      │   │
│   │                                                 │   │
│   │   root (Window)                                 │   │
│   │   ├── CurrentScene                              │   │
│   │   │   ├── Player (Node3D)                       │   │
│   │   │   │   ├── MeshInstance3D                    │   │
│   │   │   │   └── CollisionShape3D                  │   │
│   │   │   ├── Camera3D                              │   │
│   │   │   ├── DirectionalLight3D                    │   │
│   │   │   └── WorldEnvironment                      │   │
│   │   ├── AutoLoad_A                                │   │
│   │   └── AutoLoad_B                                │   │
│   └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 设计原则

1. **树形层级**：所有游戏对象以节点形式组织在树中，父节点的变换自动影响子节点
2. **通知驱动**：节点通过 `_notification()` 系统接收生命周期事件，而非虚函数重写
3. **延迟执行**：通过 `MessageQueue` 实现延迟调用，避免在遍历过程中修改树结构
4. **Server 分离**：场景层负责组织逻辑，底层渲染/物理/音频由对应 Server 处理

## 核心源文件

| 文件 | 路径 | 说明 |
|------|------|------|
| 节点基类 | `scene/main/node.h` / `node.cpp` | 引擎最核心的类 |
| 场景树 | `scene/main/scene_tree.h` / `scene_tree.cpp` | 继承 MainLoop，管理节点树 |
| 视口 | `scene/main/viewport.h` / `viewport.cpp` | 渲染目标与输入路由 |
| 主循环 | `main/main_loop.cpp` | MainLoop 接口实现 |
| 打包场景 | `scene/resources/packed_scene.h` | 场景序列化与反序列化 |
| 窗口 | `scene/main/window.h` | Window 类，Viewport 的子类 |
| 消息队列 | `core/object/message_queue.h` | 延迟调用机制 |

## 学习目标

完成本章节后，你将能够：

1. 理解 Godot 场景树的数据结构设计和遍历机制
2. 掌握 Node 类的完整生命周期与通知系统
3. 深入理解主循环的帧处理流程（物理步、渲染步、消息队列）
4. 了解视口系统的渲染目标与输入事件路由
5. 掌握场景序列化格式（.tscn）与实例化过程
