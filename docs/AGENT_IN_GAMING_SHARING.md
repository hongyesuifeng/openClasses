# AI Agent 初探实践心得

一直在听各种 Agent 的概念，想要深入学习了解下，搭建了这个游戏小镇 demo，分享下，也作为后续在业务探索落地中的前置了解。

## 游戏小镇是什么？

一个模拟游戏开发团队协作的 Multi-Agent 系统，4 个 AI Agent 扮演不同角色，围绕游戏开发任务进行讨论决策。

```
┌──────────────────────────────────────────────────────────┐
│  🎮 游戏小镇 - 《九十九亿大战》开发团队                     │
├──────────────────────────────────────────────────────────┤
│  David (制作人)  │  把控进度、协调资源、最终决策            │
│  Alex (程序员)   │  技术评估、方案实现、性能优化            │
│  Emma (策划)     │  玩法设计、数值平衡、体验把控            │
│  Luna (美术)     │  视觉风格、美术资源、特效表现            │
└──────────────────────────────────────────────────────────┘
```

**关键功能：**
- 🎭 多角色扮演：每个 Agent 有独立的性格和专业领域
- 💬 实时对话：WebSocket 实现的实时消息推送
- 🧠 记忆系统：Agent 能记住之前的讨论内容

## 一些感悟

**Agent 不神秘**：核心公式就是 **Agent = LLM + 记忆 + 规划 + (工具)**。游戏小镇就是这个公式的具体落地——LLM 提供推理能力，MemoryManager 管理对话历史，Orchestrator 控制会议流程，角色通过 Prompt 工程实现专业化。

**落地有价值**：业务有价值，Agent 也有价值，能让 Agent 很好地落地在各个业务场景上是个很难也很有价值的事情！

## AI 编程工具对比测试

开发过程中，尝试了不同的 AI 编程工具 + 模型组合：

**Claude Code + GLM**：编码能力强，而且发散思维好，最后版本采用的这个组合。

**OpenCode + MiniMax 2.5**：开始还可以，后面开始修改具体逻辑细节的时候，经常写不对，中途放弃了。

**Gemini**：开始效果挺好的，而且 UI 布局也比另外几个好看很多，但是开发一阵后，感觉开始变笨了，可能是给我换模型了，开始用的 Gemini Pro。

**Codex**：第一版 UI 交互就放弃了，有点丑，估计是初始文档写的不够完善，有点严谨不怎么发散，没有继续调，估计挺贵，放弃了，还是让他干正事吧...
