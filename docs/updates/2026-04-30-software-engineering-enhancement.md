### 1. 设计模式深入指南 (design-patterns-advanced.md)

**基于资源**:
- GoF 《设计模式：可复用面向对象软件的基础》
- Refactoring.Guru 在线参考
- 《Head First 设计模式》
- 《游戏编程模式》

**核心内容**:
- **完整的 23 种设计模式**详解
  - 5 种创建型模式（单例、工厂方法、抽象工厂、建造者、原型）
  - 7 种结构型模式（适配器、桥接、组合、装饰器、外观、代理、享元）
  - 11 种行为型模式（策略、观察者、命令、模板方法、迭代器、责任链、中介者、备忘录、状态、访问者、解释器）

- **每个模式包含**:
  - UML 结构图
  - 完整代码示例
  - 适用场景分析
  - 优缺点权衡
  - 实际应用案例

- **高级主题**:
  - 设计模式组合应用
  - MVC 架构中的模式组合
  - 游戏引擎中的模式应用
  - 反模式和误用分析

**代码示例亮点**:
```python
# 抽象工厂模式完整实现
class GUIFactory(ABC):
    @abstractmethod
    def create_button(self) -> Button:
        pass

    @abstractmethod
    def create_checkbox(self) -> Checkbox:
        pass

# 责任链模式实际应用
class Handler(ABC):
    def __init__(self):
        self._next_handler = None

    def set_next(self, handler):
        self._next_handler = handler
        return handler  # 支持链式调用
```

### 2. 代码重构完整指南 (refactoring.md)

**基于资源**:
- Martin Fowler 《重构：改善既有代码的设计》
- Refactoring.Guru 重构目录
- 《重构到模式》- Joshua Kerievsky

**核心内容**:
- **代码坏味道 (Code Smells)** 详解
  - 臃肿代码（长方法、大类、长参数列表）
  - 面向对象滥用（过多 Switch）
  - 变更阻碍器（发散式变化、霰弹式修改）
  - 不必要的复杂性（重复代码）

- **核心重构技巧**
  - 提取方法（Extract Method）
  - 内联方法（Inline Method）
  - 提取类（Extract Class）
  - 移动方法（Move Method）

- **实战案例**: 订单处理系统重构
  - 重构前：混乱的单一类
  - 重构后：清晰的职责分离
  - 完整的代码对比

**重构清单**:
- 开始重构前检查项
- 重构过程中注意事项
- 重构完成后验证项

### 3. 代码审查实践指南 (code-review.md)

**基于资源**:
- Google Engineering Practices: Code Review
- Microsoft Code Review Guidelines
- 《代码整洁之道》
- 《软件工艺》

**核心内容**:
- **8 大审查维度**:
  1. 功能正确性
  2. 代码质量
  3. 错误处理
  4. 性能考虑
  5. 安全性
  6. 测试覆盖
  7. 文档和注释
  8. 代码风格

- **完整的审查流程**:
  - 审查前准备（审查者和提交者）
  - PR 描述模板
  - 三步审查过程
  - 反馈分类（必须修复、建议修改、可选改进）

- **最佳实践**:
  - 审查者原则（保持友善、解释原因）
  - 提交者原则（开放心态、响应及时）
  - 团队实践（定期同步、建立规范）

- **代码审查指标**:
  - 审查速度（目标：24小时内）
  - PR 大小（目标：< 400行）
  - 审查覆盖率（目标：100%）

**实战案例**:
- 发现潜在 Bug（并发问题）
- 性能优化建议（数据库查询优化）
- 安全漏洞发现（密码重置流程）

### 4. 软件架构设计指南 (software-architecture.md)

**基于资源**:
- 《软件架构模式》- Mark Richards & Neal Ford
- 《架构整洁之道》- Robert C. Martin
- 《企业应用架构模式》- Martin Fowler
- 《领域驱动设计精粹》- Vaughn Vernon

**核心内容**:
- **经典架构模式**:
  - 分层架构（Layered Architecture）
  - 六边形架构（Hexagonal Architecture）
  - 微服务架构（Microservices Architecture）

- **架构设计原则**:
  - SOLID 原则在架构中的应用
  - CAP 定理和权衡
  - DRY、KISS、YAGNI 原则

- **架构设计方法**:
  - 领域驱动设计（DDD）
    - 战术设计（值对象、实体、聚合、仓储）
    - 战略设计（核心域、支撑域、通用域）
  - 事件驱动架构（EDA）
  - CQRS（命令查询职责分离）

- **架构评估方法**:
  - ATAM（架构权衡分析方法）
  - 架构 Fitness 检查清单

**实战案例**:
- 电商系统架构设计
  - 微服务架构选择
  - 服务划分原则
  - 具体服务实现
