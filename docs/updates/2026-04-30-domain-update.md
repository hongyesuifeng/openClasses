**初学者路径**:
```
软件工程基础 → 提示工程基础 → AI Agent → 游戏引擎
```

**进阶者路径**:
```
提示工程高级技术 → AI辅助开发 → AI Agent项目 → 游戏AI应用
```

**专项深化路径**:
```
提示工程专项 → 游戏开发提示 → 游戏引擎 → 游戏+AI跨领域
```

### 时间投入建议

**并行学习** (推荐):
- 提示工程 + 软件工程同时进行
- 每周各投入3-4小时
- 互相促进，效率更高

**串行学习**:
- 先完成软件工程基础
- 再学习提示工程
- 最后结合AI应用

1. **学练结合**
