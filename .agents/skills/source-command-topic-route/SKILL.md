# source-command-topic-route

Use this skill when the user asks to run the migrated source command `topic-route`.

## Command Template

# 主题学习路线推荐命令

根据用户提供的主题，智能推荐学习路线、经典学习资料和实践项目。

## 使用方法

在对话中说：`/topic-route <主题名称>`

## 示例

- `/topic-route 游戏引擎` - 获取游戏引擎学习路线
- `/topic-route AI Agent` - 获取AI Agent学习路线
- `/topic-route 提示工程` - 获取提示工程学习路线
- `/topic-route Cocos引擎` - 获取Cocos引擎专门路线

## 执行流程

### 1. 主题分析
- 识别主题关键词
- 确定主题所属领域（AI/游戏开发/编程等）
- 分析主题与现有知识的关联

### 2. 用户画像匹配
- 读取 `user-profile/learning-profile.md`
- 读取 `user-profile/skill-matrix.json`
- 分析用户当前技能水平和学习历史
- 识别相关的前置知识

### 3. 知识库搜索
搜索项目中的相关资源：
- `courses/` - 课程目录
- `docs/` - 综合指南文档
- `papers/` - 论文和研究
- `learning-routes/topic-index/` - 已有的主题路线

### 5. 个性化调整

根据用户的学习偏好和时间安排：

#### 学习风格适配
- **实践学习者**: 增加项目和实践练习
- **理论学习者**: 增加深入阅读和原理讲解
- **视觉学习者**: 增加图表和可视化资源

#### 时间安排适配
- **时间充裕(>15h/周)**: 增加深度项目和探索性内容
- **时间中等(8-15h/周)**: 平衡理论和实践
- **时间紧张(<8h/周)**: 聚焦核心概念和必要实践

#### 技能水平适配
- **初学者**: 增加基础概念讲解和练习
- **中级**: 增加进阶内容和项目挑战
- **高级**: 推荐深度研究和创新项目

## 输出和保存

1. **显示**: 在对话中展示生成的学习路线
2. **保存**: 将路线保存到 `learning-routes/topic-index/{topic-slug}.md`
3. **更新**: 更新用户的学习历史和兴趣记录

## 注意事项

- 确保推荐的资源在项目中存在或可访问
- 考虑用户的学习历史，避免重复推荐已完成的内容
- 保持路线的灵活性，允许用户根据实际情况调整
- 提供多个难度等级的选择
- 优先推荐项目中有完整文档的资源
- 考虑跨领域学习机会，特别是AI+游戏的结合点

## 相关技能

此命令会调用以下技能：
- `learning-path-generator` - 学习路径生成技能
- `topic-recommender` - 主题推荐技能
- `progress-analyzer` - 进度分析技能
