# 学习优化技能

> 基于 DeepTutor 提炼的学习优化技能，帮助高效学习和知识管理

## 技能描述

这个技能提供了一系列学习优化方法和工具，帮助你：
- 应用 Agent-Native 学习法
- 管理统一的学习上下文
- 选择合适的学习模式
- 建立持久化记忆系统
- 优化学习工作流

## 核心能力

### 1. 学习会话管理

**初始化学习会话**：
```
创建一个结构化的学习会话，包含：
- 上下文管理（统一的知识库引用）
- 记忆系统（学习摘要和画像更新）
- 工具选择（根据学习目标）
- 进度追踪（里程碑和检查点）
```

### 2. 学习模式推荐

根据学习目标推荐最合适的学习模式：

| 学习目标 | 推荐模式 | 工具组合 |
|---------|---------|----------|
| 理解新概念 | Chat | RAG + Web Search |
| 解决复杂问题 | Deep Solve | Reason + Plan + Verify |
| 检验知识掌握 | Quiz Generation | RAG + Validation |
| 深度研究主题 | Deep Research | Multi-agent + Citations |
| 可视化理解 | Math Animator | Manim + Code |

### 3. Agent 创建辅助

**为学习主题创建专用 Agent**：
```
分析学习主题的特点，推荐：
- Agent 的 Soul（个性和教学风格）
- 需要的能力（deep_solve, quiz_generation 等）
- 必需的工具（rag, web_search, code_execution 等）
- 记忆配置（短期/长期记忆）
```

### 4. 知识连接分析

**建立知识网络**：
- 识别新知识与现有知识的连接点
- 跨领域知识关联
- 理论与实践的桥梁
- 知识缺口识别

### 5. 学习迭代规划

**四层迭代学习法**：
1. **第一遍**：理解基本概念和术语
2. **第二遍**：理解原理、联系和设计思想
3. **第三遍**：深入细节、实现和边界情况
4. **第四遍**：创新应用和教学输出

## 使用方法

### 优化当前学习

```
输入：描述你当前的学习内容和困惑

输出：
1. 分析当前学习状态
2. 推荐最适合的学习模式
3. 设计学习策略
4. 规划迭代步骤
5. 设置检查点
```

### 创建主题 Agent

```
输入：学习主题名称

输出：
1. Agent 配置建议（Soul、能力、工具）
2. 学习路线建议
3. 资源推荐
4. 实践项目建议
```

### 学习会话总结

```
输入：学习内容和过程描述

输出：
1. 学习摘要（Summary）
2. 画像更新建议（Profile）
3. 知识连接分析
4. 下一步学习建议
```

## 优化原则应用

### Agent-Native 学习
为每个重要主题创建专用 Agent，让 Agent 拥有独立记忆和上下文。

### 统一上下文管理
所有学习活动共享统一上下文，避免信息孤岛。使用会话持久化保持学习连续性。

### 多模式切换
根据学习进展灵活切换模式：
- Chat → Deep Solve → Quiz Generation → Deep Research

### 持久化记忆
维护两个维度的记忆：
- **Summary**：学习内容摘要
- **Profile**：学习偏好和风格

### 工具解耦
工具独立于工作流，根据需要自由组合。

## 实践建议

### 每日学习
- 使用 Chat 模式快速了解概念
- 用 Deep Solve 解决疑难问题
- 更新学习摘要

- 更新学习画像

### 项目驱动
- 使用 Deep Research 深入探索
