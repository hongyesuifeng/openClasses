# Learning Path Generator

> 智能学习路径生成技能，基于用户画像和项目资源生成个性化学习计划

## 使用场景

当用户询问以下问题时使用此技能：
- "如何学习{主题}？"
- "给我制定{主题}的学习计划"
- "{主题}的学习路线是什么？"
- "我想学习{主题}，从哪里开始？"

## 工作流程

### 1. 用户画像分析

读取并分析以下文件：
- `user-profile/learning-profile.md` - 学习档案
- `user-profile/skill-matrix.json` - 技能矩阵
- `user-profile/learning-preferences.json` - 学习偏好

提取关键信息：
- 当前技能水平和已完成课程
- 学习风格偏好（实践/理论/视觉）
- 可用学习时间
- 兴趣领域和目标

### 2. 知识库查询

搜索项目中的相关资源：

```bash
# 课程目录
courses/

# 综合指南文档
docs/*.md

# 论文和研究
papers/

# 已有的学习路线
learning-routes/topic-index/

# 模板系统
templates/
```

### 3. 主题分析算法

```
输入：主题名称 + 用户画像 + 可用资源

处理步骤：
1. 关键词提取和匹配
2. 领域分类（AI/游戏/编程/工具）
3. 难度评估
4. 前置知识识别
5. 资源相关性评分
6. 学习路径拓扑排序

输出：个性化学习路径
```

### 4. 路径生成规则

#### 难度递进原则

```
Level 1 (初学者) → Level 2 (基础) → Level 3 (中级) → Level 4 (高级) → Level 5 (专家)
```

每个阶段应该：
- 建立在上一阶段基础上
- 有明确的检查点
- 包含理论和实践结合
- 提供足够的挑战但不至于过度困难

#### 资源优先级

1. **项目内资源**（优先使用）
   - 综合指南文档（11章格式）
   - 已完成课程的笔记
   - 实践项目文档

2. **外部经典资源**（补充推荐）
   - 官方文档
   - 经典课程
   - 开源项目
   - 技术书籍

#### 学习风格适配

| 学习风格 | 内容比例 | 推荐资源类型 |
|----------|----------|--------------|
| 实践型 | 70%实践 + 30%理论 | 项目、练习、动手实验 |
| 理论型 | 40%实践 + 60%理论 | 文档、论文、深度讲解 |
| 视觉型 | 50%实践 + 50%理论 | 视频、图表、可视化内容 |
| 混合型 | 50%实践 + 50%理论 | 均衡混合各种资源 |

## 资源匹配规则

### 1. 课程匹配

```python
# 伪代码：课程匹配算法
def match_courses(topic, user_level, user_interests):
    matches = []

    for course in all_courses:
        # 关键词匹配
        keyword_score = calculate_keyword_match(topic, course.keywords)

        # 难度匹配
        level_score = calculate_level_match(user_level, course.difficulty)

        # 兴趣匹配
        interest_score = calculate_interest_match(user_interests, course.tags)

        # 综合评分
        total_score = (keyword_score * 0.4 +
                      level_score * 0.4 +
                      interest_score * 0.2)

        if total_score > threshold:
            matches.append((course, total_score))

    return sorted(matches, key=lambda x: x[1], reverse=True)
```

### 2. 技能差距分析

```python
# 分析用户当前技能和目标主题的差距
def analyze_skill_gap(user_skills, topic_requirements):
    gaps = []

    for requirement in topic_requirements:
        user_level = user_skills.get(requirement, 0)
        required_level = topic_requirements[requirement]

        if user_level < required_level:
            gaps.append({
                "skill": requirement,
                "current": user_level,
                "required": required_level,
                "gap": required_level - user_level
            })

    return sorted(gaps, key=lambda x: x["gap"], reverse=True)
```

### 3. 学习时间估算

```python
# 基于历史数据估算学习时间
def estimate_learning_time(topic, user_level, learning_velocity):
    base_time = get_base_time(topic)  # 基础时间
    difficulty_modifier = get_difficulty_modifier(topic, user_level)
    velocity_modifier = get_velocity_modifier(learning_velocity)

    estimated_time = base_time * difficulty_modifier * velocity_modifier

    return estimated_time
```
