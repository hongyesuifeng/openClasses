# 学习计划命令

基于用户当前学习状态和目标，生成详细的短期、中期或长期学习计划。

## 使用方法

在对话中说：`/learning-plan [时间范围]`

## 参数

- **时间范围**: 可选
  - `short` 或 `本周` - 短期计划（1-2周）
  - `medium` 或 `本月` - 中期计划（1-2月）
  - `long` 或 `本季度` - 长期计划（3-6月）
  - 默认：中期计划

## 示例

- `/learning-plan` - 生成默认（中期）学习计划
- `/learning-plan short` - 生成本周学习计划
- `/learning-plan 本月` - 生成本月学习计划
- `/learning-plan long` - 生成本季度学习计划

## 🔄 学习策略调整

### 时间管理

**黄金时间**:
- 最高效时段: 晚上8-11点
- 安排重点: 新概念学习
- 安排难点: 需要深度思考的内容

**学习块**:
- 最佳长度: 2-3小时连续
- 休息间隔: 45分钟学习 + 10分钟休息
- 避免疲劳: 不要超过3小时不休息

**时间分配建议**:
- 难点内容: 安排在精力最好的时间
- 实践项目: 可以在相对疲劳时进行
- 复习总结: 睡前或周末

### 学习方法

**主动学习**:
- 费曼技巧: 尝试向别人解释学到的东西
- 实践优先: 学完就做，不要等
- 记录笔记: 使用11章格式整理

**复习策略**:
- 每日复习: 睡前回顾当天学习内容
- 每周总结: 周末总结本周学习
- 间隔重复: 使用间隔重复算法复习

**实践导向**:
- 学完就做: 理论后立即实践
- 项目驱动: 通过项目学习新知识
- 问题解决: 遇到问题主动解决

### 难度调整

**过难内容**:
- 降级处理: 先掌握基础再深入
- 分解步骤: 把复杂内容分解成小步骤
- 寻求帮助: 查找资料或询问社区

**过简单**:
- 加快速度: 快速过一遍基础
- 增加挑战: 尝试更复杂的应用
- 深入挖掘: 研究底层原理

**正好**:
- 保持节奏: 按计划进行
- 适度深入: 在关键点上深入研究
- 拓展应用: 尝试不同应用场景

## 注意事项

1. **现实性**: 确保计划可实现，不要过度安排
2. **灵活性**: 保持计划的可调整性
3. **缓冲时间**: 预留缓冲和休息时间
4. **平衡性**: 平衡理论和实践，工作和休息
5. **个性化**: 根据个人情况定制
6. **可测量**: 目标应该具体可测量
7. **有时限**: 设置明确的时间界限
