# 个性化学习框架使用指南

> 为你的学习之旅提供智能化、个性化的支持

## 🎯 框架概述

这个个性化学习框架是为了让学习更加有针对性和高效而设计的。它包含以下核心功能：

1. **用户学习画像** - 记录你的技能、兴趣和进度
2. **智能学习路线** - 为不同主题提供个性化学习路径
3. **学习计划生成** - 基于你的情况制定学习计划
4. **进度追踪** - 跟踪学习进度和成果
5. **学习优化系统** - 应用先进的学习方法论（基于 DeepTutor）

## 🧠 学习优化原则

本框架集成了来自 [DeepTutor](https://github.com/HKUDS/DeepTutor) 的学习优化原则：

### 核心原则

1. **Agent-Native 学习法** - 将 AI Agent 作为学习的第一公民
2. **统一上下文管理** - 所有学习活动共享统一上下文
3. **多模式学习流** - 根据目标灵活切换学习模式
4. **持久化记忆系统** - 维护学习摘要和画像
5. **工具与工作流解耦** - 自由组合学习工具

### 学习模式

| 模式 | 用途 | 适用场景 |
|------|------|----------|
| **Chat** | 自由对话、概念理解 | 学习新概念、快速问答 |
| **Deep Solve** | 复杂问题解决 | 遇到困难、需要深度分析 |
| **Quiz Generation** | 知识检验 | 验证理解程度、自我测试 |
| **Deep Research** | 深度研究 | 需要全面了解主题 |
| **Math Animator** | 可视化理解 | 数学概念、算法可视化 |

> 📖 详见：[学习优化准则](../docs/LEARNING_OPTIMIZATION_PRINCIPLES.md)

## 🚀 快速开始

### 1. 查看你的学习档案

你的学习档案位于 `user-profile/learning-profile.md`，包含：
- 基本信息（学习目标、兴趣领域）
- 当前技能水平
- 学习历史
- 学习数据统计

### 2. 获取主题学习路线

使用 `/topic-route` 命令获取个性化学习路线：

```bash
# 示例：获取AI Agent学习路线
/topic-route AI Agent

# 示例：获取游戏引擎学习路线
/topic-route 游戏引擎

# 示例：获取提示工程学习路线
/topic-route 提示工程
```

### 3. 生成学习计划

使用 `/learning-plan` 命令生成个性化学习计划：

```bash
# 生成默认（中期）学习计划
/learning-plan

# 生成本周学习计划
/learning-plan short

# 生成本月学习计划
/learning-plan medium

# 生成本季度学习计划
/learning-plan long
```

## 🎨 核心功能

### 主题学习路线

每个主题学习路线包含：

1. **学习概况** - 难度、时长、匹配度
2. **前置知识检查** - 已具备和需要补充的知识
3. **分阶段学习计划** - 详细的学习阶段
4. **实践项目** - 动手项目建议
5. **学习成果评估** - 完成后应达到的水平

### 学习计划

学习计划包含：

1. **计划概览** - 时间范围、主要目标
2. **重点内容** - 核心课程和新技能
3. **每周计划** - 详细的周计划
4. **里程碑检查点** - 阶段性目标
5. **进度追踪** - 课程和技能进度

### 用户画像

用户画像系统包含：

1. **学习档案** - 基本信息、技能水平、学习历史
2. **技能矩阵** - 量化的技能评估
3. **学习偏好** - 学习风格、时间安排
4. **进度追踪** - 学习进度和成果

## 📊 技能矩阵说明

技能矩阵使用1-5级评估：

- **1/5**: 初学者 - 刚开始学习
- **2/5**: 基础 - 理解基本概念
- **3/5**: 中级 - 能够独立应用
- **4/5**: 高级 - 深入理解和实践
- **5/5**: 专家 - 能够创新和教学

## 🎯 使用建议

### 1. 定期更新学习档案

建议每周更新一次：
- 更新完成的课程和进度
- 更新技能水平
- 记录学习心得

### 2. 使用进度追踪

为每个重要学习主题创建进度追踪文件：
```bash
cp user-profile/progress/progress-tracker-template.md \
   user-profile/progress/{topic-name}-progress.md
```

### 3. 灵活调整计划

- 根据实际情况调整学习计划
- 不要过于严格地遵守计划
- 保持学习的灵活性和乐趣

### 4. 专注于核心目标

- 选择1-2个主要学习方向
- 避免同时学习太多主题
- 深度比广度更重要

## 🧠 学习优化技能

使用 `/learning-optimizer` 技能应用学习优化原则：

### 优化当前学习
```
输入：描述你当前的学习内容和困惑

输出：
1. 分析当前学习状态
2. 推荐最适合的学习模式
3. 设计学习策略
4. 规划迭代步骤
```

### 创建主题 Agent
```
输入：学习主题名称

输出：
1. Agent 配置建议（Soul、能力、工具）
2. 学习路线建议
3. 实践项目建议
```

### 学习会话总结
```
输入：学习内容和过程描述

输出：
1. 学习摘要（Summary）
2. 画像更新建议（Profile）
3. 知识连接分析
```

## 🔧 自定义和扩展

### 学习优化检查清单

**开始学习前**：
- [ ] 明确学习目标（理解/应用/创新）
- [ ] 评估前置知识
- [ ] 选择合适的学习模式
- [ ] 准备学习资源

**学习过程中**：
- [ ] 主动提问和质疑
- [ ] 建立知识连接
- [ ] 实践验证理解
- [ ] 记录关键洞察

**学习完成后**：
- [ ] 总结学习成果
- [ ] 更新知识图谱
- [ ] 识别知识缺口
- [ ] 规划下一步

### 添加新的主题路线

1. 在 `learning-routes/topic-index/` 创建新文件
2. 参考现有路线的格式
3. 包含所有必要章节

### 创建跨领域路线

1. 在 `learning-routes/cross-domain/` 创建文件
2. 结合多个领域的知识
3. 设计综合性项目

### 调整用户画像

1. 编辑 `user-profile/learning-profile.md`
2. 更新技能和兴趣
3. 保持信息的准确性
