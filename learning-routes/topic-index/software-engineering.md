# 软件工程学习路线

> 现代软件开发技能的系统化学习路径

## 📊 学习概况

- **主题**: 软件工程 (Software Engineering)
- **推荐难度**: ⭐⭐⭐ (3/5)
- **预计时长**: 持续学习（12-16 周基础 + 持续进阶）
- **学习方式**: 理论 + 实践 + 项目
- **前置知识**: 基本编程能力

## 🎯 学习目标

完成本学习路线后，你将能够：

1. **编写高质量代码**
   - 遵循设计原则和模式
   - 编写可维护的代码
   - 应用最佳实践

2. **掌握开发工具**
   - 熟练使用 Git
   - 配置开发环境
   - 使用 AI 辅助工具

3. **实践工程方法**
   - 编写和运行测试
   - 进行代码审查
   - 实施持续集成

4. **应用 AI 辅助开发**
   - 设计有效的提示词
   - 使用 AI 工具
   - 优化开发流程

## 🗺️ 学习路线

### 阶段 1: 代码质量基础 (3-4 周)

**🎯 学习目标**:
- 理解代码质量的重要性
- 掌握设计模式和原则
- 学会编写清晰代码

**📖 核心内容**:
- [ ] SOLID 原则
- [ ] 常用设计模式
- [ ] 命名和格式规范
- [ ] 代码注释
- [ ] 错误处理

**📚 推荐资源**:
1. **[设计模式基础](../domains/software-engineering/guides/foundations/design-patterns.md)**
   - 类型: 系统教程
   - 重点: 创建型、结构型、行为型模式
   - 时间: 8-10小时

2. **[代码质量指南](../domains/software-engineering/guides/foundations/code-quality.md)**
   - 类型: 系统教程
   - 重点: 可读性、可维护性
   - 时间: 6-8小时

3. **《代码整洁之道》**
   - 类型: 书籍
   - 重点: 第1-7章
   - 时间: 10-12小时

**💡 实践项目**:
- **代码重构练习**: 重构低质量代码
  - 难度: ⭐⭐

## 📝 学习建议

### 学习策略
- **项目驱动**: 通过实际项目学习
- **代码实践**: 多写代码，多审查
- **工具使用**: 熟练开发工具
- **持续改进**: 不断优化和重构

### 时间安排
- **基础阶段**: 每周 8-10 小时
- **测试阶段**: 每周 6-8 小时
- **AI 阶段**: 每周 8-10 小时
- **项目阶段**: 每周 10-15 小时

### 常见挑战
- **代码质量低**: 多阅读优秀代码，多实践
- **测试困难**: 从小测试开始，逐步提高
- **工具不熟悉**: 专注核心工具，深度学习
- **项目复杂**: 分阶段实现，迭代改进

## 🔖 快速参考

### 核心原则速查

| 原则 | 说明 | 应用场景 |
|------|------|----------|
| SOLID | 面向对象设计原则 | 类和接口设计 |
| DRY | 不要重复自己 | 代码复用 |
| KISS | 保持简单 | 代码实现 |
| YAGNI | 你不需要它 | 需求管理 |

### 常用工具

| 类别 | 工具 | 用途 |
|------|------|------|
| 版本控制 | Git | 代码管理 |
| 编辑器 | VS Code, Cursor | 代码编写 |
| AI 工具 | Claude, Copilot | AI 辅助 |
| 测试 | pytest, Jest | 测试运行 |
| CI/CD | GitHub Actions | 自动化 |
