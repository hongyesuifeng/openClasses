# 提示工程学习路线

> 系统化掌握提示工程，从基础到高级应用

## 📊 学习概况

- **主题**: 提示工程 (Prompt Engineering)
- **推荐难度**: ⭐⭐⭐ (3/5)
- **预计时长**: 4-6 周（每周 5-8 小时）
- **学习方式**: 理论 + 实践
- **前置知识**: 基本的 AI/LLM 了解

## 🎯 学习目标

完成本学习路线后，你将能够：

1. **理解提示工程原理**
   - LLM 工作机制
   - 提示词的影响因素
   - In-Context Learning

2. **掌握基础技术**
   - 零样本/少样本提示
   - 角色设定
   - 结构化提示框架

3. **应用高级技术**
   - 思维链推理
   - RAG 提示设计
   - 工具调用提示

4. **专项应用能力**
   - 代码生成提示
   - 游戏开发提示
   - Agent 开发提示

## 📝 学习建议

### 学习策略
- **实践优先**: 每学一个概念就立即实践
- **对比实验**: 对比不同提示词的效果
- **记录总结**: 记录有效的提示词模式
- **持续优化**: 不断改进提示词设计

### 时间安排
- **基础阶段**: 每周 5-6 小时
- **高级阶段**: 每周 6-8 小时
- **应用阶段**: 每周 8-10 小时

### 常见挑战
- **效果不稳定**: 使用更具体的指令和示例
- **输出不符合预期**: 明确输出格式和约束
- **复杂任务处理困难**: 使用分治法和思维链
- **上下文限制**: 精简信息，聚焦核心需求
