# 代码生成提示模板

> 常用代码生成场景的提示词模板库

## 📋 使用说明

本模板库提供了各种代码生成场景的提示词模板。使用时：
1. 选择合适的模板
2. 填入你的具体信息（{括号内容}）
3. 根据项目需求调整
4. 测试和优化

## 1. 函数生成模板

### 基础函数模板

```markdown
# 角色
你是 {语言} 开发专家。

# 任务
请实现一个 {功能描述} 函数。

# 要求
1. 语言：{语言及版本}
2. 函数签名：{函数签名}
3. 功能：{详细功能描述}
4. 边界情况：{需要处理的情况}
5. 性能要求：{性能要求}

# 输出格式
1. 完整函数实现
2. 简要说明
3. 使用示例
4. 时间/空间复杂度
```

### 算法实现模板

```markdown
# 算法实现
请用 {语言} 实现 {算法名称} 算法。

# 功能要求
- 输入：{输入描述}
- 输出：{输出描述}
- 约束条件：{约束条件}

# 技术要求
1. 时间复杂度：{目标复杂度}
2. 空间复杂度：{目标复杂度}
3. 包含详细注释
4. 处理边界情况

# 验证
提供测试用例验证正确性。
```
