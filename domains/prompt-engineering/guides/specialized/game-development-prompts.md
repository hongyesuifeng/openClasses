# 游戏开发提示工程实战指南

> 专为游戏开发者设计的提示工程实践指南

## 📚 学习目标

完成本指南后，你将能够：
- 设计游戏开发场景的高效提示词
- 生成符合游戏引擎规范的代码
- 优化游戏性能和架构设计
- 处理游戏开发中的常见问题

## 🎯 适用场景

- Unity/Cocos Creator/Godot 等游戏引擎开发
- 游戏系统架构设计
- 游戏性能优化
- 游戏逻辑和 UI 实现

## 1. 游戏代码生成提示

### 1.1 架构优先原则

在生成具体代码前，先让 AI 帮助设计架构。

**系统架构设计模板**：
```markdown
# 角色
你是一位资深的游戏架构师，精通 {引擎名称} 和设计模式。

# 项目背景
- 游戏类型：{RPG/动作/策略等}
- 目标平台：{移动端/PC/主机}
- 团队规模：{人数}
- 性能要求：{具体要求}

# 系统需求
{系统功能描述}

# 架构要求
1. 遵循 {MVC/ECS/MVVM} 架构模式
2. 考虑代码的可维护性和可扩展性
3. 适合多人协作
4. 性能优化友好

# 输出内容
1. 系统架构图（文字描述）
2. 核心类和接口定义
3. 数据流向说明
4. 扩展点设计
```

### 1.2 MVC 架构代码生成

**背包系统示例**：
```markdown
# 角色
你是 Unity 架构专家，专精 MVC 模式设计。

# 任务
为 RPG 游戏设计一个背包系统的 MVC 架构。

# 具体需求
- Model: 使用 ScriptableObject 存储物品数据
- View: 继承自 BaseView，负责 UI 显示
- Controller: 继承自 BaseController，处理逻辑
- 使用事件系统解耦各层

# 性能要求
- 避免频繁的 GC 分配
- UI 更新优化
- 数据持久化优化

# 输出格式
请提供：
1. 完整的类定义（C#）
2. 接口定义
3. 事件定义
4. 使用示例
5. 性能注意事项
```

## 2. 性能优化提示

```markdown

# 代码
{需要优化的代码}

# 性能问题
- 帧率：{当前帧率}
- 内存：{内存使用情况}
- 平台：{目标平台}

# 分析要求
1. 识别性能瓶颈
2. 分析 GC 分配
3. 检查不必要的计算
4. 评估算法复杂度

# 输出格式

- {问题1}：{严重程度} - {影响}
- {问题2}：{严重程度} - {影响}

## 优化建议
1. **{建议1}**
   - 原因：{为什么}

## 优化后代码
{提供优化后的代码实现}

## 验证方法
{如何验证优化效果}
```

## 8. 最佳实践总结

### 8.1 提示词设计原则

1. **上下文完整**：提供足够的项目背景
2. **规范明确**：明确使用的框架和规范
3. **性能导向**：始终考虑性能影响
4. **可测试性**：生成的代码应易于测试
5. **可扩展性**：考虑未来需求变化

### 8.2 常见错误避免

| 错误 | 后果 | 解决方案 |
|-----|------|---------|
| 缺少项目背景 | 生成不符合项目规范的代码 | 提供详细的项目信息 |
| 忽略性能要求 | 生成性能差的代码 | 明确性能要求和目标平台 |
| 过于笼统 | 生成通用但不实用的代码 | 具体化需求和约束条件 |
| 缺少示例 | 生成风格不一致的代码 | 提供代码示例和风格参考 |
