## 🎯 核心技能

### Prompt 设计原则

1. **明确具体**: 清晰表达需求
2. **结构化**: 使用清晰的格式
3. **示例驱动**: 提供期望的输出示例
4. **迭代优化**: 持续改进 Prompt

### 常用技巧

- **角色设定**: 为 AI 分配特定角色
- **上下文提供**: 给出足够的背景信息
- **输出格式**: 指定期望的输出格式
- **约束条件**: 明确限制和要求
- **思维链**: 引导 AI 逐步推理

## 💡 最佳实践

### 设计流程

1. **明确目标**: 确定 Prompt 要解决的问题
2. **初版设计**: 编写基础 Prompt
3. **测试验证**: 用多个案例测试
4. **迭代优化**: 根据结果改进
5. **文档记录**: 记录有效模式

### 常见模式

**零样本学习**:
```
直接描述任务，不提供示例
```

**少样本学习**:
```
提供 2-3 个示例
让 AI 理解模式
```

**思维链**:
```
"让我们一步步思考：
1. 首先...
2. 然后...
3. 最后..."
```

## 🎨 模板库

### Agent 行为模板
```
你是一个 {角色}，具有 {能力}。
你的目标是 {目标}。
在 {条件} 时，你应该 {行为}。
```

### 代码生成模板
```
请用 {语言} 实现一个 {功能}。
要求：
1. {要求1}
2. {要求2}
返回 {格式} 的代码。
```

### 分析总结模板
```
请分析以下 {内容}：
{内容}

从以下角度进行分析：
1. {角度1}
2. {角度2}
3. {角度3}
```
