## 1. OpenClaw 是什么？

### 1.1 项目定义

**OpenClaw**（代号"小龙虾"）是一个**开源的、本地优先的 AI Agent 执行框架**，让 AI 能够"看见"屏幕、"操作"电脑，完成各种复杂任务。

```
┌─────────────────────────────────────────────────────────┐
│                     OpenClaw                             │
│                                                         │
│   "让 AI 不只是对话，而是真正能干活的数字员工"              │
│                                                         │
│   ┌─────────┐   ┌─────────┐   ┌─────────┐             │
│   │ 理解    │ → │ 规划    │ → │ 执行    │             │
│   │ 用户意图 │   │ 任务步骤 │   │ 实际操作 │             │
│   └─────────┘   └─────────┘   └─────────┘             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 项目起源

| 属性 | 信息 |
|------|------|
| **发起人** | Peter Steinberger（奥地利独立开发者） |
| **开源协议** | MIT License |
| **主要语言** | TypeScript / Node.js |
| **首次发布** | 2024 年 |
| **爆发时间** | 2026 年初 |

### 1.3 为什么叫"小龙虾"？

- **Claw** = 钳子，象征 AI 的"动手能力"
- **Open** = 开源开放
- **小龙虾** = 中文社区的亲切昵称 🦞

## 2. 核心设计理念

### 2.1 本地优先（Local-First）

```
┌─────────────────────────────────────────────────────────┐
│                  本地优先架构                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   传统云端 AI                    OpenClaw 本地优先       │
│   ┌─────────┐                   ┌─────────┐            │
│   │ 用户    │                   │ 用户    │            │
│   └────┬────┘                   └────┬────┘            │
│        ↓                              ↓                 │
│   ┌─────────┐                   ┌─────────┐            │
│   │ 云端    │ ← 数据外流        │ 本地    │ ← 数据留存  │
│   │ 服务器  │                   │ 机器    │            │
│   └─────────┘                   └─────────┘            │
│                                                         │
│   隐患：数据泄露、依赖网络        优势：隐私安全、离线可用  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**本地优先的优势：**

| 优势 | 说明 |
|------|------|
| 🔒 **隐私安全** | 敏感数据不出本地 |
| ⚡ **低延迟** | 本地处理，响应更快 |
| 🌐 **离线可用** | 部分功能无需联网 |
| 🎛️ **完全控制** | 可自定义所有配置 |

### 2.2 真执行能力（Real Execution）

OpenClaw 不仅是"对话工具"，而是能**真正执行任务**的"数字员工"。

```
传统 AI 助手                     OpenClaw
┌──────────────────┐          ┌──────────────────┐
│ 用户：帮我发邮件   │          │ 用户：帮我发邮件   │
│                  │          │                  │
│ AI：好的，这是    │          │ AI：好的，已发送  │
│     邮件草稿...   │          │     给张三...    │
│                  │          │                  │
│ 用户需要手动发送  │          │ ✅ 自动完成发送   │
└──────────────────┘          └──────────────────┘
```

**可执行的任务类型：**

- 📧 发送邮件、消息
- 📁 文件操作（创建、编辑、删除）
- 🌐 网页浏览、数据抓取
- 💻 代码编写、执行
- 📊 数据分析、报表生成
- 🗓️ 日程管理、提醒

### 3.1 三层架构

```
┌─────────────────────────────────────────────────────────────┐
│                    OpenClaw 三层架构                         │
├─────────────────────────────────────────────────────────────┤

│  │              工具调用层（Skill Layer）                │   │
│  │                                                     │   │
│  │   Skills 插件 │ MCP 协议 │ Function Calling         │   │
│  │                                                     │   │
```

### 3.2 各层职责

#### 用户交互层
- 接入各种即时通讯平台
- 统一消息格式处理
- 多通道并发管理

#### 工具调用层
- Skill 插件管理
- 工具调用路由
- MCP 协议支持

#### 核心执行层
- 任务理解与规划
- ReAct 执行循环
- 记忆与上下文管理
- 安全沙箱隔离

## 4. 核心特性详解

### 4.1 多模型支持

OpenClaw 支持多种大语言模型后端：

| 类型 | 支持的模型 |
|------|-----------|
| **商业 API** | Claude、GPT-4、DeepSeek、通义千问、文心一言 |
| **开源模型** | Llama、Qwen、Mistral |
| **本地部署** | Ollama、vLLM、LM Studio |

```javascript
// 配置示例：.env 文件
ANTHROPIC_API_KEY=your_claude_key
OPENAI_API_KEY=your_openai_key
DEEPSEEK_API_KEY=your_deepseek_key

// 或使用本地 Ollama
OLLAMA_BASE_URL=http://localhost:11434
```

### 4.2 多通道接入

## 7. 快速开始

### 7.1 安装步骤

```bash
# 方式一：使用 npm 安装
npm install -g openclaw

# 方式二：从源码安装
git clone https://github.com/clawdbot/openclaw.git
cd openclaw
npm install

# 初始化配置
openclaw init

# 启动服务
openclaw start
```

### 7.2 基本配置

```bash
# .env 配置文件
# 选择你的 LLM 后端
LLM_PROVIDER=anthropic  # 或 openai, deepseek, ollama

# API 密钥
ANTHROPIC_API_KEY=your_key_here

# 启用的通道
CHANNELS=cli,feishu,wechat
```

### 7.3 第一个对话

```
用户：你好，请介绍一下你自己

OpenClaw：你好！我是 OpenClaw，一个开源的 AI 助手。
我可以帮你处理各种任务，比如发送邮件、管理日程、
搜索信息等。有什么我可以帮你的吗？
```
