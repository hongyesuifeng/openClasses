# 赛博小镇 - 技术架构文档

## 概述

赛博小镇（Cyber Town）是一个由多个AI Agent驱动的虚拟社会模拟游戏。本文档描述了系统的技术架构、模块设计和数据流。

## 核心模块详解

### 1. Agent Framework (`src/framework/agent_framework.js`)

Agent基础设施，提供核心范式支持。

**关键组件：**

- **Message**: Agent间通信的基本单位
- **MessageBus**: 发布-订阅模式的消息分发系统
- **ToolRegistry**: 工具/行为注册与执行管理
- **MemorySystem**: 记忆存储与检索
- **BaseAgent**: Agent基类，实现ReAct循环

```javascript
// ReAct循环示例
async reactLoop(query, maxIterations = 10) {
    for (let i = 0; i < maxIterations; i++) {
        // 1. Thought: 思考
        const thought = await this.think(query, context, steps);

        // 2. Action: 选择行为
        const action = this.parseAction(thought);

        // 3. Observation: 观察结果
        const observation = await this.executeAction(action);
    }
}
```

### 2. Character System (`src/core/character.js`)

角色Agent系统，实现NPC的核心逻辑。

**OCEAN性格模型：**

| 特质 | 英文 | 描述 | 影响范围 |
|------|------|------|----------|
| 开放性 | Openness | 好奇心、创造力 | 探索倾向 |
| 尽责性 | Conscientiousness | 自律、组织能力 | 工作倾向 |
| 外向性 | Extraversion | 社交性、活力 | 社交倾向 |
| 宜人性 | Agreeableness | 合作、善良 | 助人倾向 |
| 神经质 | Neuroticism | 情绪稳定性 | 休息需求 |

**状态属性：**

```javascript
state: {
    mood: 0.5,      // 心情值 (-1 到 1)
    energy: 1.0,    // 能量值 (0 到 1)
    hunger: 0.0,    // 饥饿值 (0 到 1)
    social: 0.5     // 社交需求 (0 到 1)
}
```

### 3. Behavior System (`src/core/behavior.js`)

行为决策系统，实现ReAct范式在游戏中的应用。

**行为类型：**

| 行为 | 效果 | 需求 |
|------|------|------|
| move | energy -0.05 | energy >= 0.1 |
| eat | hunger -0.5, energy +0.1, mood +0.1 | 特定地点 |
| rest | energy +0.4, mood +0.1 | 家/公园 |
| socialize | social -0.3, mood +0.2 | energy >= 0.2 |
| work | energy -0.2, mood -0.1 | 办公室 |

**决策流程：**

```
1. 分析需求 → 获取紧迫需求列表
2. Thought → 生成思考（分析当前状态）
3. Action → 选择行为（基于需求和性格）
4. Observation → 评估可行性
5. 执行或选择替代方案
```

### 4. Memory System (`src/core/memory.js`)

扩展记忆系统，支持游戏特定场景。

**记忆类型：**

- **事件记忆** (Event Memory): 发生的事件
- **社交记忆** (Social Memory): 与其他角色的互动
- **空间记忆** (Spatial Memory): 地点访问记录

**记忆衰减公式：**

```
importance(t) = importance_0 × e^(-decay_rate × t)
```

其中：
- `importance_0`: 初始重要性
- `decay_rate`: 衰减率（默认0.01）
- `t`: 时间（小时）

### 5. Time System (`src/world/time_system.js`)

游戏时间管理系统。

**时段划分：**

| 时段 | 时间范围 | 活动倍率 | 工作倾向 | 社交倾向 |
|------|----------|----------|----------|----------|
| 黎明 | 5:00-7:00 | 0.5x | 0.2 | 0.3 |
| 早晨 | 7:00-12:00 | 1.0x | 0.9 | 0.6 |
| 下午 | 12:00-18:00 | 1.0x | 0.8 | 0.7 |
| 傍晚 | 18:00-21:00 | 0.8x | 0.3 | 0.9 |
| 夜晚 | 21:00-5:00 | 0.3x | 0.1 | 0.4 |

### 6. Location System (`src/world/location.js`)

地点管理系统，处理空间关系。

**地点类型：**

- `HOME`: 家
- `WORK`: 工作场所
- `SOCIAL`: 社交场所
- `COMMERCIAL`: 商业场所
- `PUBLIC`: 公共场所
- `NATURE`: 自然场所

**路径搜索：** 使用BFS算法寻找最短路径。

### 7. Social System

**关系系统 (`src/social/relationship.js`):**

关系值范围：-1（敌对）到 1（亲密）

关系类型：
- 敌人 (Enemy): < -0.6
- 不喜欢 (Dislike): -0.6 ~ -0.3
- 陌生人 (Stranger): -0.3 ~ 0.3
- 熟人 (Acquaintance): 0.3 ~ 0.6
- 朋友 (Friend): > 0.6

**对话系统 (`src/social/conversation.js`):**

- 支持模板生成对话
- 支持MiniMax API生成智能对话
- 记录对话历史和情感分析

**社交网络 (`src/social/social_network.js`):**

- 社交影响力计算
- 社区发现
- 关系图谱可视化

### 8. Event System (`src/world/event_system.js`)

游戏事件管理系统。

**事件类型：**

- `MOVEMENT`: 移动事件
- `SOCIAL`: 社交事件
- `ACTION`: 行为事件
- `WORLD`: 世界事件
- `SYSTEM`: 系统事件
- `RANDOM`: 随机事件

## 扩展性设计

### 添加新角色

1. 在 `data/characters.json` 添加角色配置
2. 定义性格（OCEAN）和初始状态
3. 设置初始位置

### 添加新地点

1. 在 `data/locations.json` 添加地点配置
2. 定义位置坐标和连接关系
3. 配置允许的行为

### 添加新行为

1. 在 `src/core/behavior.js` 的 `BEHAVIORS` 对象添加行为定义
2. 定义效果（effects）和需求（requirements）
3. 在 `GameOrchestrator` 添加执行方法

### 集成LLM

1. 配置MiniMax API Key
2. `ConversationSystem` 会自动使用LLM生成对话
3. 可以扩展到其他LLM服务

## 性能优化

- **记忆限制**: 短期记忆50条，长期记忆500条
- **事件历史**: 最多保留1000条
- **增量更新**: 只更新变化的部分
- **Canvas渲染**: 使用离屏渲染优化
