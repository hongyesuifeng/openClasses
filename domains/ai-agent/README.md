## 📝 学习笔记

### 核心概念

- **Agent**: 具有自主决策能力的 AI 系统
- **MCP**: Model Context Protocol，上下文协议
- **RAG**: Retrieval Augmented Generation，检索增强生成
- **Memory**: 长期和短期记忆系统

### 常见问题

**Q: Agent 和 Chatbot 的区别？**
A: Agent 具有自主决策和工具使用能力，Chatbot 主要是对话。

**Q: 如何开始学习 Agent 开发？**
A: 建议从 CS146S 或 Hello-Agents 课程开始。
