## 论文阅读方法

### 三遍阅读法

1. **第一遍（15分钟）**: 读标题、摘要、引言、结论，了解论文大意
2. **第二遍（1小时）**: 通读全文，关注图表和实验，理解核心方法
3. **第三遍（2-4小时）**: 深入细节，理解数学推导，思考与已有知识的关联

### 笔记原则

- 不是抄摘要，是自己的消化
- 每篇论文回答三个问题：解决了什么问题？核心方法是什么？为什么重要？
- 建立论文之间的关联：这篇论文建立在哪些前人工作之上？又催生了哪些后续工作？

## 学习策略

### 推荐顺序
按章节顺序（第1章→第10章），因为后续章节依赖前面章节的知识。

### 专题路线
- **LLM 方向**: 第1章→第2章→第5章→第6章→第7章→第8章→第9章
- **视觉/生成方向**: 第1章→第3章→第4章
- **应用方向**: 第1章→第2章→第9章→第10章

### 时间安排
- 每周 6-8 小时，2-3 篇论文
- 每篇论文预计 2-3 小时（含笔记整理）
- 16 周完成全部 44 篇
