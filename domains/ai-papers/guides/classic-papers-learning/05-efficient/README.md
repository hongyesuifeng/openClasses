# 第6章：高效训练与架构

> 让大模型飞入寻常百姓家

## 章节概览

大模型的民主化依赖于训练和推理效率的提升。本章涵盖 LoRA/QLoRA 让微调平民化，MoE 用稀疏激活提升模型容量，FlashAttention 从底层优化注意力计算，Mamba 探索 Transformer 之外的架构可能。

## 学习目标

- 掌握 LoRA 低秩适配的原理和实践
- 理解 MoE 稀疏激活的机制
- 了解 FlashAttention 的 IO 感知优化
- 理解 Mamba/SSM 的选择性状态空间模型
