# 技术原理：规模与涌现

> 规模不是万能的，但没有规模是万万不能的

## 核心概念

### 1. 幂律关系（Power Law）

Scaling Laws 的核心发现：模型性能与计算资源呈幂律关系。

L(C) ≈ (C/C0)^(-α)

其中 L 是损失，C 是计算量，α 是幂律指数。这意味着：可预测地估计投入更多资源能带来多少提升。

### 2. 涌现能力（Emergent Ability）

定义：在小模型上不存在、但在大模型上突然出现的能力。

关键特征：
- 非线性增长：不是渐进提升，而是"突变"
- 不可预测：无法从小模型外推
- 任务特定：不同能力在不同规模涌现

### 3. 计算最优训练（Compute-Optimal Training）

Chinchilla 的核心洞察：给定固定计算预算，模型参数量和训练数据量应等比增长。

GPT-3 的问题：参数量过大（175B）但训练数据不足（300B tokens）。
Chinchilla 的方案：更小的模型（70B）+ 更多的数据（1.4T tokens）= 更好的效果。

### 4. 训练系统工程

大规模训练的工程挑战：
- **数据并行**: 多 GPU 上拆分 batch
- **模型并行**: 单个模型拆分到多个 GPU
- **流水线并行**: 按层拆分到不同设备
- **混合精度**: FP16/BF16 训练降低显存

## 关键数学

### Scaling Laws
```
L(N, D) = (Nc/N)^αN + (Dc/D)^αD + L∞
```
N = 参数量, D = 数据量, αN ≈ 0.076, αD ≈ 0.095

### Chinchilla 最优
```
N_opt ∝ C^a, D_opt ∝ C^b
其中 a ≈ 0.5, b ≈ 0.5
即参数量和数据量应等比增长
```

## 规模与能力对应关系

| 参数量 | 典型能力 |
|--------|----------|
| 1B-7B | 基础文本生成、简单QA |
| 7B-30B | 指令遵循、代码生成 |
| 30B-70B | 复杂推理、多轮对话 |
| 70B-175B | 少样本学习、涌现推理 |
| 175B+ | Chain-of-Thought、复杂规划 |
