# 第2章：规模与涌现

> 当模型大到一定程度，神奇的事情开始发生

## 章节概览

本章探讨 AI 领域最重要的发现之一：**规模效应（Scaling）**。从 Scaling Laws 的理论框架，到 GPT-3 的涌现能力验证，再到 Chinchilla 对数据量的重新审视，这些工作证明了"更大=更强"并非盲目信仰，而是有数学基础的规律。

## 学习目标

- 理解 Scaling Laws 的幂律关系
- 掌握涌现能力（Emergent Ability）的概念
- 了解规模扩展的工程挑战（训练系统、数据质量）
- 理解 Chinchilla 对 GPT-3 训练不足的修正
