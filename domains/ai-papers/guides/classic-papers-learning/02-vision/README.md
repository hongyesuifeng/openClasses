# 第3章：视觉AI革命

> 从 CNN 到 Transformer，视觉理解的范式转换

## 章节概览

视觉 AI 在 2020-2023 年间经历了深刻变革。ViT 将 Transformer 引入视觉领域，CLIP 统一了视觉和语言的语义空间，SAM 开创了"分割一切"的基础模型范式，DeiT 证明了小数据也能训练 ViT。

## 学习目标

- 理解 ViT 如何将图像转化为序列
- 掌握 CLIP 对比学习的原理
- 了解 SAM 的 promptable segmentation 范式
- 理解视觉基础模型的概念和意义
