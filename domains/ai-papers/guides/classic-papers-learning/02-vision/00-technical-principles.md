# 技术原理：视觉AI革命

> 把一切 token 化——图像也不例外

## 核心概念

### 1. 图像 Token 化

ViT 的核心洞察：图像可以像文本一样被切分成离散单元。

```
文本: "Hello world" → ["Hello", "world"] → Token 序列
图像: 224×224 图像 → 14×14 个 16×16 Patch → Token 序列
```

每个 Patch 通过线性投影变成一个向量（类似于 Word Embedding），然后加上位置编码，送入标准 Transformer。

### 2. 视觉-语言对齐

CLIP 的核心思想：把图像和文本映射到同一个向量空间。

训练目标：
- 配对的图像-文本：向量表示接近（高余弦相似度）
- 不配对的：向量表示远离（低余弦相似度）

这创造了"视觉语义空间"——可以零样本分类、跨模态搜索。

### 3. 基础模型（Foundation Model）

定义：在大量数据上预训练，能适配多种下游任务的大模型。

视觉基础模型演进：
- ViT：通用视觉骨干
- CLIP：视觉-语言桥梁
- SAM：通用分割
- DINOv2：自监督视觉特征

### 4. 知识蒸馏（Knowledge Distillation）

DeiT 的方法：用强教师网络（CNN）指导 ViT 训练。

- 软标签：教师网络的输出概率分布
- 硬标签：真实标签
- 学生网络（ViT）同时学习两者

## 关键技术对比

| 方法 | 数据需求 | 核心创新 | 下游适配 |
|------|---------|---------|---------|
| ViT | 大量（JFT-300M） | Patch Embedding | 微调 |
| CLIP | 大量（400M 文本-图像对） | 对比学习 | 零样本 |
| SAM | 大量（SA-1B 11M 图像） | Promptable | 零样本 |
| DeiT | 中等（ImageNet 1.28M） | 蒸馏 | 微调 |
