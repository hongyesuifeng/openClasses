# Gemini（2023）— 原生多模态：从一开始就用所有模态共同训练

## 基本信息
- **论文**: Gemini: A Family of Highly Capable Multimodal Models
- **作者**: Google DeepMind
- **机构**: Google DeepMind
- **年份**: 2023
- **状态**: 未阅读

## 解决了什么问题

GPT-4 虽然展示了多模态能力，但它是建立在语言模型基础上再进行多模态微调的——本质上还是"语言模型学会了看图"。这种"后融合"路线有几个问题：

1. **模态不均衡**：语言能力远强于视觉能力，因为预训练阶段只使用了文本
2. **音频缺失**：GPT-4V 只支持文本和图像，无法处理语音输入
3. **跨模态推理受限**：模型在需要深度跨模态理解的任务（如"视频中的这个人说了什么，他的表情是怎样的"）上表现不佳

Gemini 试图回答的核心问题是：**如果从一开始就用文本、图像、音频、视频等多种模态数据共同训练模型，能否获得更深层次的多模态理解能力？**

## 核心方法

Gemini 的核心设计理念是**原生多模态（Native Multimodal）**：

1. **统一架构**：不同于 GPT-4 的"视觉编码器 + 语言模型"拼接方案，Gemini 从模型设计之初就考虑多模态输入。所有模态（文本、图像、音频、视频）被映射到同一个表示空间，由同一个 Transformer 架构处理。

2. **多模态预训练数据**：预训练阶段直接使用图像-文本配对、视频片段、音频片段等多种数据，而非先训练纯文本模型再进行多模态微调。

3. **模型家族**：Gemini 不是一个模型，而是一个系列：
   - **Gemini Ultra**：最强版本，对标 GPT-4，支持全部模态
   - **Gemini Pro**：中等规模，对标 GPT-3.5，成本和性能的平衡
   - **Gemini Nano**：端侧部署版本，可在手机上运行

4. **工具调用能力**：Gemini API 内置代码执行、函数调用等工具能力，模型可以主动决定何时调用外部工具。

**与 GPT-4 的关键区别**：

| 维度 | GPT-4 | Gemini |
|------|-------|--------|
| 多模态方式 | 视觉编码器 + LLM 后融合 | 原生多模态统一训练 |
| 音频支持 | 不支持（GPT-4V 时代） | 原生支持 |
| 模型系列 | 单一模型 + 上下文变体 | Ultra / Pro / Nano 三档 |
| 工具调用 | 通过 API 层实现 | 模型内置能力 |

## 关键实验结果

- **MMLU（大规模多任务语言理解）**：Gemini Ultra 首次在 MMLU 上超越人类专家水平（90.0% vs 89.8%）
- **MMMU（大规模多模态多任务理解）**：在需要跨模态推理的基准上显著优于 GPT-4V
- **数学推理**：GSM8K 上达到 94.4%，MATH 上达到 53.2%
- **代码生成**：HumanEval 上达到 74.4%
- **图像理解**：在 VQAv2、TextVQA 等视觉理解基准上表现优异
- **多语言**：支持 40+ 语言，在多语言任务上与 GPT-4 相当

## 为什么重要

Gemini 的重要性在于它代表了一种与 GPT-4 截然不同的多模态路线：

1. **原生多模态 vs 拼接多模态**：Gemini 证明了"从一开始就融合"的路线是可行的，而且在某些跨模态任务上可能更优。这个路线之争至今仍在继续。

2. **多模态理解深度的提升**：Gemini 在需要理解图像中文字、图表数据、视频时间序列等任务上表现更好，说明原生多模态确实带来了更深层次的跨模态理解。

3. **Google 的 AI 战略支点**：Gemini 是 Google 将 Google Brain 和 DeepMind 合并后的首个旗舰项目，代表了 Google 全面对抗 OpenAI 的决心。

4. **模型家族理念**：Ultra/Pro/Nano 的分档策略影响了后续几乎所有大模型厂商的产品规划。

## 后续影响

- **Gemini 1.5 Pro**：引入 100 万 token 超长上下文，以及视频理解能力
- **Gemini 2.0 系列**：进一步强化原生多模态和 Agent 能力
- **多模态评估基准**：MMMU 等基准因 Gemini 的出现而成为标配
- **行业影响**：推动了所有大模型厂商转向原生多模态路线

## 个人理解

Gemini 和 GPT-4 的对比让我想到了一个有趣的问题：**语言是不是人类思维的本质？** GPT-4 的路线暗示"语言是基础，其他模态是附加"；Gemini 的路线暗示"所有模态都是平等的，应该一起学习"。

从实际效果看，两种路线各有优劣。GPT-4 在纯文本推理上可能更强（因为文本训练量更大），而 Gemini 在跨模态任务上更有优势。但随着技术进步，这两种路线很可能会趋同——最终都会走向"用所有可用数据联合训练"的方案。

Gemini 的另一个启示是：**AI 竞争正在从"谁的模型更强"变成"谁的生态更完整"**。Google 将 Gemini 深度集成到搜索、文档、Android 等全产品线中，这种生态优势是纯 API 公司难以匹敌的。
