# 第7章：多模态系统

> AI 的终极形态是理解一切模态

## 章节概览

单一模态到多模态是 AI 发展的必然趋势。GPT-4 通过微调实现了视觉+语言，Gemini 从预训练阶段就原生支持多模态，Gato 则探索了用单一模型处理视觉、语言、强化学习等完全不同类型任务的可能性。

## 学习目标

- 理解多模态融合的两种路线：微调 vs 原生
- 掌握 GPT-4 的能力边界和评估方法
- 了解通才智能体（Generalist Agent）的概念
