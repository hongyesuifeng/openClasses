# 技术原理：生成式AI

> 从随机噪声中创造秩序

## 核心概念

### 1. 扩散模型（Diffusion Models）

核心思想：通过逐步添加噪声（前向过程）然后学习逆向去噪。

**前向过程**（加噪）：
x_t = √(α_t) × x_0 + √(1-α_t) × ε

**逆向过程**（去噪）：
训练一个网络预测噪声 ε，然后从 x_t 恢复 x_{t-1}

**为什么比 GAN 好？**
- 训练稳定，不存在模式崩溃
- 生成多样性更好
- 有完整的概率论基础

### 2. 潜空间扩散（Latent Diffusion）

Stable Diffusion 的核心创新：不在像素空间做扩散，而是在压缩的潜空间做。

```
像素空间 (512×512×3) → 编码器 → 潜空间 (64×64×4) → 扩散 → 解码器 → 像素空间
```

计算量降低约 64 倍，使得消费级 GPU 上生成高质量图像成为可能。

### 3. 隐式神经表示（Implicit Neural Representation）

NeRF 的核心思想：用神经网络表示连续的 3D 场景。

- 输入：3D 坐标 (x, y, z) + 视角方向 (θ, φ)
- 输出：颜色 (RGB) + 密度 (σ)
- 渲染：沿光线积分得到像素颜色

不需要离散的网格或体素，天然支持任意分辨率。

### 4. SDS Loss（Score Distillation Sampling）

DreamFusion 的核心方法：利用 2D 扩散模型的知识指导 3D 生成。

```
循环：
1. 从 3D 表示渲染 2D 图像
2. 用 2D 扩散模型评估"这张图像与文本描述匹配吗？"
3. 将梯度反向传播到 3D 表示
4. 优化 3D 表示使其渲染结果更符合文本描述
```

### 5. U-Net 架构

扩散模型的核心骨干网络：

- **编码器**：逐步下采样，提取多尺度特征
- **解码器**：逐步上采样，恢复空间分辨率
- **跳跃连接**：将编码器特征直接传给解码器对应层

## 技术演进

```
GAN (2014) → 模式崩溃、训练不稳定
    ↓
Diffusion (2020) → 训练稳定但计算昂贵
    ↓
Latent Diffusion (2021) → 高效的潜空间扩散
    ↓
    ├── 文本→图像: DALL-E → Stable Diffusion → Midjourney
    ├── 文本→3D: DreamFusion → Gaussian Splatting
    └── 文本→视频: Sora → 世界模拟器
```
