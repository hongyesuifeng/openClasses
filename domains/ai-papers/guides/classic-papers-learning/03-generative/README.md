# 第4章：生成式AI

> 从像素到世界模拟器

## 章节概览

本章追踪了生成式 AI 的完整技术谱系：从 GAN 到 Diffusion 的范式转换，从 2D 图像生成到 3D 场景重建再到视频生成。这些工作不仅改变了内容创作的方式，也深刻影响了游戏、影视、设计等行业。

## 学习目标

- 理解扩散模型的数学原理和训练过程
- 掌握 Latent Diffusion 为什么比 Pixel Diffusion 高效
- 了解 NeRF 隐式神经表示的思想
- 理解从文本到 3D/视频生成的技术路径
