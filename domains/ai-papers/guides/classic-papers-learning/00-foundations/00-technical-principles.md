# 技术原理：基础架构与理论

> 理解现代深度学习的根基

## 核心概念

### 1. 注意力机制（Attention）

在 Transformer 出现之前，序列建模（如翻译、文本生成）主要依赖 RNN/LSTM。这些模型的核心局限是**串行处理**——必须一个词一个词地处理，无法并行化。

注意力机制的核心思想：**让模型在处理每个词时，能"看到"输入序列中的所有其他词，并决定哪些词最重要。**

- **Query (Q)**: 当前词在"问"什么
- **Key (K)**: 每个词能提供什么信息
- **Value (V)**: 每个词的实际内容
- **计算**: Attention(Q, K, V) = softmax(QK^T / √d_k) × V

### 2. 残差学习（Residual Learning）

深层网络的训练难题：梯度在反向传播中不断衰减。

ResNet 的解决方案：**让每一层只学习增量**。
- 传统：学习 H(x)
- 残差：学习 F(x) = H(x) - x，输出 y = F(x) + x

### 3. 对抗生成（Adversarial Training）

GAN 的核心思想：两个网络的博弈。
- **生成器 G**: 尽量生成逼真的假数据
- **判别器 D**: 尽量区分真假数据
- 训练目标：min_G max_D V(D, G)

### 4. 预训练范式（Pre-training Paradigm）

| 方法 | 方向 | 目标 | 代表 |
|------|------|------|------|
| 自编码 | 双向 | 完形填空 | BERT |
| 自回归 | 左到右 | 预测下一个词 | GPT 系列 |

## 技术演进脉络

```
RNN/LSTM (串行处理)
    ↓
Attention (关注重要信息)
    ↓
Transformer (全并行 + 注意力)
    ↓
     ├── BERT (双向预训练 → 理解)
     └── GPT (自回归预训练 → 生成)
```

## 关键数学

### 缩放点积注意力
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```
其中 d_k 是 Key 的维度，除以 √d_k 防止点积过大导致 softmax 梯度消失。

### 残差块
```
y = F(x, {W_i}) + x
```
梯度可以直接通过恒等映射传播，解决梯度消失。

### GAN 目标函数
```
min_G max_D V(D, G) = E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 - D(G(z)))]
```
