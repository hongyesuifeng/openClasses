# 第9章：AI推理能力

> 从模式匹配到真正的思考

## 章节概览

推理能力是通向 AGI 的关键一步。Chain-of-Thought 打开了"慢思考"的大门，AlphaGeometry 展示了神经符号系统的威力，o1 和 DeepSeek-R1 将推理能力提升到了新高度。

## 学习目标

- 理解 Chain-of-Thought 为什么能提升推理能力
- 了解测试时计算扩展（Test-Time Compute）的概念
- 掌握神经符号系统的设计思想
- 理解开源推理模型的技术路线
