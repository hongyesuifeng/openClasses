# 技术原理：AI推理能力

> 思考需要时间和空间

## 核心概念

### 1. 快思考 vs 慢思考（System 1 vs System 2）

Daniel Kahneman 的双系统理论在 AI 中的映射：

| 系统 | 特点 | AI 对应 |
|------|------|---------|
| System 1 | 快速、直觉、自动 | 直接生成答案（标准 LLM） |
| System 2 | 缓慢、推理、深思熟虑 | CoT/o1 的逐步推理 |

### 2. Chain-of-Thought（CoT）

核心洞察：**推理过程本身也是文本**。

```
无 CoT:  问题 → 答案（容易出错）
有 CoT:  问题 → 中间步骤1 → 步骤2 → ... → 答案（更准确）
```

为什么有效：
- 给模型"思考空间"
- 每一步的预测更简单
- 错误可以在中间步骤被发现

### 3. 测试时计算扩展（Test-Time Compute Scaling）

o1 的核心创新：在推理时投入更多计算，获得更好的结果。

```
传统 LLM: 训练时大量计算，推理时一次前向传播
o1: 训练时大量计算 + 推理时也大量计算（搜索、验证、反思）

推理过程：
1. 生成多个候选推理链
2. 评估每条链的可靠性
3. 选择最优或综合多条链
4. 可能反思和修正错误
```

### 4. 神经符号系统

AlphaGeometry 的设计哲学：

```
神经网络（直觉）: 生成构造辅助线的灵感
    +
符号引擎（严谨）: 基于逻辑规则的严格证明
    =
超越纯神经或纯符号的系统
```

### 5. GRPO（Group Relative Policy Optimization）

DeepSeek-R1 的训练创新：
- 不需要显式的奖励模型
- 同一问题的多个回答在组内比较
- 组内相对排名作为奖励信号

## 推理能力演进

```
2022  CoT: 把推理步骤写出来
2023  Self-Consistency: 多次采样 + 投票
2023  Tree-of-Thought: 树状搜索推理空间
2024  o1: 测试时计算扩展
2025  DeepSeek-R1: 开源推理模型
```
