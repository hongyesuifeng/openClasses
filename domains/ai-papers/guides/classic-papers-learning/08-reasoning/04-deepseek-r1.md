# DeepSeek-R1（2025）— 纯强化学习路线自涌现推理能力的开源模型

## 基本信息
- **论文**: DeepSeek-R1: Incentivizing Reasoning Capability in LLMs via Reinforcement Learning
- **作者**: DeepSeek
- **机构**: DeepSeek (深度求索)
- **年份**: 2025
- **状态**: 未阅读

## 解决了什么问题

OpenAI 的 o1 系统证明了通过强化学习可以让大模型获得深度推理能力，但 o1 是闭源的——外界不知道它是怎么训练的，也无法复现。这引发了两个关键问题：

1. **技术复现问题**：o1 的推理能力到底是如何训练的？需要多少标注数据？训练流程是什么样的？
2. **开源问题**：是否存在一条不依赖 OpenAI 技术路线的开源方案，能让任何人都能训练出推理模型？

更深层的技术问题是：**推理能力是否必须通过监督学习（用人类写的推理链作为训练数据）来获得？还是可以通过纯强化学习，让模型自己"涌现"出推理能力？**

DeepSeek-R1 试图回答这些问题，并给出了一个令人惊讶的答案：**推理能力可以通过纯 RL 训练从无到有地涌现出来。**

## 核心方法

DeepSeek-R1 的核心创新是 **GRPO（Group Relative Policy Optimization）** 和纯 RL 路线。

### 1. GRPO：群体相对策略优化

传统的 RL 训练（如 PPO）需要一个独立的奖励模型来评估生成质量，训练流程复杂且不稳定。GRPO 简化了这个过程：

- **组内对比**：对同一个问题生成多个回答（一组），在组内进行相对排名
- **相对奖励**：不依赖外部奖励模型的绝对评分，而是用组内相对表现作为训练信号
- **基线自校正**：用组内平均表现作为基线，高于基线的获得正奖励，低于基线的获得负奖励

GRPO 的优势：
- 不需要训练单独的奖励模型（省去了 RM 训练这一步）
- 训练更稳定（相对评分比绝对评分更鲁棒）
- 计算效率更高（组内对比只需一次前向传播）

### 2. 纯 RL 路线：不依赖监督数据

这是 DeepSeek-R1 最令人震惊的发现。传统的推理模型训练通常需要：

1. 大量人类写的推理链作为监督数据（SFT 阶段）
2. 用这些数据微调模型
3. 再用 RL 进一步优化

DeepSeek-R1 跳过了第 1-2 步，直接从预训练模型开始 RL：

- **DeepSeek-R1-Zero**：完全不用任何监督数据，直接对基础模型（DeepSeek-V3）进行 RL 训练
- **推理能力自涌现**：训练过程中，模型自发地学会了生成长推理链、自我验证、回溯修正等行为
- **Aha Moment**：研究者观察到模型在训练中突然"学会了"在推理链中进行反思和修正

### 3. 冷启动 + 多阶段训练

虽然纯 RL 路线有效，但 DeepSeek-R1 最终版本采用了一个更实用的多阶段训练流程：

1. **冷启动 SFT**：用少量（数千条）高质量的推理链数据微调，为 RL 提供好的起点
2. **RL 训练（推理任务）**：在数学、编程等有明确对错的任务上用 GRPO 进行 RL 训练
3. **拒绝采样 + SFT**：从 RL 后的模型中采样高质量推理链，用于进一步微调
4. **全场景 RL**：在所有任务（不仅限于推理任务）上进行最终的 RL 对齐

### 4. 知识蒸馏：让小模型也能推理

DeepSeek-R1 的另一个重要贡献是**蒸馏版本**：

- 将 DeepSeek-R1（671B 参数）的推理能力蒸馏到 1.5B、7B、8B、14B、32B、70B 等小模型中
- 蒸馏方法：用大模型生成高质量推理链数据，用这些数据训练小模型
- 蒸馏后的 7B 模型在数学推理上超过了 GPT-4o，且可以在消费级硬件上运行

## 关键实验结果

- **数学推理（AIME 2024）**：DeepSeek-R1 的准确率与 o1 相当（约 79.8%）
- **数学推理（MATH-500）**：97.3%，与 o1 的 96.4% 相当甚至更优
- **编程（Codeforces）**：Elo 评分约 1800，与 o1 相当
- **科学推理（GPQA Diamond）**：71.5%，接近 o1 的 75.7%
- **蒸馏效果**：
  - DeepSeek-R1-Distill-7B 在 MATH 上达到 79.8%（超过 GPT-4o 的 76.6%）
  - DeepSeek-R1-Distill-32B 在多个基准上超过 o1-mini

## 为什么重要

DeepSeek-R1 的重要性是多维度的：

1. **"推理能力可以涌现"的证明**：DeepSeek-R1-Zero 证明了推理能力不需要人类示范——通过纯 RL 训练，模型可以自己"发明"推理策略。这是一个深远的发现，暗示推理可能是语言模型在 RL 压力下的自然涌现特性。

2. **o1 的开源替代**：DeepSeek-R1 是第一个在推理能力上与 o1 相当的开源模型，让学术界和工业界都能研究和使用推理模型。

3. **GRPO 方法论贡献**：GRPO 简化了 RL 训练流程，降低了训练推理模型的技术门槛。

4. **蒸馏使推理能力民主化**：蒸馏版本让任何人都能在消费级硬件上部署推理模型。一个 7B 的蒸馏模型就可以在本地运行，同时具备强大的数学推理能力。

5. **"纯 RL 路线"的可行性验证**：证明了不需要昂贵的监督数据标注，也能训练出强大的推理模型。这降低了训练推理模型的成本门槛。

## 后续影响

- **开源推理模型生态**：Qwen-QWQ、Sky-T1、Open-R1 等一系列开源推理模型涌现
- **RL 训练流程标准化**：GRPO 成为训练推理模型的标准方法之一
- **蒸馏技术的广泛应用**：从大模型蒸馏推理能力到小模型成为行业惯例
- **o1 vs R1 的路线之争**：OpenAI 的"闭源推理模型" vs DeepSeek 的"开源推理模型"成为行业焦点
- **推理成本大幅下降**：开源推理模型使推理能力的获取成本降低了几个数量级

## 个人理解

DeepSeek-R1 最令人惊讶的发现是 **"Aha Moment"**——模型在 RL 训练过程中自发地学会了反思和修正自己的推理。这个发现暗示了一件深奥的事情：**推理可能不是需要被"教会"的能力，而是在正确的训练压力下会自然涌现的能力。**

这与人类认知发展有有趣的平行：儿童在成长过程中也是先通过试错学习，逐渐发展出"停下来想一想"的能力。DeepSeek-R1 的训练过程在某种程度上模拟了这个发展过程。

从技术角度看，GRPO 的设计非常优雅。PPO 需要单独训练一个奖励模型，这增加了训练的复杂性和不稳定性。GRPO 通过"组内对比"巧妙地绕过了这个问题——你不需要知道每个答案的绝对质量，只需要知道在一组答案中哪个更好。这就像考试中的"相对评分"——不需要知道每道题的绝对难度，只需要排名。

蒸馏策略也是一个关键决策。671B 的模型对大多数人来说太大了，但 7B 的蒸馏版本可以在任何消费级 GPU 上运行。这让推理能力真正走向了大众。

从更大的视角看，DeepSeek-R1 代表了中国 AI 在"前沿技术"领域的突破。如果说 DeepSeek-V2 在工程效率上展示了中国团队的能力，DeepSeek-R1 则在最前沿的研究方向上证明了中国的创新能力。
