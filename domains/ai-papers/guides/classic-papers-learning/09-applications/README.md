# 第10章：知识增强与应用

> 让 AI 真正有用

## 章节概览

如何让 AI 系统真正实用？RAG 通过外部知识检索解决幻觉问题，Whisper 统一了多语言语音识别，ReAct 和 Toolformer 让 AI 学会推理与行动的结合。

## 学习目标

- 掌握 RAG 的检索-生成架构
- 了解大规模弱监督在语音领域的应用
- 理解 ReAct 的推理-行动循环
- 掌握 Toolformer 的自监督工具学习
