# Web3D 学习阶段验收规范

每阶段分别检查实验实现和个人理解。通过条件是能够复现实验、解释过程、给出结果依据，并说明 Cocos 对应机制与差异。阶段 0／1 首版与核心运行检查已有[进度记录](../../../../../user-profile/progress/3d-game-client-progress.md)，个人理解验收仍待开展。

[学习方式修订] 2026-10-10，学习者明确要求使用简明原理、交互演示或动图，避免填写与测算。上述实现检查由 Agent 执行；个人理解可通过后续自然交流确认，填写记录、预测手算和自测答题不作为推进的强制前置。

## 一 阶段检查

| 阶段 | 实现与边界检查 | 理解与 Cocos 对照 |
| --- | --- | --- |
| 0 帧循环 | 旋转、零速度、暂停／继续、重置、尺寸变化、退出清理 | 时间步长与角度；帧回调、引擎调度、对象与渲染职责 |
| 1 数学 | 父节点移动／旋转／缩放；局部与世界转换；投影；不可逆变换给出说明 | 矩阵顺序、四元数、坐标空间、裁剪与透视除法；Vec3／Quat／Mat4 与 Node |
| 2 运动 | 不同帧率同模拟时长；无输入、射线未命中、障碍边界；重置与退出 | 方向、速度、相机、拾取与碰撞区别；时间步长与 Cocos 对应查询机制 |
| 3 资产与动画 | 缺失资源、导入方向／比例、线框／法线／骨骼、播放／暂停、切换与混合 | Mesh、UV、蒙皮与 Clip；Three.js 播放与 Cocos 动画／导入差异 |
| 4 玩法 | 命中去重、无效目标、攻击取消、死亡停止、Buff 时序、状态重置 | 规则与表现分离、状态机与事件顺序；Cocos 组件表现怎样接收结果 |
| 5 渲染 | 原生三角形与纹理、编译错误、深度与透明对比；效果开关与初始状态 | CPU 到 GPU 的步骤、顶点／片元、Shader 参数；Cocos Material／Effect／GFX |
| 6 性能 | 同条件测量、数量与效果对比、资源反复加载释放、池化状态清理 | 区分 CPU、绘制和资源开销；统计范围、优化收益与引擎实现差异 |

## 二 统一证据

```mermaid
flowchart LR
    A[规则与预期] --> B[输入和环境]
    B --> C[运行与中间记录]
    C --> D[实际结果]
    D --> E[解释与适用范围]
    E --> F[个人自测与阶段结论]
```

| 字段 | 必须记录 |
| --- | --- |
| 环境 | 设备、浏览器、分辨率、代码提交与锁定依赖版本 |
| 条件 | 固定输入、初始状态、时间步长、目标与预期 |
| 过程 | 与学习问题相关的坐标、矩阵、状态、事件或统计 |
| 结果 | 实际值或运行表现；失败原因与复现步骤 |
| 解释 | 支持什么结论，哪些条件没有验证 |
| 理解 | 自测答案、Cocos 对照、待补充问题 |

帧率对比使用相同模拟时间、输入和规则；数学结果按所用算法约定浮点容差。视觉截图需要结合过程与交互记录，性能指标需要注明采样方法与单位。

## 三 验证方法

| 内容 | 方法 |
| --- | --- |
| 独立数学与规则 | 用明确输入和预期结果验证；重点覆盖边界与真实失败 |
| 交互与生命周期 | 浏览器检查暂停、重置、切换、尺寸和资源释放 |
| 图形学机制 | 对比控制参数和中间状态，检查画面是否符合计算与规则 |
| 性能 | 同条件采样比较；Draw Call、三角形与资源数量分别记录 |
| 个人理解 | 解释机制图、预测参数变化、回答自测并说明 Cocos 差异 |

单一 FPS、测试数量或资源计数不能替代瓶颈解释。Three.js 的几何体与纹理数量统计也不能直接作为精确 GPU 内存字节数。
