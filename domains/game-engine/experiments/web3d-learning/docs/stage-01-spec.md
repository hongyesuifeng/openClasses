# 阶段 1 空间原理动画规格

[用户反馈] 2026-10-10，学习者明确表示填写与测算不易理解，希望通过简单原理、交互演示或动图理解机制。当前版本采用“看变化 → 看一句解释 → 一键对比”的方式；公式、源码和自测作为按需补充，不要求填写记录或手算。

## 一 演示主题

| 主题 | 原理动画 | 一句话理解 |
| --- | --- | --- |
| 点与箭头 | 位移、整体平移、归一化、朝向比较、叉积方向 | 点是位置，向量是方向与长度 |
| 托盘与小球 | 一起移动、一起旋转、两种变换顺序 | 父变换影响子物体的世界位置 |
| 相机与画面 | 透视／正交对比、镜头前后方 | 世界里的物体如何进入画面 |

入口是开发服务地址的 `?lab=space`。默认自动播放，每个原理有一个切换按钮、暂停／播放和重播按钮。减少动画偏好下默认暂停，可主动播放。主画面使用清晰的 SVG 示意图，Three.js 的 3D 观察只在展开时建立，关闭即释放。

## 二 图示约定

- 点与位移：同一个平面内的两个点，连接箭头的方向从 A 到 B。整体搬动时两个点及箭头一起平移，相对关系不变。
- 归一化：灰色箭头保留原长度，彩色箭头沿相同方向缩短到一个单位。它表达方向，原距离要另外保存；零向量的方向无定义。
- 点积：保持两输入长度不变，黄箭头经过同向、垂直、反向；一般点积的大小还受长度影响，不能直接称为余弦。
- 叉积：平面 X 向右、Y 向上，+Z 朝向观看者；⊙ 表示朝向你，⊗ 表示远离你。交换顺序后反向；图示输入不平行。
- 托盘：橙色点是父物体参考点，小球固定在托盘中。整体平移或绕参考点旋转时，局部位置保持，世界位置变化。
- 顺序：两条路径从同一点出发，比较先绕世界原点转动再向右移动，以及先向右移动再绕世界原点转动。列向量约定下对应 T×R 与 R×T。
- 投影：左图为空间示意，右图为画面。右图的圆心和半径采样来自 inspectProjection；用同深度的圆边缘点投影示意物体大小，不作为真实球体轮廓的精确渲染。
- 透视相机距离在 8 与 6 之间变化；近／远圆中心为 (-1,0,2)、(1,0,-2)，示意半径同为 0.85。正交的上下界固定 ±3，保持同一视口，两者不因距离缩放。
- 前后方动画用于解释可见性；完整裁剪条件、w=0 与 WebGL NDC 约定在可选深入内容说明。它不是逐帧的完整裁剪模拟。

## 三 工程检查

| 检查 | 判定 |
| --- | --- |
| 主学习流程 | 没有 input／textarea、测算、预测填写或答题提交流程 |
| 原理一致性 | 移动两点时相对位移保持；父子相对关系保持；透视近球更大，正交两球等大 |
| 播放 | 暂停、继续和重播有效，切换原理没有重复图示 |
| 解释 | 一键切换后解释同步，尤其透视切正交时不保留旧状态的说明 |
| 可选 3D | 展开仅一个画布；关闭为零，监听与图形资源释放 |
| 图形失败 | WebGL2 不可用只影响可选 3D，SVG 动画和解释仍可观看 |
| 布局与可访问性 | 桌面／窄屏无横向溢出，按钮和图示有名称，减少动画偏好下暂停 |
| 动图 | 来自实际页面图示，GIF 循环播放，中文字清楚，关键帧发生变化 |

数学模块与原有 15 项数值测试保留，自动检查由 Agent 执行。用户观看动画即可进入学习；技能结论仍依据实际理解，不能从动画制作或测试通过推定。
