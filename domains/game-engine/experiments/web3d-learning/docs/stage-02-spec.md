# 阶段 2：场景与运动演示规格

[用户安排] 2026-10-10，继续下一阶段，沿用图文和交互演示，同时增加原理描述。每个问题使用“观察 → 原因 → 公式与变量 → 三步过程 → 条件与游戏例子”，不要求填写、测算或答题。

## 一 演示范围

| 主题 | 演示 | 中间过程 |
| --- | --- | --- |
| 方向与时间 | 数字方向键的斜走、直走、无输入；30／120 步对比 | 输入长度 → 单位方向 → 速度 × 步长 → 位移 |
| 镜头与运动 | 镜头朝向改变输入的世界方向；平滑跟随 | 镜头地面基向量；位置误差与时间相关衰减 |
| 点击与射线 | 中心、右箱、空白及实际画面点击；角色体积对比 | 画面矩形 → NDC → 世界射线 → 按距离排序的命中 |
| 碰撞与响应 | 停止／沿墙滑动；大步／短步穿墙对比 | 首次接触时间 → 接触法线 → 剩余位移分解 |

入口为 `?lab=motion`，阶段 0／1 的导航可直接进入。SVG 显示数学结果，运动与响应在独立 TypeScript 模块中；拾取实际使用 Three.js Raycaster 与 BoxGeometry，渲染示意图不依赖 WebGL。

## 二 单位、模型与边界

- 地面为 XZ 平面，图中 +Z 向上、+X 向右；世界单位不默认等同于米，时间是秒。
- 数字方向输入先归一化；零输入保持不动。模拟摇杆应保留长度小于 1 的力度，本实验没有实现摇杆。
- 恒速位移使用 `speed × dt`，30／120 是模拟更新次数，不是浏览器实测帧率。相等总时间的恒速终点一致，不推出所有物理积分在不同步长下都等效。
- 镜头前方采用图示的地面朝向参数；真实相机需从世界旋转提取水平基向量，处理俯视退化与引擎局部前方约定。
- 指数跟随采用 λ=2／秒。目标在 t=1 从 0 变到 4、t=4 变回 0；30／120 的切换时刻对齐。固定目标误差随总时间等效，变化目标仍有采样误差；不是弹簧、镜头避障或旋转跟随。
- 拾取使用相机位置 (0,2,8)，看向原点，透视 FOV=55°、aspect=1.2。近箱 (0,0,3)、远箱 (0,0,−1)、右箱 (3,0,0)，尺寸均为 (1.5,2.4,1.2)。右图画投影包围矩形，命中检查真正的三角形，因此包围矩形空角不一定命中。
- 画面点击先使用 SVG 逆屏幕变换，得到画面内坐标，再处理偏移与 Y 翻转。射线白点只辅助看路径，真实查询一次完成；不是光传播动画。
- 碰撞使用半宽 0.3 的固定朝向方块和一面静止轴对齐墙，扩大障碍的两个轴，再求中心线段的进入时间。这对本例平移 AABB 等价，不用于精确圆形／胶囊／旋转盒。
- 默认墙为 x∈[0,0.4]、z∈[−3,3]；擦边对比墙为 z∈[−1,1]。滑动不模拟重力、摩擦、反弹或多障碍求解；初始重叠返回明确标志，本例不做脱离重叠的求解。
- 接触轴吸附到边界，防止浮点残差把贴边判成穿入。贴边沿切线或离开允许移动；向墙内移动在 τ=0 接触。

## 三 交互与生命周期

| 操作 | 行为 |
| --- | --- |
| 默认播放 | 6 秒一轮；移动在前 2 秒完成，随后保留结果；镜头和射线按各自时间线播放 |
| 暂停／播放 | 保持当前模拟时间；继续不补算停顿 |
| 逐步看 | 每次前进 0.25 秒并暂停；到循环末尾保持结果 |
| 从头看 | 时间回到 0，保留当前原理、对照状态与播放偏好 |
| 切换主题／原理 | 使用该原理默认对照状态，时间回到 0 |
| 一键对比 | 切换同一问题的模型／输入，时间回到 0，说明同步 |
| 直接点击画面 | 仅拾取原理有效；实际查询射线并显示选中或无命中 |
| 减少动画偏好 | 初始默认暂停；偏好切到 reduce 时暂停，允许用户主动播放 |
| 隐藏／返回 | 停止 rAF，恢复时重新建立时间基准，不累计离开页面的时间 |
| HMR／退出 | 取消 rAF、释放监听；拾取查询的临时几何与材质在 finally 中释放 |

开发环境的 `motion-demo-seek` 事件只用于自动逐帧捕获与检查，生产页面保留用户播放控制。长帧最多推进 0.1 秒，因此播放时间是受控模拟时间，不声称与后台墙钟同步。

## 四 验证要求

| 检查 | 判定 |
| --- | --- |
| 数学 | 无输入不移动；直／斜规范速度一致；30／60／120 的恒速终点；时间平滑与每帧比例对比 |
| 拾取 | 正确处理画面偏移和 Y；近箱先命中、右箱可选、空白正常返回 |
| 碰撞 | 角色前沿接触；滑动保留切向；终点漏检而扫掠命中；贴边、无障碍、初始重叠 |
| 浏览器 | 八个原理、一键切换、直接画面点击、暂停、重播、逐步与导航 |
| 布局 | 桌面与 390×844 页面无横向溢出；窄屏图示局部可横滑，避免缩小中文字；按钮有名称，公式可换行 |
| 动图 | 捕获实际图示，统一调色板，循环与总时长正确，关键帧发生变化 |

实现与运行证据见[阶段 2 讲解记录](stage-02-lab.md)，个人理解另行确认，不因演示制作完成而自动通过。
