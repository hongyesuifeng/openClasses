# 卡牌系统设计文档

## 1. 卡牌分类体系

### 1.1 三大类型

| 类型 | 英文标识 | 说明 | 打出后去向 |
|------|---------|------|-----------|
| 攻击牌 | Attack | 对敌人造成伤害，可能附带额外效果 | 进入弃牌堆（除非注明消耗） |
| 技能牌 | Skill | 提供防御、增益、抽牌等辅助效果 | 进入弃牌堆（除非注明消耗） |
| 能力牌 | Power | 持续生效的被动增益，整场战斗有效 | 消耗（Exhaust） |

### 1.2 稀有度体系

| 稀有度 | 英文标识 | 出现概率 | 颜色标识 | 说明 |
|--------|---------|---------|---------|------|
| 普通 | Common | 65% | 灰色边框 | 基础效果，数值保守 |
| 罕见 | Uncommon | 25% | 蓝色边框 | 有趣的机制或更强数值 |
| 稀有 | Rare | 10% | 金色边框 | 改变战局的强力效果 |

### 1.3 关键词说明

| 关键词 | 英文 | 说明 |
|--------|------|------|
| 消耗 | Exhaust | 打出后从本战斗中移除 |
| 虚无 | Ethereal | 回合结束时若在手牌中则消耗 |
| 固有 | Innate | 每场战斗起始手牌必定包含此牌 |
| 多段 | Multi-hit | 多次触发攻击判定，每次独立计算加成 |
| 易伤 | Vulnerable | 受到攻击伤害 +50% |
| 虚弱 | Frail | 格挡效果 -25% |
| 力量 | Strength | 每点增加攻击伤害 1 点 |
| 敏捷 | Dexterity | 每点增加格挡 1 点 |

## 4. 卡牌升级路径设计

### 4.1 升级规则

- 升级发生在：休息点（Rest Site）、事件奖励
- 每次休息点可选择：升级 1 张牌 **或** 回复 30% HP
- 升级仅针对单张卡牌，不可批量升级
- 同一张牌只能升级一次（Innate 属性牌除外，首版不做特殊规则）

### 4.2 升级方向总结

| 升级类型 | 适用范围 | 典型变化 |
|---------|---------|---------|
| 增伤 | 攻击牌 | 基础伤害 +3~8 |
| 增防 | 技能牌（格挡类） | 基础格挡 +3~5 |
| 增效 | 状态施加类 | 施加层数 +1 |
| 增抽 | 抽牌类 | 抽牌数 +1 |
| 降费 | 极少数卡牌 | 费用 -1（首版不做，保留设计空间） |

### 4.3 升级命名规范

- 升级后的卡牌在名称旁显示 "+" 标记
- 例：重击 → 重击+，伤害从 14 变为 18

## 5. 卡牌数据结构（技术参考）

```gdscript
# CardData.gd — 资源文件结构
class_name CardData
extends Resource

@export var id: String                # 唯一标识，如 "strike"
@export var card_name: String         # 显示名称，如 "打击"
@export var cost: int                 # 能量费用
@export var card_type: String         # "attack" / "skill" / "power"
@export var rarity: String            # "common" / "uncommon" / "rare"
@export var description: String       # 效果文本
@export var upgraded_description: String  # 升级后效果文本
@export var target: String            # "enemy" / "all_enemies" / "self" / "none"
@export var keywords: Array[String]   # ["exhaust", "ethereal", "innate"]
@export var effects: Array[Dictionary]  # 效果列表
@export var upgraded_cost: int        # 升级后费用（-1 表示不变）
@export var upgraded_effects: Array[Dictionary]  # 升级后效果
@export var is_innate: bool = false   # 固有属性
@export var is_ethereal: bool = false # 虚无属性
@export var exhausts: bool = false    # 消耗属性
```

### effects 字典结构示例

```gdscript
# 单个 effect 字典
{
    "type": "damage",        # damage / block / apply_status / draw / heal / gain_strength / gain_dexterity
    "value": 6,              # 基础数值
    "status": "",            # 状态名（仅 apply_status 类型）
    "status_stacks": 0,      # 状态层数（仅 apply_status 类型）
    "hits": 1,               # 命中次数（多段攻击）
    "target_override": ""    # 覆盖目标（如 all_enemies）
}
```

## 6. 卡牌池与获取概率

### 6.1 战斗奖励卡牌

| 来源 | 普通出现率 | 罕见出现率 | 稀有出现率 |
|------|-----------|-----------|-----------|
| 普通战斗 | 70% | 25% | 5% |
| 精英战斗 | 50% | 35% | 15% |
| Boss 战 | 30% | 40% | 30% |

战斗胜利后展示 3 张卡牌，玩家选择 1 张或跳过。

### 6.2 商店卡牌

- 商店展示 5 张卡牌，稀有度随机但保证至少 1 张罕见
- 定价见奖励与经济系统文档

### 6.3 首版完整卡池统计

| 稀有度 | 攻击牌 | 技能牌 | 能力牌 | 合计 |
|--------|--------|--------|--------|------|
| 普通 | 5 | 7 | 0 | 12 |
| 罕见 | 4 | 4 | 2 | 10 |
| 稀有 | 3 | 2 | 1 | 6 |
| **合计** | **12** | **13** | **3** | **28** |

加上初始牌组的 5 打击 + 4 防御 = 基础牌 2 种 + 扩展池 28 种 = **共计 30 种不同卡牌**，符合 20~30 张的设计目标。
