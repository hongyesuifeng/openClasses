# SlayDemo 资源显示适配优化说明 v2

本包基于录屏逐帧检查后优化，重点不是重新生成精修插画，而是解决运行时 UI/交互显示问题。

## 本次重点修复
1. 战斗背景：去除左右两侧巨大橙色前景块，避免遮挡玩家区与结束回合按钮；底部加暗处理，降低手牌区域干扰。
2. 地图/奖励背景：降低羊皮纸大面板亮度、噪点和竖线强度，避免抢节点和卡牌的视觉层级。
3. 卡牌底框：重新整理成本区、图标区、描述区，减少装饰压到代码叠加文字的问题。
4. 卡牌/意图/HUD 图标：提高图形填充比例，适配 32/36/64 小尺寸显示。
5. 角色与敌人：统一透明边距和落脚基线，减少过小、漂浮、贴边的问题。

## 建议 Godot 显示设置
- 所有 TextureRect 图标：stretch_mode = keep_aspect_centered；expand_mode = ignore_size 或 fit_width/height 按当前容器决定。
- 地图节点图标：建议 32x32 容器内显示 24-28px 视觉主体，不要再叠 emoji。
- 状态图标：建议容器 32x32，图标 28x28，叠层数字放右下角。
- 遗物图标：建议容器 48x48 或 56x56，按钮 hover 只改边框，不要缩放图标本身。
- 手牌卡牌：当前代码若按 120x166 左右显示，卡牌文字会天然偏小；建议后续代码层把手牌卡宽提升到 132-144，奖励选择可保持 120-130。
