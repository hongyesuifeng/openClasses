# slayDemo 学习资料维护规则

本目录保留玩法设计、技术原理、实验结论与历史复盘。实际游戏项目已迁移至独立 cocosProjects 仓库，工程归属和学习入口见 `README.md`。

- 维护重点是解释原理、整理验证依据和总结可迁移经验。
- 文档中的 `client/slay-demo/`、`res://` 和 Godot 测试命令属于历史记录；旧运行工程已移出学习目录。
- 文档维护应检查链接、事实和资料分类。需要新实验时，按具体学习问题建立最小范围，并遵循实验目录自身的运行和验证规则。
- 实际游戏功能开发、资源维护和整合在对应游戏项目中进行；切换到工作区之外的项目须遵守用户的工作区边界要求。
