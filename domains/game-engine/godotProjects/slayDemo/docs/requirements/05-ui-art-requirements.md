# 05. UI 与美术需求

> 面向: 美术、UI、开发  
> 状态: 首版需求基准

## 1. 总原则

UI 和美术首要任务是帮助玩家判断局面。

> 信息可读性优先于装饰复杂度。

首版可以使用占位资源，但不能牺牲关键信息辨识。

## 2. 战斗界面必须显示

玩家侧:

- 血量
- 格挡
- 能量
- 手牌
- 抽牌堆数量
- 弃牌堆数量
- 当前状态

敌人侧:

- 血量
- 格挡
- 意图
- 力量
- 虚弱
- 脆弱
- 中毒或其他状态

卡牌侧:

- 名称
- 费用
- 类型
- 稀有度
- 效果描述
- 关键词
- 是否消耗
- 目标类型

Boss 战:

- Boss 意图
- 小怪意图
- 小怪数量
- 半血阶段变化

## 3. 关键词与颜色建议

```text
力量: 红色
格挡: 蓝色
抽牌: 黄色
消耗: 紫色
虚弱 / 脆弱 / 中毒: 负面色
AOE: 图标或特殊标记
状态牌 / 废牌: 灰色或污染感
```

注意:

- 颜色不能作为唯一信息来源，最好配图标或关键词。
- 负面状态需要 hover 或点击说明。

## 4. 卡牌视觉需求

卡牌模板必须支持:

- 费用区域
- 名称区域
- 插画区域
- 类型 / 稀有度
- 效果文本
- 关键词高亮

三流派视觉倾向:

抽牌循环流:

- 速度、流动、连携感
- 可用线条、残影、轻盈元素

力量多段流:

- 红色、冲击、武器、多段斩击
- 强调攻击次数和力量成长

防御反击流:

- 盾牌、壁垒、金属、反击光效
- 强调稳固和蓄力

## 5. 敌人视觉需求

普通怪:

- 地穴爬虫: 低威胁教学怪
- 黏液怪: 黏稠、污染、软体感
- 迅捷刺客: 快速、轻甲、短刃
- 狂热信徒: 邪教、仪式、成长感

精英怪:

- 堕落骑士: 重甲、腐化、压迫感
- 地图和战斗中都要明显区别普通怪

Boss:

- 深渊领主: 大体型、召唤者、深渊主题
- 深渊仆从: 小型召唤物，和 Boss 同源但层级更低
- 半血阶段需要明显变化

## 6. 敌人意图图标需求

至少需要:

- 单次攻击
- 多段攻击
- 防御
- Buff
- Debuff
- 召唤
- 未知 / 特殊

意图图标必须在不读文字的情况下大致可理解。

## 7. 地图 UI 需求

节点图标:

- 普通怪
- 精英
- Boss
- 商店
- 事件
- 宝箱
- 休息点

路线视觉:

- 已走过路径
- 可选路径
- 不可选路径
- 精英路线需要更高风险感
- Boss 节点必须是终点视觉焦点

## 8. 商店 UI 需求

必须显示:

- 当前金币
- 商品价格
- 卡牌商品
- 药水商品
- 遗物或特殊服务
- 删牌服务

交互要求:

- 买不起的商品置灰。
- 购买后有明确反馈。
- 删牌时能看到当前牌组。

## 9. 奖励 UI 需求

奖励三选一必须显示:

- 三张卡牌
- 跳过按钮
- 当前牌组查看入口

可以显示牌组统计:

```text
攻击牌数量
技能牌数量
能力牌数量
抽牌相关数量
力量相关数量
格挡相关数量
AOE 数量
```

不要显示:

- 推荐选牌
- 自动流派判断
- 最优解提示

## 10. 验收标准

- 玩家能在 3 秒内识别敌人下回合是否攻击。
- 玩家能在 3 秒内识别卡牌费用和主要效果。
- 玩家能区分普通怪、精英和 Boss。
- 玩家能区分三类地图路线风险。
- Boss 战中 Boss 和小怪不会视觉混淆。
- 奖励界面能支持玩家查看当前牌组。
