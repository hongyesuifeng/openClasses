本目录不是学习笔记，而是实施输入。后续开发、配置表、美术资源、UI 设计应优先以这些需求为准，再回查 `docs/design/`、`docs/tech/` 和 `docs/art/`。

## 首版定案摘要

- 角色: 1 个战士型角色
- Act: 1 个 15 层 Act
- 流派: 抽牌循环流、力量多段流、防御反击流
- 卡牌: 24-30 张
- 敌人: 4 个普通怪左右、1 个精英怪、1 个 Boss
- 地图: 普通怪、事件、商店、精英、宝箱、休息点、Boss
- 遗物: 5 个以内
- 药水: 4 个以内
- UI: 支持玩家判断，不替玩家推荐最优解

## 实施原则

1. 小而闭环优先，不追求内容量。
2. 每个系统都必须服务核心链路: 流派成立 -> 敌人测试 -> 地图选择 -> 奖励修正 -> Boss 验证。
3. 技术实现优先数据驱动，避免把卡牌和敌人行为写死。
4. 美术表现优先可读性，视觉风格服务信息判断。
5. 首版允许占位美术，但不允许关键信息不可读。
