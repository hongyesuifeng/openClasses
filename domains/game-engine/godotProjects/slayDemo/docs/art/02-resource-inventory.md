# 美术资源清单与优先级

> 适用项目：SlayDemo — 类《杀戮尖塔》卡牌 Roguelike Demo
> 文档版本：v1.0

---

## 优先级定义

| 等级 | 含义 | 标准 |
|------|------|------|
| **P0** | 必须 | 没有它游戏无法运行或无法理解 |
| **P1** | 重要 | 没有它体验明显下降，但功能可用 |
| **P2** | 加分项 | 锦上添花，时间允许再做 |

## 八、工作量估算

### 总览

| 类别 | P0 资源数 | P1 资源数 | P2 资源数 | 预估总工时 |
|------|-----------|-----------|-----------|------------|
| 卡牌 | 5 | 2 | 1 | 8h |
| 角色 | 5 | 14 | 0 | 16h（含敌人） |
| UI | 15 | 10 | 3 | 20h |
| 背景 | 2 | 3 | 0 | 6h |
| 特效 | 5 | 6 | 1 | 8h |
| 图标 | 10 | 7 | 2 | 6h |
| 字体 | 2 | 1 | 0 | 1h（选型+测试） |
| **合计** | **44** | **43** | **7** | **~65h** |

### 优化说明

- 如果使用免费资源包替代自绘，工时可降至 **20-30h**（主要是整合和调整）
- 如果采用"最小替代方案"（Tween 替代帧动画、纯代码替代特效），P0 工时约 **15-20h**
- 建议美术总投入控制在 **30h 以内**

## 九、资源文件格式规范

| 类型 | 格式 | 色彩空间 | 说明 |
|------|------|----------|------|
| 2D 精灵图 | PNG | sRGB, 无压缩 | 透明背景 |
| 背景 | PNG 或 JPG | sRGB | JPG 用于大背景减少体积 |
| UI 九宫格 | PNG | sRGB | 四角不拉伸，四边单轴拉伸 |
| 粒子纹理 | PNG | sRGB | 小尺寸，白色或灰色底便于 tint |
| 矢量图标 | SVG（源文件） | — | 导出为 PNG 使用 |
| 字体 | TTF 或 OTF | — | 确认授权允许嵌入游戏 |

## 十、资源命名规范

```
{类别}_{子类}_{名称}_{状态/变体}

示例：
card_template_common.png
card_template_rare.png
card_icon_slash.png
enemy_slime_idle_01.png
enemy_slime_atk_01.png
ui_btn_normal.png
ui_btn_hover.png
bg_battle_dungeon.png
icon_status_poison.png
vfx_particle_spark.png
```

### 类别前缀

| 前缀 | 含义 |
|------|------|
| `card_` | 卡牌相关 |
| `enemy_` | 敌人相关 |
| `player_` | 玩家角色相关 |
| `ui_` | UI 元素 |
| `bg_` | 背景图 |
| `icon_` | 图标 |
| `vfx_` | 特效资源 |
| `font_` | 字体文件 |
| `audio_` | 音频（配合音频规划） |
