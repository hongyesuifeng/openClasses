## 一、玩家角色视觉设计

### 1.1 角色定位

- 类型：战士（Warrior）
- 关键词：坚毅、沉稳、伤痕累累、孤独旅者
- 视觉原型：穿着简朴铠甲的流浪战士，不是华丽的骑士

### 1.2 视觉设计方向

**推荐方案：剪影 + 色块法**

不需要精细的角色绘制。用高对比度的剪影轮廓 + 少量色彩细节即可在卡牌游戏的小尺寸显示中保持辨识度。

```
战士角色特征：
- 粗壮的方形轮廓（区别于瘦长的法师）
- 单手持剑或双手大剑的轮廓
- 肩甲是主要辨识元素（宽肩）
- 头盔面罩（遮住面部，增加神秘感）
- 暗红色披风（少量颜色点缀）
```

### 1.3 配色方案

| 部位 | 颜色 | 说明 |
|------|------|------|
| 铠甲 | `#4a4a5a` | 深灰铁色 |
| 剑刃 | `#c0c0d0` | 银白金属 |
| 披风 | `#8b2020` | 暗红，标志性颜色 |
| 头盔 | `#5a5a6a` | 略亮于铠甲 |
| 皮肤（如露出） | `#c8a882` | 暖肤色 |

### 1.4 角色尺寸规范

| 场景 | 显示尺寸 | 说明 |
|------|----------|------|
| 战斗场景 | 128x128 px | 屏幕左下方 |
| 肖像图标（HP条旁） | 64x64 px | 头部特写 |
| 卡牌中（如有） | 32x32 px | 极小图标 |

## 二、敌人视觉设计

### 2.1 敌人一览

本项目设计 8 个敌人，按难度分三档。

#### 普通敌人（前3层遭遇）

**E1：史莱姆（Slime）**

- 视觉特点：圆胖的果冻体，半透明感，一高一低两只眼睛，下垂的嘴巴
- 配色：酸性绿 `#66cc44`，体内有深色气泡
- 尺寸：96x96 px
- 辨识度要素：经典果冻怪造型，玩家一眼就能认出

**E2：骷髅兵（Skeleton Soldier）**

- 视觉特点：直立骨架，持盾和锈剑，头盔歪斜，眼窝中微光
- 配色：骨白 `#d4c8a0`，锈铁 `#6a5a4a`，眼窝微光 `#44ff44`
- 尺寸：96x128 px（偏高瘦）
- 辨识度要素：歪头盔 + 眼窝绿光

**E3：毒蘑菇（Poison Shroom）**

- 视觉特点：巨大蘑菇伞盖带紫色斑点，短粗菌柄，两个小黑眼睛，顶部冒毒泡
- 配色：深紫 `#6a2a8a`，斑点 `#aa44cc`，菌柄 `#b8a878`
- 尺寸：80x96 px
- 辨识度要素：紫色斑点 + 冒泡泡

#### 中级敌人（中后层遭遇）

**E4：蝙蝠群（Bat Swarm）**

- 视觉特点：3-4只蝙蝠纠缠的群体轮廓，红色眼睛群，翅膀散乱
- 配色：深灰 `#3a3a4a`，眼睛 `#ff4444`，翅膀内侧 `#5a2a3a`
- 尺寸：96x64 px（偏扁宽）
- 辨识度要素：多点红眼 + 不规则轮廓

**E5：石像鬼（Gargoyle）**

- 视觉特点：蹲伏姿态的石质生物，大翅膀收拢，爪牙锋利，石质纹理
- 配色：灰石 `#7a7a8a`，眼睛 `#ff6622`（熔岩色）
- 尺寸：128x128 px
- 辨识度要素：石质纹理 + 熔岩色眼

**E6：暗影法师（Shadow Mage）**

- 视觉特点：悬浮的暗色斗篷，看不清面部只有紫色幽光，双手释放暗能量
- 配色：深紫斗篷 `#2a1a3a`，能量光 `#aa66ff`，内衬 `#4a2a5a`
- 尺寸：96x128 px
- 辨识度要素：悬浮 + 紫色幽光 + 无面

#### 精英/Boss

**E7：腐化骑士（Corrupted Knight）— 精英/小Boss**

- 视觉特点：比玩家角色大一圈的黑色铠甲骑士，裂缝中透出红色能量，巨剑上有裂纹
- 配色：黑铁 `#2a2a3a`，裂纹红光 `#ff2222`，锈迹 `#5a3a2a`
- 尺寸：160x160 px
- 辨识度要素：红色裂纹 + 体型明显大于普通敌人
- 与普通敌人的区别：体型 1.5x，有独特的发光裂纹效果

**E8：远古巨龙（Ancient Dragon）— 最终Boss**

- 视觉特点：巨大的龙形剪影，仅露出上半身（从黑暗中探出），火焰从嘴角和鳞片缝隙中渗出
- 配色：黑鳞 `#1a1a2a`，火焰 `#ff6622`，眼睛 `#ffcc00`
- 尺寸：256x256 px
- 辨识度要素：远超其他敌人的体型 + 火焰效果 + 屏幕占比大
- 与其他敌人的区别：占据屏幕右半部分的 1/3 以上

### 2.2 敌人视觉差异层级

```
体型递增：史莱姆 < 蝙蝠群 < 骷髅 < 蘑菇 < 法师 < 石像鬼 < 腐化骑士 < 巨龙
威胁感递增：通过颜色（绿->紫->红）、体型、发光效果递增
```

## 三、角色动画需求

### 3.1 最小帧数方案

| 动画 | 最少帧数 | 说明 |
|------|----------|------|
| Idle（待机） | 4 帧 | 呼吸/微微晃动循环 |
| Attack（攻击） | 3 帧 | 蓄力-挥出-收回 |
| Hit（受伤） | 1 帧 + 代码闪白 | 受击姿势 + 白色闪烁 |
| Death（死亡） | 3 帧 | 后仰-倒下-消散 |
| Block（格挡） | 2 帧 | 举盾-保持 |

### 3.2 动画帧规格

| 角色 | 精灵图尺寸 | 帧尺寸 | 总帧数 |
|------|-----------|--------|--------|
| 玩家 | 512x128（4列x1行）| 128x128 | idle:4 |
| 玩家攻击 | 384x128（3列x1行）| 128x128 | atk:3 |
| 史莱姆 | 384x96 | 96x96 | idle:4 |
| 骷髅 | 384x128 | 96x128 | idle:4 |

### 3.3 无帧动画替代方案（推荐起步方案）

在项目早期阶段，完全不需要精灵图帧动画。用以下方案替代：

```
Idle:    静态图 + Tween 上下浮动（幅度3px，周期1.6s）
Attack:  静态图 + Tween 向目标方向位移50px后弹回
Hit:     静态图 + modulate 闪白 0.1s + 微微后退
Block:   静态图 + 微微缩小表示防御姿态
Death:   静态图 + Tween 缩放至0 + 淡出 + 粒子散发
```

这个方案只需要每个角色**1张静态图**，通过代码实现所有动画效果。

### 3.4 敌人动画实现优先级

| 敌人 | Idle | Attack | Hit | Death | 优先级 |
|------|------|--------|-----|-------|--------|
| 史莱姆 | Tween浮动 | Tween位移 | 闪白 | 缩放淡出 | P0 |
| 骷髅兵 | Tween浮动 | Tween位移 | 闪白 | 缩放淡出 | P0 |
| 腐化骑士 | Tween浮动 | Tween位移 | 闪白 | 缩放淡出 | P0 |
| 远古巨龙 | Tween呼吸 | Tween位移 | 闪白 | 缩放淡出+粒子 | P0 |
| 其余敌人 | Tween浮动 | Tween位移 | 闪白 | 缩放淡出 | P1 |

## 四、自制角色方案

### 4.1 工具推荐

| 工具 | 价格 | 说明 |
|------|------|------|
| **Piskel** (piskelapp.com) | 免费 | 在线像素画工具，支持动画预览 |
| **Aseprite** | $20 | 专业像素画工具，强烈推荐 |
| **GIMP** | 免费 | 通用图片编辑 |
| **Figma** | 免费 | 矢量/扁平风格角色设计 |

### 4.2 极简角色制作流程

以史莱姆为例（Piskel 或 Aseprite）：

```
Step 1: 创建 96x96 画布

Step 2: 用椭圆工具画身体
        - 选择酸性绿色
        - 画一个宽椭圆（约占画布 60%）

Step 3: 添加眼睛
        - 两个白色圆形（直径约12px）
        - 两个黑色瞳孔（直径约6px）
        - 一高一低放置，增加可爱感

Step 4: 添加嘴巴
        - 一条弧线，微微下垂

Step 5: 添加高光
        - 左上方一个白色半椭圆（高光反射）

Step 6: 添加阴影
        - 底部加深颜色

Step 7: 导出 PNG
```

单个角色在 15-30 分钟内可以完成（扁平/简笔画风格）。

### 4.3 模板化角色变体

很多敌人可以通过**基础模板 + 颜色变化**来批量生成：

```
史莱姆模板 -> 绿色(普通) / 红色(火焰) / 蓝色(冰霜)
骷髅模板 -> 白骨(普通) / 黑骨(暗影) / 金骨(精英)
```

在 Godot 中可以用 `modulate` 属性实现颜色变化，只需要 1 张基础图。

```gdscript
# 创建颜色变体
var slime_green = preload("res://assets/enemies/slime_base.png")
var slime_red = slime_green  # 同一张图
var red_slime = TextureRect.new()
red_slime.texture = slime_red
red_slime.modulate = Color(1.2, 0.6, 0.6)  # 偏红色调
```

## 五、敌人意图视觉

### 5.1 意图图标设计

杀戮尖塔的核心机制之一是敌人意图显示。每个意图需要对应的图标：

| 意图类型 | 图标设计 | 颜色 |
|----------|----------|------|
| 攻击 | 剑/爪痕图标 | `#ff4444`（红色） |
| 防御 | 盾牌图标 | `#4488ff`（蓝色） |
| 增益 | 向上箭头图标 | `#44cc88`（绿色） |
| 特殊 | 问号/感叹号 | `#ffcc00`（金色） |

### 5.2 意图显示位置

```
+-------------------------------+
|     [意图图标] [伤害数字]       |
|         ↑                      |
|       敌人 sprite              |
|                                |
+-------------------------------+

意图图标：位于敌人头顶上方 20px
伤害数字：意图图标右侧
背景：半透明暗色圆形底板
```

### 5.3 意图图标资源

建议直接从 Game-Icons.net 获取：

- 攻击意图：搜索 "sword" 或 "claw"
- 防御意图：搜索 "shield"
- 增益意图：搜索 "arrow up" 或 "buff"
- 特殊意图：搜索 "exclamation" 或 "question"
