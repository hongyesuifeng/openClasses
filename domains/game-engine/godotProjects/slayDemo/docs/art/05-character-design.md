## 一、玩家角色视觉设计

### 1.1 角色定位

- 类型：魔法少女（Magical Girl）
- 关键词：活泼、可爱、勇敢、萌系冒险者
- 视觉原型：穿着魔法制服、手持卡牌契约册的Q版魔法少女

### 1.2 视觉设计方向

**推荐方案：Q版卡通圆润风格**

采用2~2.5头身Q版比例，大头小身，圆润线条。通过简洁的色块平涂和特征性服饰元素在小尺寸下保持高辨识度。

```
魔法少女角色特征：
- 2~2.5头身Q版大头比例
- 魔法制服（蓬蓬裙或少女战斗装）
- 手持卡牌契约册（主要辨识元素）
- 双马尾或短发（鲜明发色）
- 星星或魔法符文装饰
```

| 制服主色 | `#ce93d8` | 中紫魔法制服 |

## 二、敌人视觉设计

### 2.1 敌人一览

本项目设计 12 个敌人，按难度分三档。

#### 普通敌人（前3层遭遇）

**E1：布丁怪（Pudding Slime）**

- 视觉特点：圆滚滚的奶油布丁形体，闪亮果冻质感，大眼睛配腮红，顶部有樱桃装饰
- 配色：奶油黄 `#ffd54f`，腮红 `#f8bbd0`，樱桃红 `#ef5350`
- 尺寸：96x96 px
- 辨识度要素：Q版圆胖、顶部樱桃、大眼腮红

**E2：棉花甲士（Cotton Knight）**

- 视觉特点：穿着棉花糖质感盔甲的小矮人，盔甲上有粉色星星图案，持小圆盾
- 配色：棉白 `#fce4ec`，粉星 `#f8bbd0`，盾牌蓝 `#42a5f5`
- 尺寸：96x128 px（偏高）
- 辨识度要素：棉花糖盔甲纹理、星星图案

**E3：暴躁布丁（Angry Pudding）**

- 视觉特点：皱着眉头的愤怒布丁，比布丁怪颜色更深、眉毛更粗，身上有裂纹冒出泡泡
- 配色：深布丁橙 `#ffa726`，怒眉 `#3e2a5a`，泡泡紫 `#ce93d8`
- 尺寸：80x96 px
- 辨识度要素：浓眉愤怒表情 + 泡泡

#### 中级敌人（中后层遭遇）

**E4：泡泡蝙蝠（Bubble Bat）**

- 视觉特点：2-3只粉紫色蝙蝠，翅膀透明带泡泡纹理，眼睛是大大的星形
- 配色：淡紫 `#ce93d8`，翅膀 `#e8eaf6`，星形眼 `#ffd54f`
- 尺寸：96x64 px（偏扁宽）
- 辨识度要素：星形眼 + 透明泡泡翅膀

**E5：布偶守卫（Plush Guard）**

- 视觉特点：圆乎乎的布偶熊形状守卫，身上有缝线纹理，眼睛是纽扣，手持棉花棒
- 配色：暖棕 `#bcaaa4`，纽扣眼 `#3e2a5a`，棒头粉 `#f8bbd0`
- 尺寸：128x128 px
- 辨识度要素：布偶缝线纹理 + 纽扣眼

**E6：星座魔女（Zodiac Witch）**

- 视觉特点：悬浮的Q版小魔女，斗篷上有星座图案，手持魔法水晶球，头顶有星星光圈
- 配色：深紫斗篷 `#7c5f9a`，星星 `#ffd54f`，水晶球 `#80deea`
- 尺寸：96x128 px
- 辨识度要素：悬浮 + 星座图案斗篷 + 水晶球

#### 精英/Boss

**E7：甜心骑士长（Sweet Knight Commander）— 精英/小Boss**

- 视觉特点：比普通敌人大一圈的Q版骑士，盔甲是粉红糖果质感，巨剑上有爱心纹路，眼睛闪亮
- 配色：糖果粉甲 `#f8bbd0`，爱心红 `#ef5350`，金色剑柄 `#ffd54f`
- 尺寸：160x160 px
- 辨识度要素：爱心纹路巨剑 + 体型明显大于普通敌人
- 与普通敌人的区别：体型 1.5x，有独特的爱心发光效果

**E8：星愿守护龙（Star Wish Dragon）— 最终Boss**

- 视觉特点：Q版巨大龙形，仅露出上半身（从云朵中探出），全身覆盖彩虹鳞片，从嘴角喷出星星和彩色光束
- 配色：彩虹鳞片渐变（粉→蓝→紫），星星 `#ffd54f`，眼睛 `#80deea`
- 尺寸：256x256 px
- 辨识度要素：远超其他敌人的体型 + 彩虹鳞片 + 星星光束
- 与其他敌人的区别：占据屏幕右半部分的 1/3 以上

**E9：暴走熊（Rampage Bear）**

- 视觉特点：蓬松大熊，怒目圆睁，蜂蜜滴落全身，手持蜂蜜罐当武器
- 配色：蜂蜜棕 `#ffa726`，蜂蜜黄 `#ffd54f`，眼红 `#ef5350`
- 尺寸：128x128 px
- 辨识度要素：蜂蜜滴落效果 + 怒目大熊

**E10：布丁女王（Pudding Queen）**

- 视觉特点：超大号布丁，戴着奶油皇冠，脸颊红晕，裙摆状底座
- 配色：奶油白 `#fce4ec`，皇冠金 `#ffd54f`，腮红 `#f48fb1`
- 尺寸：160x160 px
- 辨识度要素：奶油皇冠 + 裙摆底座

**E11：星座魔女精英版（Zodiac Witch Elite）**

- 与E6同形，体型更大，斗篷更华丽，手持两个水晶球，星座图案发光
- 尺寸：128x160 px

**E12：狂暴糖果熊（Berserk Candy Bear）**

- 视觉特点：全身镶嵌糖果结晶的暴怒大熊，糖果发光，四肢粗壮
- 配色：糖果粉 `#f8bbd0`，结晶蓝 `#42a5f5`，眼红 `#ef5350`
- 尺寸：160x160 px

### 2.2 敌人视觉差异层级

```
体型递增：布丁怪 < 泡泡蝙蝠 < 棉花甲士 < 暴躁布丁 < 星座魔女 < 布偶守卫 < 甜心骑士长 < 星愿守护龙
威胁感递增：通过颜色（暖黄->粉紫->红）、体型、发光效果递增
```

## 三、角色动画需求

### 3.1 最小帧数方案

| 动画 | 最少帧数 | 说明 |
|------|----------|------|
| Idle（待机） | 4 帧 | 呼吸/微微晃动循环 |
| Attack（攻击） | 3 帧 | 蓄力-挥出-收回 |
| Hit（受伤） | 1 帧 + 代码闪白 | 受击姿势 + 白色闪烁 |
| Death（死亡） | 3 帧 | 后仰-倒下-消散 |
| Block（格挡） | 2 帧 | 举盾-保持 |

### 3.2 动画帧规格

| 角色 | 精灵图尺寸 | 帧尺寸 | 总帧数 |
|------|-----------|--------|--------|
| 玩家 | 512x128（4列x1行）| 128x128 | idle:4 |
| 玩家攻击 | 384x128（3列x1行）| 128x128 | atk:3 |
| 布丁怪 | 384x96 | 96x96 | idle:4 |
| 棉花甲士 | 384x128 | 96x128 | idle:4 |

### 3.3 无帧动画替代方案（推荐起步方案）

在项目早期阶段，完全不需要精灵图帧动画。用以下方案替代：

```
Idle:    静态图 + Tween 上下浮动（幅度3px，周期1.6s）
Attack:  静态图 + Tween 向目标方向位移50px后弹回
Hit:     静态图 + modulate 闪白 0.1s + 微微后退
Block:   静态图 + 微微缩小表示防御姿态
Death:   静态图 + Tween 缩放至0 + 淡出 + 粒子散发
```

这个方案只需要每个角色**1张静态图**，通过代码实现所有动画效果。

### 3.4 敌人动画实现优先级

| 敌人 | Idle | Attack | Hit | Death | 优先级 |
|------|------|--------|-----|-------|--------|
| 布丁怪 | Tween浮动 | Tween位移 | 闪白 | 缩放淡出 | P0 |
| 棉花甲士 | Tween浮动 | Tween位移 | 闪白 | 缩放淡出 | P0 |
| 甜心骑士长 | Tween浮动 | Tween位移 | 闪白 | 缩放淡出 | P0 |
| 星愿守护龙 | Tween呼吸 | Tween位移 | 闪白 | 缩放淡出+粒子 | P0 |
| 其余敌人 | Tween浮动 | Tween位移 | 闪白 | 缩放淡出 | P1 |

## 四、自制角色方案

### 4.1 工具推荐

| 工具 | 价格 | 说明 |
|------|------|------|
| **Piskel** (piskelapp.com) | 免费 | 在线像素画工具，支持动画预览 |
| **Aseprite** | $20 | 专业像素画工具，强烈推荐 |
| **GIMP** | 免费 | 通用图片编辑 |
| **Figma** | 免费 | 矢量/扁平风格角色设计 |

### 4.2 极简角色制作流程

以布丁怪为例（Piskel 或 Aseprite）：

```
Step 1: 创建 96x96 画布

Step 2: 用椭圆工具画身体
        - 选择奶油黄色
        - 画一个宽椭圆（约占画布 60%）

Step 3: 添加眼睛
        - 两个白色大圆形（直径约14px）
        - 两个黑色瞳孔（直径约7px）
        - 加上粉色腮红（椭圆色块）

Step 4: 添加嘴巴
        - 一条弧线，微微上扬（开心表情）

Step 5: 添加顶部装饰
        - 画一颗小樱桃（圆形+茎）

Step 6: 添加高光
        - 左上方一个白色半椭圆（高光反射）

Step 7: 导出 PNG
```

单个角色在 15-30 分钟内可以完成（扁平/简笔画风格）。

### 4.3 模板化角色变体

很多敌人可以通过**基础模板 + 颜色变化**来批量生成：

```
布丁怪模板 -> 奶油黄(普通) / 橙色(暴躁) / 粉色(精英)
棉花甲士模板 -> 白色(普通) / 蓝色(精英) / 金色(Boss变体)
```

在 Godot 中可以用 `modulate` 属性实现颜色变化，只需要 1 张基础图。

```gdscript
# 创建颜色变体
var pudding_base = preload("res://assets/enemies/pudding_base.png")
var pudding_angry = pudding_base  # 同一张图
var angry_pudding = TextureRect.new()
angry_pudding.texture = pudding_angry
angry_pudding.modulate = Color(1.2, 0.8, 0.4)  # 偏橙色调
```

## 五、敌人意图视觉

### 5.1 意图图标设计

杀戮尖塔的核心机制之一是敌人意图显示。每个意图需要对应的图标：

| 意图类型 | 图标设计 | 颜色 |
|----------|----------|------|
| 攻击 | 剑/爪痕图标 | `#ef5350`（粉红红） |
| 防御 | 盾牌图标 | `#42a5f5`（天蓝） |
| 增益 | 向上箭头图标 | `#66bb6a`（嫩绿） |
| 特殊 | 问号/感叹号 | `#ffd54f`（暖黄） |

### 5.2 意图显示位置

```
+-------------------------------+
|     [意图图标] [伤害数字]       |
|         ↑                      |
|       敌人 sprite              |
|                                |
+-------------------------------+

意图图标：位于敌人头顶上方 20px
伤害数字：意图图标右侧
背景：半透明暗色圆形底板
```

### 5.3 意图图标资源

建议直接从 Game-Icons.net 获取：

- 攻击意图：搜索 "sword" 或 "claw"
- 防御意图：搜索 "shield"
- 增益意图：搜索 "arrow up" 或 "buff"
- 特殊意图：搜索 "exclamation" 或 "question"
