### 2.2 卡牌中心图案方案

**核心思路**：不做手绘插画，用**大号图标**替代卡牌插画区域。

| 方案 | 来源 | 优势 | 操作方式 |
|------|------|------|----------|
| **Game-Icons.net** | https://game-icons.net | 5000+ 图标，风格统一，支持自定义前景/背景色 | 网页上选择图标 -> 自定义颜色 -> 下载 SVG/PNG |
| **Kenney Game Icons** | kenney.nl | 风格一致，PNG 格式 | 直接下载使用 |
| **Noun Project** | thenounproject.com | 海量图标，部分免费 | 搜索 RPG/武器/魔法关键词 |
| **FontAwesome** | fontawesome.com | 字体图标，Godot 中可当字体使用 | 下载免费版 TTF |

**Game-Icons.net 使用流程（重点推荐）**：

1. 访问 https://game-icons.net
2. 浏览或搜索关键词（如 "sword", "shield", "fire", "skull"）
3. 点击图标进入详情页
4. 在右侧面板设置：
   - 前景色：白色（`#ffffff`）
   - 背景色：按卡牌类型对应色（攻击=红, 防御=蓝, 技能=绿）
   - 尺寸：128x128 或 256x256
5. 下载 PNG 格式
6. 放入项目的 `assets/card/icons/` 目录

> 这个方案可以在 **2-3 小时内**为所有 25-30 张卡牌生成视觉上统一、风格一致的卡面图标。

### 3.2 无合适免费资源时的自制方案

如果找不到匹配的免费角色精灵图，推荐以下**零绘画基础方案**：

#### 方案 A：几何组合法

```
使用基础形状组合 Q版角色：

布丁怪 = 椭圆形身体 + 两个白色大圆形(眼睛) + 腮红圆形 + 爱心嘴巴
棉花甲士 = 圆形(头) + 棉花团(身体) + 两个黑色大圆(眼睛) + 圆盾
蘑菇 = 半圆(伞盖，粉色点点) + 圆柄 + 两个白圆(眼睛)
```

工具：Aseprite（付费但便宜，$20）或 Piskel（免费在线工具 https://www.piskelapp.com）

#### 方案 B：AI 辅助生成

| 工具 | 说明 | 注意事项 |
|------|------|----------|
| **Bing Image Creator** | 免费，可生成 Q 版/Chibi 角色 | 需要手动清理背景，风格可能不一致 |
| **Leonardo.ai** | 免费额度，支持生成游戏素材 | 可指定 "chibi sprite sheet" 或 "kawaii monster" 风格 |
| **ComfyUI + Stable Diffusion** | 本地免费，完全控制 | 需要一定技术门槛，但生成 Q 版角色效果好；推荐使用 Anything V5 等动漫风 LoRA |

> **AI 生成的注意事项**：AI 生成的图像需要二次加工（统一风格、裁切、调整尺寸）。不要直接拿来用，会显得不统一。

#### 方案 C：纯 Tween 动画法（终极简化）

如果精灵图帧动画完全不做，可以用一张静态图 + Godot Tween：

```gdscript
# 敌人 idle：上下微浮动
var tween = create_tween().set_loops()
tween.tween_property(self, "position:y", base_y - 3, 0.8).set_ease(Tween.EASE_IN_OUT)
tween.tween_property(self, "position:y", base_y + 3, 0.8).set_ease(Tween.EASE_IN_OUT)

# 敌人攻击：向前冲刺再回来
var attack_tween = create_tween()
attack_tween.tween_property(self, "position:x", base_x + 50, 0.15)
attack_tween.tween_property(self, "position:x", base_x, 0.15)

# 受伤：闪白
modulate = Color.WHITE  # 白色闪烁
await get_tree().create_timer(0.1).timeout
modulate = Color(1, 0.5, 0.5)  # 泛红
await get_tree().create_timer(0.1).timeout
modulate = Color.WHITE  # 恢复

# 死亡：缩小 + 淡出
var death_tween = create_tween()
death_tween.tween_property(self, "scale", Vector2.ZERO, 0.5)
death_tween.parallel().tween_property(self, "modulate:a", 0.0, 0.5)
```

### 5.3 自制背景方案

如果找不到合适的免费背景，可以用以下方案：

#### 方案：渐变 + 纹理叠加

1. 在 Godot 中创建一个 `ColorRect`，使用马卡龙渐变（`#fce4ec` 到 `#e1bee7`，粉→淡紫）
2. 叠加一张来自 Kenney Texture Pack 的噪点纹理，透明度设为 5-10%
3. 在前景添加几个简单的几何形状作为"糖果柱子"或"星光装饰"轮廓
4. 添加几盏低强度的 PointLight2D（粉色/薰衣草色）营造魔法氛围

> 这个方案不需要任何绘画能力，15 分钟就能做出一个还不错的 Q 版魔法走廊背景。

## 九、资源整合工作流

### 推荐流程

```
1. 需求确定
   └── 参照 02-resource-inventory.md 确定需要的资源清单

2. 搜索资源
   └── 按 itch.io -> Kenney -> OpenGameArt 的顺序搜索
   └── 优先选择 CC0 协议资源

3. 下载并记录
   └── 下载到临时目录
   └── 记录来源 URL 和授权协议（存入 assets/LICENSES.txt）

4. 调整适配
   └── 用 GIMP/Aseprite 调整尺寸、色彩
   └── 统一命名（参照命名规范）
   └── 统一格式（PNG, sRGB）

5. 导入 Godot
   └── 放入 assets/ 对应子目录
   └── 设置 Godot 导入参数（过滤模式、压缩等）
   └── 在 .import 标记资源属性

6. 测试验证
```
