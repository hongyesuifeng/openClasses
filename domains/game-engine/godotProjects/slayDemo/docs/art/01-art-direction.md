# 美术方向与风格指南

> 适用项目：SlayDemo — 《甜心迷宫》Q版卡通卡牌 Roguelike
> 目标平台：桌面（PC）
> 文档版本：v1.0

---

## 一、美术风格定位

### 推荐风格：Q版卡通风（Chibi/Kawaii Cartoon）

经过对以下四种候选风格的对比分析，**Q版卡通风**是本项目的最优选择。

| 风格 | 优势 | 劣势 | 推荐度 |
|------|------|------|--------|
| 像素风 | 社区资源极多，修改门槛低 | 角色辨识度差，卡牌细节受限 | ★★★☆ |
| **Q版卡通风** | **角色萌感强，马卡龙色系赏心悦目，AI生成一致性高** | **需统一头身比和色系风格** | **★★★★★** |
| 厚涂写实风 | 视觉冲击力强 | 制作门槛极高，资源几乎无免费可用的 | ★★☆ |
| 低多边形风 | 3D领域资源多 | 2D卡牌游戏不适用 | ★☆ |

#### 为什么选Q版卡通风

1. **大头小身、高辨识度**：2~2.5头身的Q版比例在卡牌小尺寸下仍然清晰可爱，角色特征一眼可辨。
2. **马卡龙色系天然适配**：粉/蓝/紫/黄/绿高饱和粉彩色系与《甜心迷宫》世界观高度吻合，无需额外调色。
3. **AI生成一致性高**：Q版卡通风格在当前AI图像生成工具（MidJourney、NovelAI等）中一致性最好，适合批量生成角色和卡牌插图。
4. **降低制作成本**：Q版角色结构简单，圆润线条、色块平涂，即使手绘也可在15-30分钟内完成一个敌人。
5. **与 Godot 的兼容性**：Godot 4.x 的 `StyleBox`、`Theme` 系统天然适合Q版扁平风格的 UI 体系。

#### 视觉特征定义

- 线条：无描边或 2px 均匀描边
- 填充：纯色 + 微渐变（线性渐变，不超过 2 个色阶）
- 阴影：柔和投影（偏移 2-4px，透明度 20-30%），无内阴影
- 质感：轻微纹理叠加（可选，统一使用同一张噪声纹理）
- 动画：帧动画较少，依赖补间动画（Tween）和粒子效果

## 二、色彩方案设计

### 主色调

项目采用**马卡龙粉彩**基调，以高饱和粉彩色为底、深紫色为文字，营造轻松可爱的视觉氛围。

#### 基础色板

| 角色 | 色值 | 用途 | 说明 |
|------|------|------|------|
| **背景主色** | `#f0e6ff` | 场景底色、深色面板 | 淡薰衣草紫 |
| **面板底色** | `#fce4ec` | 次级面板、卡片底板 | 浅玫瑰粉 |
| **交互元素** | `#ce93d8` | 按钮、交互元素底色 | 中紫 |
| **主要文字** | `#3e2a5a` | 主要文字、标题 | 深紫 |
| **次要文字** | `#7c5f9a` | 次要文字、描述文字 | 中深紫 |

#### 功能色（强调色）

| 角色 | 色值 | 用途 | 说明 |
|------|------|------|------|
| **能量/费用** | `#80deea` | 能量水晶、费用数字 | 浅青色，代表"蓝量" |
| **攻击** | `#ef5350` | 攻击卡牌、伤害数字 | 粉红红 |
| **防御** | `#42a5f5` | 防御卡牌、护盾图标 | 天蓝 |
| **技能** | `#66bb6a` | 技能卡牌、增益效果 | 嫩绿 |
| **诅咒/负面** | `#ce93d8` | 诅咒卡牌、debuff | 中紫 |
| **金币/奖励** | `#ffd54f` | 金币、稀有掉落 | 暖黄 |
| **危险/意图** | `#ef5350` | 敌人攻击意图指示 | 粉红红 |

#### 稀有度色

| 稀有度 | 色值 | 对应 |
|--------|------|------|
| 普通（Common） | `#f8bbd0` | 白粉边 |
| 罕见（Uncommon） | `#66bb6a` | 嫩绿边 |
| 稀有（Rare） | `#42a5f5` | 天蓝边 |
| 传说（Legendary） | `#ffd54f` | 金色彩虹边 |

### 色彩使用原则

1. **60-30-10 法则**：背景深色占 60%，中间色占 30%，强调色占 10%。
2. **功能色不混用**：红=攻击、蓝=格挡、绿=技能，贯穿始终。
3. **文字对比度**：所有文字与背景的对比度不低于 WCAG AA 标准（4.5:1）。
4. **避免彩虹效应**：同一界面中同时出现的强调色不超过 3 种。

## 四、美术参考游戏

### 一级参考（核心风格对标）

1. **Slay the Spire（杀戮尖塔）**
   - 风格：暗色卡通风插画 + 简洁 UI
   - 参考点：卡牌信息层级、战斗界面布局、敌人展示方式
   - 我们的简化：省略手绘插画，用几何图形 + 色块 + 图标替代

2. **宝可梦图鉴（Pokémon）**
   - 风格：Q版卡通，高饱和色彩，圆润可爱
   - 参考点：角色设计语言（大头小身）、配色方案、萌感怪物设计

### 二级参考（局部借鉴）

3. **皇室战争（Clash Royale）**
   - 风格：Q版3D卡通，马卡龙色系
   - 参考点：小兵角色的辨识度设计、卡牌稀有度视觉区分

4. **碧蓝档案（Blue Archive）**
   - 风格：二次元卡通，高饱和粉彩色系
   - 参考点：UI界面的粉紫色调运用、角色立绘的Q版变形比例

5. **Dicey Dungeons**
   - 风格：扁平卡通风，鲜艳配色
   - 参考点：简洁角色设计、状态图标风格、动画用 Tween 补间

6. **Brotato**
   - 风格：极简扁平，高对比度
   - 参考点：用最少笔画做出可辨识的角色剪影

## 五、美术统一性原则

### 5.1 "三个一致"原则

1. **线条一致**：全局统一使用 2px 描边或无描边，不要混用。
2. **阴影一致**：所有元素的投影方向为 (2, 2)，透明度统一为 25%，模糊半径 4px。
3. **圆角一致**：UI 元素统一使用 4px 圆角（小元素）或 8px 圆角（大面板）。

### 5.2 图标风格统一

- 所有图标使用同一套视觉语言：单色填充 + 2px 描边
- 图标尺寸统一为 32x32（标准）和 64x64（放大版）
- 状态图标在图标右下角添加小色点标识类型

### 5.3 字体统一

- 英文/数字：统一使用一种像素风或无衬线字体（见字体推荐章节）
- 中文：统一使用一种无衬线中文字体
- 标题字号：32px / 正文字号：18px / 小字：14px / 卡牌描述：12px

### 5.4 禁止事项

- 禁止在同一界面混用不同风格的美术资源（如像素风角色 + 写实风背景）
- 禁止使用带水印的素材
- 禁止使用未经确认授权协议的资源
- 禁止在没有美术基础的情况下尝试手绘复杂角色——改用几何组合

### 5.5 "能用就行"底线

本项目是学习型 Demo，美术的底线标准是：

> **玩家能在 3 秒内理解当前画面在传达什么信息。**

只要信息传达清晰，美术"粗糙"是可以接受的。不要为了追求精美而在美术上花费超过总项目时间的 20%。

## 六、风格验证检查清单

在添加任何新美术资源前，用以下清单自检：

- [ ] 是否与现有 UI 的圆角、阴影、线条粗细一致？
- [ ] 色彩是否来自本文档定义的色板？
- [ ] 在 1920x1080 分辨率下是否清晰可辨？
- [ ] 是否使用了正确的授权协议资源？
- [ ] 新增资源是否用模板化/程序化方式可实现？
- [ ] 信息层级是否清晰（最重要的信息最醒目）？
