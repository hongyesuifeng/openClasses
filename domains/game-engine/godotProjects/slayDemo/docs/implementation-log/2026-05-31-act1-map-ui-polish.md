## 2. 本轮已完成体验修复

### 2.1 宝箱奖励反馈

问题:

- 宝箱打开后立刻返回地图，玩家看不清获得了什么。

当前实现:

- 打开宝箱后按钮禁用，避免重复领取。
- 状态文本明确展示:
  - `获得 X 金币`
  - `获得遗物：名称`
  - `效果：描述`
- 若遗物池已空，显示 `没有新的遗物`。
- 奖励信息停留约 1.5 秒后自动返回地图。

涉及文件:

- `scripts/scenes/chest_scene.gd`
- `tests/integration/relic_ui_test.gd`

### 2.2 遗物信息可见性

问题:

- 战斗中看不到当前持有哪些遗物，也看不到遗物效果。

当前实现:

- 新增 `scripts/ui/relic_view_factory.gd`。
- 复用 `data/relics.json` 中的 `name`、`description`、`rarity`。
- 战斗顶部玩家面板加入常驻遗物栏。
- 地图界面加入遗物栏。
- 遗物控件支持 tooltip: `名称 + 效果描述`。
- 点击遗物会把详情写入当前场景状态提示区，便于鼠标与 headless 测试覆盖。
- 无遗物时显示 `遗物: 无`。

涉及文件:

- `scripts/ui/relic_view_factory.gd`
- `scripts/scenes/battle_scene.gd`
- `scripts/scenes/map_scene.gd`
- `tests/integration/relic_ui_test.gd`

### 2.3 休息点升级卡牌横向滚动

问题:

- 休息点进入升级模式后，牌太多会导致后面的牌超出屏幕，看不到也点不到。

当前实现:

- 升级模式下，卡牌列表包入 `ScrollContainer`。
- 横向滚动条常显。
- 禁用垂直滚动。
- `返回` 按钮固定在滚动区域外，不会随卡牌行被挤出屏幕。

涉及文件:

- `scripts/scenes/rest_scene.gd`
- `tests/integration/rest_node_test.gd`

### 2.4 主菜单入口收敛

问题:

- 起始界面同时出现「开始游戏」和「开始 V2 扩展局」，对当前可玩目标不清晰。

当前实现:

- 移除「开始 V2 扩展局」按钮。
- 移除对应 `_on_v2_start_pressed`。
- 只保留「开始游戏」，启动 `act1_map_run`。

涉及文件:

- `scripts/scenes/main_menu_scene.gd`

## 6. 建议下一步

下一步建议优先做 `P1: 事件节点首版`。

最小实现范围:

1. 在 `DataLoader` 中允许并校验 `event` 地图节点。
2. 在 `SceneRouter` 中新增 `event` 场景路由。
3. 在 `RunController` 中支持进入和完成事件节点。
4. 新增 `EventScene`，展示 2-3 个选择按钮。
5. 在 `GameState` 或独立 `EventService` 中落地事件效果。
6. 在 `data/run_v1.json` 的 Act 1 地图中接入少量事件节点。
7. 增加自动化测试，覆盖事件选择、资源变化、返回地图。

推荐先做固定配置事件，不做随机事件池，避免扩大范围。
