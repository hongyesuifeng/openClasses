## 一、版本定义

**《甜心迷宫》V1.0 Demo** — 类《杀戮尖塔》Q版卡牌 Roguelike，单局约 30~45 分钟。

核心判断标准：*"一个陌生人拿到这个游戏，能否独立完成一局完整游戏，并愿意再玩一局？"*

## 四、已知问题 & 技术债

| 问题 | 优先级 | 说明 |
|------|--------|------|
| MapGenerator seed 非确定性 | 低 | 内部用 `randi()` 非独立 RNG，replay 不可复现 |
| 遗物效果类型单一（6 种） | 中 | 无"打出攻击牌触发"等互动性效果 |
| 仅 1 个 Act | 中 | 无 Act 2，长期复玩性受限 |
| 无多角色支持 | 中 | 所有卡牌都是战士风格 |
| 诅咒卡/状态卡缺失 | 低 | 未实现 curse 类型卡牌 |
| 格挡流偏弱 | 低 | 缺少格挡流核心牌 |

## 五、PlayTest 验证清单

下次实际游玩时建议验证以下内容：

**游戏感**
- [ ] 新手引导 4 条提示是否看得清楚、时机是否合适
- [ ] 场景切换过渡是否自然（0.15s 是否太快/太慢）
- [ ] 序列帧动画是否流畅，敌人受击反馈是否明显
- [ ] 能量水晶动画是否影响可读性

**平衡性**
- [ ] 力量流能否稳定打过 Boss（目标：70% 以上）
- [ ] 毒流能否打赢 Boss（新流派验证）
- [ ] 结算评价 S 级（800分）是否太难/太容易
- [ ] 甜心女巫 Boss（第3个）难度是否合适

**信息传达**
- [ ] 升级对比 UI 是否清晰，能否帮助做决策
- [ ] 遗物 tooltip 信息是否充分
- [ ] 状态图标是否容易看懂
