# Slay the Spire 2 卡牌系统分析

> 本文档深入分析游戏的卡牌系统设计，包括数据模型、效果系统、费用机制等核心内容。

## 1. 卡牌数据模型

```csharp

    // === 关键字与标签 ===

}
```

## 2. 动态变量系统

### 2.1 设计理念

游戏使用 **DynamicVar（动态变量）** 系统来管理卡牌效果数值。这种设计允许：

- 数值可以被遗物、能力、事件动态修改
- 支持复杂的数值计算链
- 保持代码的可读性和可维护性

### 2.2 变量类型

```csharp
// 常见动态变量类型
DamageVar       // 伤害值
BlockVar        // 格挡值
HealVar         // 治疗值
PowerVar<T>     // 能力层数
CardsVar        // 卡牌数量
EnergyVar       // 能量值
MaxHpVar        // 最大生命值
```

### 2.3 使用示例

```csharp
// 示例：一张造成伤害的卡牌
public sealed class Strike : CardModel
{
    protected override IEnumerable<DynamicVar> CanonicalVars =>
        new[] { new DamageVar(6m, ValueProp.Move) };

    protected override async Task OnPlay(PlayerChoiceContext ctx, CardPlay play)
    {
        await DamageCmd.Attack(DynamicVars.Damage.BaseValue)
            .FromCard(this)
            .Targeting(play.Target)
            .Execute(ctx);
    }
}

// 示例：一张多效果的卡牌
public sealed class PommelStrike : CardModel
{
    protected override IEnumerable<DynamicVar> CanonicalVars => new DynamicVar[]
    {
        new DamageVar(9m, ValueProp.Move),
        new CardsVar(1)  // 抽一张牌
    };
}
```

## 3. 费用系统

### 3.1 能量费用

```csharp
public sealed class CardEnergyCost
{
    public int Canonical { get; }      // 基础费用
    public bool CostsX { get; }        // X费用卡牌

    // 计算实际费用
    public int GetWithModifiers(CostModifiers modifiers)
    {
        int cost = _base;

        // 应用局部修改器（如"本回合费用减少"）
        if (modifiers.HasFlag(CostModifiers.Local))
        {
            foreach (var mod in _localModifiers)
                cost = mod.Modify(cost);
        }

        // 应用全局修改器（如能力效果）
        if (modifiers.HasFlag(CostModifiers.Global))
        {
            cost = (int)Hook.ModifyEnergyCostInCombat(state, card, cost);
        }

        return Math.Max(0, cost);
    }
}
```

### 4.2 升级概率系统

```csharp
// 卡牌奖励时的升级概率计算
private static void RollForUpgrade(Player player, CardModel card,
    decimal baseChance, Rng rng)
{
    decimal odds = baseChance;

    // 非稀有卡牌随层数增加升级概率
    if (card.Rarity != CardRarity.Rare)
    {
        odds += (decimal)currentActIndex * UpgradedCardOddScaling;
    }

    // 遗物可以修改概率
    odds = Hook.ModifyCardRewardUpgradeOdds(runState, player, card, odds);

    if (rng.NextFloat() <= odds)
    {
        CardCmd.Upgrade(card);
    }
}
```

### 5.2 消耗机制

```csharp
public static async Task Exhaust(PlayerChoiceContext ctx, CardModel card,
    bool causedByEthereal = false, bool skipVisuals = false)
{
    // 移动到消耗堆
    await CardPileCmd.Add(card, PileType.Exhaust,
        CardPilePosition.Bottom, null, skipVisuals);

    // 记录历史
    CombatManager.Instance.History.CardExhausted(combatState, card);

    // 触发消耗后的Hook
    await Hook.AfterCardExhausted(combatState, ctx, card, causedByEthereal);
}
```

## 7. 卡牌效果执行

### 7.1 核心执行流程

```csharp
protected override async Task OnPlay(PlayerChoiceContext ctx, CardPlay play)
{
    // 1. 主要效果
    await DamageCmd.Attack(DynamicVars.Damage.BaseValue)
        .FromCard(this)
        .Targeting(play.Target)
        .WithHitFx("vfx/vfx_attack_slash")
        .Execute(ctx);

    // 2. 附加效果
    if (IsUpgraded)
    {
        await CardCmd.DrawCards(1);
    }

    // 3. 消耗检查
    if (Keywords.Contains(CardKeyword.Exhaust))
    {
        await CardCmd.Exhaust(ctx, this);
    }
}
```

## 8. 卡牌池系统

### 8.1 卡池设计

每个角色有专属卡池：

```csharp
public abstract class CardPoolModel : AbstractModel, IPoolModel
{
    protected abstract IEnumerable<CardModel> GenerateAllCards();

    // 获取可用卡牌
    public IEnumerable<CardModel> GetAvailableCards(UnlockState unlock)
    {
        return AllCards.Where(c => unlock.IsCardAvailable(c));
    }
}
```

### 8.2 奖励卡生成

```csharp
public static IEnumerable<CardModel> GenerateCardReward(
    RunState runState, Player player, CardRarity rarity, int count)
{
    var pool = player.Character.CardPool.GetAvailableCards(unlockState);

    // 按稀有度筛选
    var candidates = pool.Where(c => c.Rarity == rarity);

    // 随机选择
    return rng.Sample(candidates, count);
}
```

## 9. 设计亮点总结

`★ Insight ─────────────────────────────────────`
**Slay the Spire 2 卡牌系统的设计亮点：**

1. **动态变量系统**：通过 DynamicVar 实现灵活的数值管理，支持多层修改链
2. **高度可扩展**：基于 AbstractModel 的继承体系，添加新卡牌只需继承并实现
3. **命令模式**：所有效果封装为命令，支持撤销、重放和多人同步
4. **Hook 集成**：每个关键步骤都可被遗物/能力/模组介入修改
`─────────────────────────────────────────────────`
