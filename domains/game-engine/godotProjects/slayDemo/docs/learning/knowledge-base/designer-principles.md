## 游戏设计原则

### 决策密度

**来源**: slayDemo 设计文档
**日期**: 2026-05-20

### 发现
- 每回合的选择都有意义，不存在"无脑最优解"
- 让玩家在多个选项中做出取舍

### 为什么重要
- 保持游戏的策略深度
- 避免游戏变得枯燥

### 应用场景
- 卡牌设计：每张卡都有使用场景，没有绝对最强的卡
- 数值平衡：不同策略强度接近
