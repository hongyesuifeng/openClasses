## Godot 技术模式

### 信号驱动模式

**来源**: Godot 官方教程
**日期**: 2026-05-20

### 发现
- 使用信号（Signal）解耦模块间通信
- 发射方不关心接收方是谁
- 接收方通过 `connect()` 订阅信号

### 为什么重要
- 降低模块耦合度
- 便于扩展和测试
- 符合 Godot 的设计哲学

### 应用场景
- UI 更新：游戏状态变化时发射信号，UI 监听并更新
- 事件系统：玩家行为、敌人行动等都可用信号驱动
