## 2. 房间类型设计

### 2.1 房间类型总表

| 类型 | 图标 | 英文标识 | 说明 |
|------|------|---------|------|
| 怪怪对决 | ● | `COMBAT` | 与可爱怪物战斗 |
| 强敌来袭 | ▲ | `ELITE` | 与强力怪物战斗，高奖励 |
| 最终守护者 | ★★★ | `BOSS` | 与最终守护者战斗，甜心迷宫终极挑战 |
| 魔法杂货铺 | ◇ | `SHOP` | 购买卡牌、移除卡牌、购买药水 |
| 神秘事件 | ◆ | `EVENT` | 文本选择事件，有风险和回报 |
| 甜蜜休息站 | ○ | `REST` | 回复 HP 或升级一张牌 |
| 起始 | ★ | `START` | 起始营地 |

### 2.2 各房间类型详细设计

#### 怪怪对决（Combat）

- 触发后进入战斗界面
- 敌人来源：根据当前楼层的可爱怪物池随机选择
- 完成后获得：金币 + 卡牌选择（可选跳过）
- 难度随楼层递增

#### 强敌来袭（Elite）

- 图标明显区别于普通怪怪对决（红色标记/特殊外观）
- 进入前有确认提示："前方有强大的怪物，确定要挑战吗？"
- 完成后获得：金币 + 稀有度提升的卡牌奖励
- 首版设计 2 个强敌位置（层 7、层 11）

#### 最终守护者（Boss）

- 甜心迷宫最后一层固定为最终守护者房间
- 进入前有视觉提示（大门、红色光效）
- 完成后进入通关结算界面
- 首版仅 1 个最终守护者（星愿守护龙）

#### 魔法杂货铺（Shop）

- 进入后显示魔法杂货铺界面
- 可以购买：卡牌、药水
- 可以消费：移除一张牌
- 离开后进入下一层选择
- 首版设计 2 个魔法杂货铺（层 5、层 12）

#### 神秘事件（Event）

- 进入后显示事件文本和选项
- 每个事件 2~3 个选项，有不同的风险和回报
- 首版设计 3 个事件（详见下方）

#### 甜蜜休息站（Rest Site）

- 提供两个选择（二选一）：
  - **休息**：回复 30% 最大 HP
  - **锻造**：升级 1 张卡牌
- 是玩家调整节奏的关键节点

## 3. 地图生成规则

### 3.1 生成算法概述

```
1. 创建 15 行（层 0~层 15）
2. 每行生成 2~4 个房间节点
3. 相邻行之间的节点建立连接边
4. 确保从起点到 Boss 存在至少 1 条可达路径
5. 根据楼层类型分配房间内容
6. 验证路径平衡性
```

### 3.2 房间分配规则

| 楼层范围 | 房间类型权重 | 说明 |
|---------|-------------|------|
| 层 1~3 | 怪怪对决 80%，神秘事件 20% | 早期以对决为主，建立牌组 |
| 层 4~6 | 怪怪对决 50%，魔法杂货铺 20%，神秘事件 30% | 引入魔法杂货铺和事件 |
| 层 7 | 强敌来袭 60%，怪怪对决 40% | 第一个强敌区 |
| 层 8~10 | 怪怪对决 60%，神秘事件 40% | 中期以对决为主 |
| 层 11 | 强敌来袭 60%，怪怪对决 40% | 第二个强敌区 |
| 层 12 | 魔法杂货铺 50%，怪怪对决 50% | 最终守护者前最后补给 |
| 层 13 | 怪怪对决 100% | 最终守护者前最后对决 |
| 层 14 | 甜蜜休息站 100% | 最终守护者前必定可以休息 |
| 层 15 | 最终守护者 100% | 固定最终守护者 |

### 3.3 路径连接规则

1. 每个节点至少与上一层 1 个节点相连
2. 每个节点最多与上一层 2 个节点相连
3. 不允许同一行内横向连接
4. 从起点出发，至少存在 3 条不同的可达路径到达 Boss
5. 每条路径至少经过 1 个甜蜜休息站、1 个魔法杂货铺、1 个强敌来袭

### 3.4 连线可视化

玩家在地图界面看到当前层的所有节点，以及与上一层的连接线。已访问的节点高亮，当前可用节点闪烁提示。未访问的未来节点显示类型图标但不显示连接细节（仅下一层的连接可见）。

## 4. 事件设计

### 4.1 事件列表（首版 3 个）

#### 事件 1：神秘旅人（Mysterious Traveler）

**描述**：一位戴着大帽子的神秘旅人挡住了去路。"以魔力换力量，你愿意吗？"

| 选项 | 效果 |
|------|------|
| 接受交易 | 失去 10 HP，获得 1 张随机稀有牌 |
| 拒绝离开 | 无事发生 |

**设计意图**：早期高风险高回报选择。用 HP 换稀有牌，对牌组构建意义重大但需要承担生命值压力。

---

#### 事件 2：惊喜宝箱（Abandoned Shrine）

**描述**：一个闪闪发光的宝箱出现在迷宫走廊，旁边似乎有什么东西在动……

| 选项 | 效果 |
|------|------|
| 打开宝箱 | 回复 15 HP（若满 HP 则获得 5 最大 HP） |
| 摇晃宝箱 | 获得随机 1 张罕见牌 |
| 离开 | 无事发生 |

**设计意图**：测试玩家对当前 HP 状态的评估。HP 低时回血更安全，HP 充足时可以赌牌。

---

#### 事件 3：魔法学院测试（Blacksmith's Trial）

**描述**：一位魔法导师拦住你——"来接受一个小挑战！接住这颗魔法球！"

| 选项 | 效果 |
|------|------|
| 接住 | 失去 5 HP，升级 2 张卡牌 |
| 拒绝 | 无事发生 |

**设计意图**：用少量 HP 换取 2 次升级机会。比甜蜜休息站的"休息/锻造"选择更高效但有 HP 代价。

## 5. 房间奖励设计

### 5.1 怪怪对决奖励

| 奖励类型 | 内容 | 跳过选项 |
|---------|------|---------|
| 金币 | 8~15（普通）/ 25~35（精英） | 不可跳过 |
| 卡牌 | 展示 3 张卡，选择 1 张 | 可跳过（不选任何牌） |

### 5.2 强敌来袭奖励

| 奖励类型 | 内容 |
|---------|------|
| 金币 | 25~35 |
| 卡牌 | 展示 3 张卡（稀有度概率提升），选择 1 张 |

### 5.3 最终守护者奖励

| 奖励类型 | 内容 |
|---------|------|
| 金币 | 60~80 |
| 卡牌 | 展示 3 张卡（高稀有概率），选择 1 张 |
| 通关结算 | 显示统计信息（战斗次数、精英击败数、卡牌数等） |

> 详细奖励数值见 `05-reward-and-economy.md`。

## 6. 难度曲线设计

### 6.1 难度维度

| 维度 | 早期（层 1~5） | 中期（层 6~10） | 后期（层 11~14） | Boss（层 15） |
|------|---------------|----------------|-----------------|--------------|
| 敌人 HP | 12~26 | 20~50 | 30~56 | 120~140 |
| 单次伤害 | 5~8 | 6~12 | 8~20 | 10~30 |
| 状态压力 | 无~低 | 中 | 高 | 极高 |
| 卡组强度要求 | 低（基础牌可通） | 中（需要核心卡） | 高（需要成型） | 极高（需要完整策略） |

### 6.2 玩家成长曲线

| 阶段 | 预期牌组大小 | 预期核心策略 | 预期 HP |
|------|-------------|-------------|---------|
| 层 1~3 后 | 13~15 张 | 初步方向选择 | 65~80 |
| 层 5~7 后 | 15~18 张 | 核心卡到位 | 50~70 |
| 层 10~12 后 | 16~22 张 | 牌组成型 | 35~65 |
| Boss 前 | 18~25 张 | 完整策略 | 25~60（取决于休息点选择） |

### 6.3 难度调节机制

- **底层保护**：层 1~2 的敌人 HP 取下限值
- **递增伤害**：每 3 层，敌人基础伤害 +1
- **精英可选**：精英房间可以绕行，不影响通关
- **甜蜜休息站保障**：最终守护者前必有甜蜜休息站

## 7. 地图数据结构（技术参考）

```gdscript
# MapData.gd
class_name MapData
extends Resource

@export var floors: Array[FloorData]    # 15 层楼
@export var current_floor: int = 0      # 当前楼层
@export var visited_rooms: Array[String] # 已访问房间 ID

# FloorData.gd
class_name FloorData
extends Resource

@export var floor_index: int            # 楼层编号 0~15
@export var rooms: Array[RoomData]       # 本层所有房间
@export var connections: Array[Dictionary] # 连接关系 {from_room_id, to_room_id}

# RoomData.gd
class_name RoomData
extends Resource

@export var id: String                  # 唯一标识
@export var room_type: String           # "combat" / "elite" / "boss" / "shop" / "event" / "rest" / "start"
@export var is_visited: bool = false    # 是否已访问
@export var encounter_id: String = ""   # 战斗房间的遭遇 ID
@export var event_id: String = ""       # 事件房间的事件 ID
@export var position: Vector2           # 在地图上的位置
```
