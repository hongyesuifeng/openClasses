# 敌人设计文档

## 1. 设计原则

### 1.1 核心设计理念

1. **意图可读**：敌人行动必须提前展示，让玩家能做出有意义的决策
2. **模式可学**：每个敌人有固定的行为模式或权重池，玩家能通过经验做出预判
3. **定位清晰**：每个敌人测试玩家的不同能力（爆发、续航、AOE、解状态）
4. **数值渐进**：从 Act 前期到 Boss，HP 和伤害逐步递增

### 1.2 意图类型

| 意图图标 | 英文标识 | 说明 |
|---------|---------|------|
| 剑 | Attack | 对玩家造成伤害 |
| 盾 | Defend | 敌人获得格挡 |
| 剑+盾 | AttackDefend | 同时攻击和防御 |
| ↑箭头 | Buff | 敌人获得增益状态 |
| ↓箭头 | Debuff | 对玩家施加减益状态 |
| 特殊 | Special | Boss 专属特殊行动 |

### 1.3 敌人数据结构（技术参考）

```gdscript
# EnemyData.gd
class_name EnemyData
extends Resource

@export var id: String                    # 唯一标识
@export var enemy_name: String            # 显示名称
@export var hp_min: int                   # HP 下限
@export var hp_max: int                   # HP 上限
@export var enemy_type: String            # "normal" / "elite" / "boss"
@export var moves: Array[Dictionary]      # 行动池
@export var loot_gold_min: int            # 掉落金币下限
@export var loot_gold_max: int            # 掉落金币上限
```

## 2. 普通敌人（Normal Enemies）— 共 4 个

### 2.1 绿皮小怪（Green Slime）

| 属性 | 数值 |
|------|------|
| HP | 12~17 |
| 类型 | 普通 |
| 定位 | 入门教学敌，伤害低、机制简单 |

**行为模式（固定序列，循环）**：

| 回合 | 意图 | 效果 |
|------|------|------|
| 回合 1 | 攻击 | 造成 5 伤害 |
| 回合 2 | 攻击 | 造成 6 伤害 |
| 回合 3 | 防御 | 获得 4 格挡 |
| 回合 4 | 攻击 | 造成 8 伤害 |
| → 循环至回合 1 | | |

**定位描述**：最基础的敌人，伤害低、血量少，适合让玩家熟悉出牌和能量管理。第三回合防御，测试玩家是否能利用对方防御回合积攒力量或抽牌。

---

### 2.2 尖刺兽（Spiky Beast）

| 属性 | 数值 |
|------|------|
| HP | 20~26 |
| 类型 | 普通 |
| 定位 | 中等威胁，多段攻击测试玩家格挡能力 |

**行为模式（权重池）**：

| 行动 | 权重 | 效果 |
|------|------|------|
| 连爪击 | 40% | 造成 2x3 伤害（共 6，分两段） |
| 冲撞 | 30% | 造成 8 伤害 |
| 蓄力咆哮 | 20% | 获得 1 层力量 |
| 退缩 | 10% | 获得 6 格挡 |

**定位描述**：多段攻击敌人，让玩家意识到多次小攻击在力量加成后会变得很痛。蓄力咆哮是软性 DNR（不做不影响通关），但忽视会导致后续伤害明显增加。

---

### 2.3 暗影法师（Shadow Cultist）

| 属性 | 数值 |
|------|------|
| HP | 18~22 |
| 类型 | 普通 |
| 定位 | Debuff 型敌人，测试玩家对状态管理的能力 |

**行为模式（权重池）**：

| 行动 | 权重 | 效果 |
|------|------|------|
| 暗影侵蚀 | 50% | 施加 2 层虚弱 |
| 暗影打击 | 30% | 造成 6 伤害 |
| 强化仪式 | 20% | 获得 2 层力量（下回合攻击大幅增强） |

**特殊规则**：强化仪式回合，意图显示为 Buff。若玩家无法在下一回合击杀或防御，将承受 10+ 伤害。

**定位描述**：核心教学——让玩家理解"预防优于治疗"的道理。如果不打断或防御强化仪式后的攻击，代价很大。这也是让玩家意识到多段攻击配合易伤的价值。

---

### 2.4 石壳龟（Shell Turtle）

| 属性 | 数值 |
|------|------|
| HP | 24~30 |
| 类型 | 普通 |
| 定位 | 高防坦克型，测试玩家的持续输出能力 |

**行为模式（固定序列，循环）**：

| 回合 | 意图 | 效果 |
|------|------|------|
| 回合 1 | 防御 | 获得 10 格挡 |
| 回合 2 | 攻击防御 | 造成 5 伤害，获得 5 格挡 |
| 回合 3 | 攻击 | 造成 8 伤害 |
| 回合 4 | 防御 | 获得 12 格挡 |
| → 循环至回合 1 | | |

**定位描述**：高防低攻的坦克敌人。玩家需要学会在防御回合积累手牌资源，在攻击回合打出爆发。间接测试玩家的牌组伤害输出是否足够。

## 3. 精英敌人（Elite Enemies）— 共 2 个

### 3.1 暴怒骑士（Raging Knight）

| 属性 | 数值 |
|------|------|
| HP | 48~56 |
| 类型 | 精英 |
| 掉落金币 | 25~35 |
| 定位 | 高压测试——大伤害 + Debuff 组合 |

**行为模式（固定序列，循环）**：

| 回合 | 意图 | 效果 |
|------|------|------|
| 回合 1 | 攻击 | 造成 12 伤害 |
| 回合 2 | 攻击 | 施加 2 层易伤 |
| 回合 3 | 攻击（强化） | 造成 20 伤害 |
| 回合 4 | 攻击防御 | 造成 10 伤害，获得 12 格挡 |
| → 循环至回合 1 | | |

**定位描述**：精英怪是玩家的"牌组检验器"。暴怒骑士的核心威胁是回合 2 的易伤 + 回合 3 的大伤害连招。如果玩家没有足够的防御或无法在回合 3 前解决，将承受 30 伤害（20 × 1.5）。这迫使玩家学习如何规划多回合输出和防御节奏。

**奖励**：击败后额外掉落金币 + 卡牌奖励池提升稀有度概率。

---

### 3.2 双头蛇（Twin Serpent）

| 属性 | 数值 |
|------|------|
| HP | 42~50 |
| 类型 | 精英 |
| 掉落金币 | 20~30 |
| 定位 | 状态叠加型——中毒 + 多段伤害组合 |

**行为模式（权重池，每 2 回合强制一次剧毒吐息）**：

| 行动 | 权重 | 效果 |
|------|------|------|
| 毒牙撕咬 | 35% | 造成 7 伤害，施加 3 层中毒 |
| 剧毒吐息 | 25% | 施加 5 层中毒 |
| 双头猛击 | 25% | 造成 2x6 伤害（共 12，分两段） |
| 蜕皮再生 | 15% | 回复 8 HP，获得 6 格挡 |

**特殊规则**：每 2 回合至少执行一次"剧毒吐息"（强制权重提升）。

**定位描述**：中毒是持续伤害机制，如果不及时击杀，中毒会不断叠加。测试玩家在持续压力下的输出节奏。蜕皮再生增加击杀难度，要求玩家有足够的爆发伤害。

**奖励**：击败后额外掉落金币 + 卡牌奖励池提升稀有度概率。

## 4. Boss 敌人（Boss）— 共 1 个

### 4.1 深渊领主（Abyss Lord）

| 属性 | 数值 |
|------|------|
| HP | 120~140 |
| 类型 | Boss |
| 掉落金币 | 60~80 |
| 定位 | Act 最终 Boss，三阶段战斗 |

**第一阶段（HP 100%~60%）**：

| 回合 | 意图 | 效果 |
|------|------|------|
| 回合 1 | 攻击 | 造成 10 伤害 |
| 回合 2 | 攻击防御 | 造成 8 伤害，获得 12 格挡 |
| 回合 3 | Debuff | 施加 2 层易伤 + 1 层虚弱 |
| 回合 4 | 攻击 | 造成 15 伤害 |
| → 循环 | | |

**第二阶段（HP 60%~30%）**：

| 回合 | 意图 | 效果 |
|------|------|------|
| 回合 1 | Buff | 获得 3 层力量 |
| 回合 2 | 攻击（强化） | 造成 2x10 伤害（共 20） |
| 回合 3 | Debuff | 施加 3 层易伤 |
| 回合 4 | 攻击防御 | 造成 12 伤害，获得 15 格挡 |
| 回合 5 | 攻击（强化） | 造成 25 伤害 |
| → 循环 | | |

**第三阶段（HP 30%~0%）**：

| 回合 | 意图 | 效果 |
|------|------|------|
| 回合 1 | 特殊 — 深渊凝视 | 施加 2 层易伤 + 2 层虚弱 |
| 回合 2 | 攻击（终极） | 造成 30 伤害 |
| 回合 3 | 攻击防御 | 造成 15 伤害，获得 20 格挡 |
| → 循环（逐步加压） | | |

**特殊规则**：
- 阶段切换时，Boss 清除所有 debuff 并获得 5 格挡
- 第三阶段开始时播放特殊动画/特效
- 回合 2 的 30 伤害是本 Demo 最大单次伤害，测试玩家的防御极限

**定位描述**：三阶段 Boss 战是整个 Act 的高潮。第一阶段让玩家建立节奏，第二阶段加大伤害并引入力量叠加，第三阶段是最终考验——必须在承受致命攻击前击杀或完美防御。设计意图是让玩家在 8~12 回合内完成战斗，全程保持紧张感。

## 5. 敌人难度梯度

### 5.1 出现顺序与难度曲线

```
地图层数：  0        1~3         4~6         7~9         10~12       13~15（Boss）
            │         │           │           │           │            │
难度：      ▼         ▼           ▼           ▼           ▼            ▼
          绿皮小怪  绿皮小怪   尖刺兽      暗影法师    暴怒骑士     深渊领主
                    尖刺兽     暗影法师    石壳龟      双头蛇
                               石壳龟                 (以上均可)
```

### 5.2 难度参数对比

| 敌人 | HP 范围 | 平均每回合伤害 | 特殊威胁 | 出现楼层 |
|------|--------|--------------|---------|---------|
| 绿皮小怪 | 12~17 | 5~8 | 无 | 1~6 |
| 尖刺兽 | 20~26 | 6~8 | 力量叠加 | 2~9 |
| 暗影法师 | 18~22 | 6~10（强化后） | 虚弱 + 力量 | 3~10 |
| 石壳龟 | 24~30 | 5~8 | 高格挡 | 4~12 |
| 暴怒骑士 | 48~56 | 10~20 | 易伤 + 大伤害 | 7~13 |
| 双头蛇 | 42~50 | 7~12 + 中毒 | 中毒叠加 | 7~13 |
| 深渊领主 | 120~140 | 10~30（分阶段） | 三阶段 + 状态 | 15（Boss） |

### 5.3 多敌人战斗说明

- 普通战斗可能出现 1~2 个普通敌人
- 精英战斗为单个精英敌人
- Boss 战为单个 Boss
- 多敌人组合详见 `07-combat-encounter-design.md`
