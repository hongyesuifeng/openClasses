# 奖励与经济系统

## 1. 战斗奖励设计

### 1.1 奖励触发流程

```
战斗胜利 → battle_end
    │
    ├── 1. 显示战斗结果（回合数、造成伤害、承受伤害等统计）
    │
    ├── 2. 发放金币（自动获得，显示获得数量）
    │
    ├── 3. 卡牌选择界面（显示 3 张卡牌 → 选择 1 张或跳过）
    │
    ├── 4. 药水奖励（仅精英和 Boss）
    │
    └── 5. 返回地图
```

### 1.2 金币奖励

| 战斗类型 | 金币范围 | 平均值 | 备注 |
|---------|---------|--------|------|
| 普通战斗 | 8~15 | 12 | 随楼层微增，层 1~5 取低值，层 10+ 取高值 |
| 精英战斗 | 25~35 | 30 | 稳定高收益 |
| Boss 战斗 | 60~80 | 70 | 一次性大量金币 |

**金币递增规则**：

| 楼层范围 | 普通战斗金币修正 |
|---------|----------------|
| 层 1~5 | 基础值（8~15） |
| 层 6~10 | +3（11~18） |
| 层 11~14 | +6（14~21） |

### 1.3 卡牌奖励

#### 奖励卡池

- 排除初始牌组中的基础牌（魔法弹、魔法盾）
- 奖励池仅包含 C01~C12、U01~U10、R01~R06 共 28 张牌
- 不包含玩家牌组中已有的卡牌（避免重复获取同一种牌，首版简化规则）
- 若牌组已达 30 张，提示"牌组已满"但仍可选择添加

#### 稀有度概率

| 战斗类型 | 普通 | 罕见 | 稀有 |
|---------|------|------|------|
| 普通战斗 | 70% | 25% | 5% |
| 精英战斗 | 50% | 35% | 15% |
| Boss 战斗 | 30% | 40% | 30% |

#### 展示规则

1. 随机生成 3 张卡牌，每张独立按稀有度概率抽取
2. 保底规则：3 张中至少 1 张为普通牌（避免全是稀有导致选择困难，首版简化）
3. 玩家点击选择 1 张加入牌组，或点击"跳过"不选
4. 跳过没有任何惩罚

### 1.4 药水奖励（首版简化）

| 获取时机 | 药水类型 |
|---------|---------|
| 精英战斗后 | 随机获得 1 瓶药水 |
| Boss 战后 | 随机获得 1 瓶药水 |

**药水种类（首版 3 种）**：

| 药水 | 效果 | 稀有度权重 |
|------|------|-----------|
| 治疗药水 | 回复 20 HP | 50% |
| 力量药水 | 本场战斗获得 2 层力量 | 30% |
| 格挡药水 | 立即获得 12 格挡 | 20% |

**药水使用规则**：
- 药水栏位上限：2 个
- 战斗中可以使用，不消耗能量，不消耗出牌机会
- 使用后药水栏位清空
- 首版不做药水商店（仅通过战斗获取）

### 2.2 魔法杂货铺商品与定价

#### 卡牌商品

| 稀有度 | 定价 | 说明 |
|--------|------|------|
| 普通 | 50 金币 | 基础卡牌 |
| 罕见 | 75 金币 | 进阶卡牌 |
| 稀有 | 150 金币 | 高级卡牌 |

**卡牌生成规则**：
- 展示 5 张卡牌
- 保证至少 1 张普通、1 张罕见
- 稀有卡最多 1 张
- 不重复牌组已有的卡牌
- 定价固定，不受折扣影响（首版简化）

| 药水 | 定价 | 说明 |
|------|------|------|
| 治疗药水 | 30 金币 | 回复 20 HP |
| 力量药水 | 50 金币 | 战斗中获得 2 力量 |
| 格挡药水 | 40 金币 | 立即获得 12 格挡 |

**药水生成规则**：
- 展示 2 瓶药水
- 可能有 1 瓶与上次商店不同（增加随机性）
- 购买药水时，如果药水栏已满则提示是否替换

#### 卡牌移除服务

| 服务 | 价格 | 说明 |
|------|------|------|
| 移除卡牌 | 75 金币 | 从牌组中永久移除一张牌 |

**移除规则**：
- 每次访问魔法杂货铺只能移除 1 张牌
- 可以移除任何牌（包括基础魔法弹/魔法盾）
- 移除操作不可撤销
- 首版不做递增定价（每次都是 75 金币）

## 3. 经济平衡分析

### 3.1 全局金币收支预估

#### 金币收入

| 来源 | 次数（预估） | 单次收入 | 总计 |
|------|-------------|---------|------|
| 怪怪对决 | 7~9 次 | 8~21（平均 14） | 98~189 |
| 强敌来袭 | 0~2 次 | 25~35（平均 30） | 0~70 |
| 最终守护者 | 1 次 | 60~80（平均 70） | 70 |
| 事件金币 | 0~1 次 | 0~30 | 0~30 |
| **总计** | | | **168~359** |

**平均值**：约 250 金币/局

#### 金币支出

| 项目 | 次数（预估） | 单次价格 | 总计 |
|------|-------------|---------|------|
| 购买卡牌 | 2~4 次 | 50~150（平均 80） | 160~320 |
| 移除卡牌 | 0~2 次 | 75 | 0~150 |
| 购买药水 | 0~2 次 | 30~50（平均 40） | 0~100 |

### 3.2 经济决策分析

| 决策场景 | 经济影响 | 策略含义 |
|---------|---------|---------|
| 是否挑战强敌 | +30 金币但消耗 HP/资源 | 强敌来袭是高风险高回报的经济来源 |
| 买牌 vs 移除牌 | 都消耗金币，方向不同 | 买牌增加牌组厚度，移除提高牌组精密度 |
| 路过魔法杂货铺不消费 | 金币可以留给第二家 | 两家魔法杂货铺可以选择性消费 |
| 跳过卡牌奖励 | 不消耗金币但错过构建机会 | 有时"不添加差牌"比"添加好牌"更重要 |

### 3.3 平衡目标

- **理想情况**：玩家每局能购买 2~3 张卡牌 + 移除 1 张基础牌
- **经济紧张**：迫使玩家在"买好牌"和"精简牌组"之间做选择
- **避免极端**：不让金币完全不够用（最低也能移除 1 张牌），也不让金币完全花不完

### 3.4 平衡调节参数

| 参数 | 当前值 | 调节方向 | 影响 |
|------|--------|---------|------|
| 怪怪对决金币 | 8~15 | 上调/下调 | 影响整体经济宽松度 |
| 强敌来袭金币 | 25~35 | 上调 | 鼓励挑战强敌 |
| 魔法杂货铺稀有牌价格 | 150 | 下调 | 让稀有牌更易获取 |
| 移除价格 | 75 | 上调 | 增加牌组精简的代价 |

## 4. 奖励数据结构（技术参考）

```gdscript
# RewardData.gd
class_name RewardData
extends Resource

@export var gold_min: int
@export var gold_max: int
@export var card_choices: int = 3             # 展示卡牌数量
@export var card_rarity_weights: Dictionary = {  # 稀有度权重
    "common": 70,
    "uncommon": 25,
    "rare": 5
}
@export var potion_reward: bool = false       # 是否奖励药水
@export var potion_choices: int = 1           # 药水选择数量

# ShopData.gd
class_name ShopData
extends Resource

@export var cards_for_sale: Array[CardData]   # 出售的卡牌
@export var potions_for_sale: Array[PotionData] # 出售的药水
@export var remove_cost: int = 75             # 移除卡牌价格

# PotionData.gd
class_name PotionData
extends Resource

@export var id: String
@export var potion_name: String
@export var description: String
@export var price: int
@export var effect_type: String               # "heal" / "gain_strength" / "gain_block"
@export var effect_value: int
```

## 5. 奖励界面交互设计

### 5.1 卡牌选择界面

1. 战斗结束后自动弹出
2. 显示 3 张卡牌，每张展示：名称、费用、类型、效果描述、稀有度标识
3. 点击卡牌 → 确认添加到牌组
4. 点击"跳过"按钮 → 不选择任何牌
5. 确认后自动关闭界面，返回地图

### 5.2 魔法杂货铺界面

1. 进入魔法杂货铺房间后显示界面
2. 商品可点击查看详情（弹出卡牌/药水详情）
3. "购买"按钮仅在有足够金币时高亮
4. 移除卡牌：点击后显示牌组列表，选择 1 张移除
5. "离开魔法杂货铺"按钮始终可用

### 5.3 药水使用

1. 战斗界面中，药水栏显示在屏幕底部
2. 点击药水 → 显示目标选择（若需要）→ 确认使用
3. 使用后药水栏位清空，播放对应特效
