# 状态与 Buff 系统

## 1. 状态效果总表

### 1.1 设计原则

- 每个状态效果都有明确的数值和触发时机
- 状态可以叠加层数，效果随层数线性增长
- 持续型状态有明确的消退机制
- 状态之间的交互关系必须可预测

### 1.2 状态效果一览（共 10 种）

| # | 名称 | 英文标识 | 类型 | 持续性 | 作用对象 |
|---|------|---------|------|--------|---------|
| 1 | 力量 | Strength | Buff | 永久（整场战斗） | 自身 |
| 2 | 敏捷 | Dexterity | Buff | 永久（整场战斗） | 自身 |
| 3 | 易伤 | Vulnerable | Debuff | 持续 N 回合 | 敌人或玩家 |
| 4 | 虚弱 | Frail | Debuff | 持续 N 回合 | 敌人或玩家 |
| 5 | 中毒 | Poison | Debuff | 持续到消失 | 敌人（首版仅敌人） |
| 6 | 格挡 | Block | 临时 | 本回合 | 自身 |
| 7 | 荆棘 | Thorns | Buff | 持续 N 回合 | 自身 |
| 8 | 生命链接 | Regeneration | Buff | 持续 N 回合 | 自身 |
| 9 | 护盾 | Shield | Buff | 永久（整场战斗） | 自身 |
| 10 | 无力 | Weak | Debuff | 持续 N 回合 | 敌人或玩家 |

## 2. 状态效果详细设计

### 2.1 力量（Strength）

| 属性 | 说明 |
|------|------|
| 标识 | `strength` |
| 类型 | Buff |
| 叠加方式 | 线性叠加（每层 +1） |
| 持续时间 | 永久（整场战斗，不消退） |
| 获取方式 | 卡牌（战吼 +1，恶魔之力 +2/回合）、药水 |

**效果**：每点力量使所有攻击牌的伤害 +1。

**计算公式**：
```
最终伤害 = 基础伤害 + 力量值
```

**示例**：
- 基础伤害 6 的打击，力量为 3 → 最终伤害 9
- 多段攻击：连击（2x5），力量为 2 → 每段 7 伤害，共 14 伤害

**交互**：
- 与易伤独立计算（先加力量，再乘易伤系数）
- 力量可以为负数（未来扩展：敌人施加减力量效果）

---

### 2.2 敏捷（Dexterity）

| 属性 | 说明 |
|------|------|
| 标识 | `dexterity` |
| 类型 | Buff |
| 叠加方式 | 线性叠加（每层 +1） |
| 持续时间 | 永久（整场战斗，不消退） |
| 获取方式 | 卡牌（蓄力 +1） |

**效果**：每点敏捷使所有获得格挡的效果 +1。

**计算公式**：
```
最终格挡 = 基础格挡 + 敏捷值
```

**示例**：
- 基础格挡 5 的防御，敏捷为 2 → 最终格挡 7

**交互**：
- 与虚弱交互：虚弱使格挡减少 25%
- 计算顺序：先加敏捷，再乘虚弱系数

---

### 2.3 易伤（Vulnerable）

| 属性 | 说明 |
|------|------|
| 标识 | `vulnerable` |
| 类型 | Debuff |
| 叠加方式 | 层数 = 持续回合数 |
| 持续时间 | 每回合结束层数 -1，到 0 消失 |
| 获取方式 | 卡牌（重击施加 2 层）、敌人行为 |

**效果**：受到的攻击伤害增加 50%。

**计算公式**：
```
最终伤害 = (基础伤害 + 力量) × 1.5（向上取整）
```

**示例**：
- 基础伤害 10，力量 0 → 易伤时 15 伤害
- 基础伤害 10，力量 3 → 易伤时 (10+3)×1.5 = 19.5 → 20 伤害

**消退规则**：
- 回合结束时层数 -1
- 层数为 0 时移除
- 不影响格挡计算

**交互**：
- 与力量乘法叠加（力量先加，易伤后乘）
- 不影响中毒伤害
- 不影响状态效果的伤害

---

### 2.4 虚弱（Frail）

| 属性 | 说明 |
|------|------|
| 标识 | `frail` |
| 类型 | Debuff |
| 叠加方式 | 层数 = 持续回合数 |
| 持续时间 | 每回合结束层数 -1，到 0 消失 |
| 获取方式 | 卡牌（破甲击施加 2 层）、敌人行为 |

**效果**：获得的格挡减少 25%（向下取整，最低 0）。

**计算公式**：
```
最终格挡 = floor((基础格挡 + 敏捷) × 0.75)
```

**示例**：
- 基础格挡 8，敏捷 2 → 虚弱时 floor(10×0.75) = 7 格挡
- 基础格挡 5，敏捷 0 → 虚弱时 floor(5×0.75) = 3 格挡

**消退规则**：
- 回合结束时层数 -1
- 层数为 0 时移除

**交互**：
- 与敏捷独立计算（先加敏捷，再乘虚弱系数）
- 不影响其他状态

---

### 2.5 中毒（Poison）

| 属性 | 说明 |
|------|------|
| 标识 | `poison` |
| 类型 | Debuff |
| 叠加方式 | 线性叠加（层数直接累加） |
| 持续时间 | 每回合开始时造成层数等值的伤害，然后层数 -1 |
| 获取方式 | 卡牌（敌人专用，首版玩家不可施加）、敌人行为 |

**效果**：回合开始时造成等于当前层数的伤害，然后层数 -1。

**计算公式**：
```
中毒伤害 = 当前中毒层数
回合结束后：中毒层数 = 当前层数 - 1
```

**示例**：
- 中毒 5 层 → 回合开始受到 5 伤害，变为 4 层
- 中毒 4 层 → 下回合开始受到 4 伤害，变为 3 层
- 总伤害 = 5+4+3+2+1 = 15（若无新中毒施加）

**消退规则**：
- 每回合自动 -1
- 降为 0 时移除
- 可以被新的中毒叠加（不会重置消退计时，直接累加层数）

**交互**：
- 中毒伤害不受力量影响
- 中毒伤害不受易伤影响
- 中毒伤害不受格挡减免（直接扣除 HP）

---

### 2.6 格挡（Block）

| 属性 | 说明 |
|------|------|
| 标识 | `block` |
| 类型 | 临时状态 |
| 叠加方式 | 直接累加 |
| 持续时间 | 本回合结束清零（玩家格挡） |
| 获取方式 | 卡牌、状态效果（不屈意志） |

**效果**：受到攻击时，先扣除格挡，再扣除 HP。

**计算公式**：
```
实际 HP 损失 = max(0, 伤害 - 格挡)
剩余格挡 = max(0, 格挡 - 伤害)
```

**消退规则**：
- 玩家格挡：回合结束清零
- 敌人格挡：下一回合开始前保留（直到被打掉或战斗结束）

**交互**：
- 受虚弱影响
- 受敏捷加成
- 穿刺伤害无视格挡

---

### 2.7 荆棘（Thorns）

| 属性 | 说明 |
|------|------|
| 标识 | `thorns` |
| 类型 | Buff |
| 叠加方式 | 层数叠加 |
| 持续时间 | 持续 N 回合（N = 叠加时设定的值） |
| 获取方式 | 首版仅敌人行为（预留卡牌设计空间） |

**效果**：被攻击时，攻击者受到等于荆棘层数的伤害。

**计算公式**：
```
反弹伤害 = 荆棘层数
```

**消退规则**：
- 每次被攻击后层数不变
- 回合结束时持续时间 -1
- 首版不做持续时间（永久型，简化实现）

**交互**：
- 反弹伤害在攻击结算后触发
- 反弹伤害不受力量影响
- 反弹伤害可以杀死亡攻击者

---

### 2.8 生命回复（Regeneration）

| 属性 | 说明 |
|------|------|
| 标识 | `regeneration` |
| 类型 | Buff |
| 叠加方式 | 层数叠加 |
| 持续时间 | 每回合触发一次，触发后层数 -1 |
| 获取方式 | 首版仅敌人行为 |

**效果**：回合开始时回复等于当前层数的 HP。

**计算公式**：
```
回复 HP = min(当前层数, 最大HP - 当前HP)
回合后层数 -1
```

**消退规则**：
- 每次触发后层数 -1
- 降为 0 时移除

**交互**：
- 不超过最大 HP 上限

---

### 2.9 护盾（Shield / Plated Armor）

| 属性 | 说明 |
|------|------|
| 标识 | `shield` |
| 类型 | Buff |
| 叠加方式 | 线性叠加 |
| 持续时间 | 永久（整场战斗） |
| 获取方式 | 首版预留，不做获取途径（为能力牌预留设计空间） |

**效果**：回合结束时获得等于护盾层数的格挡。

**计算公式**：
```
回合结束获得格挡 = 护盾层数
```

**消退规则**：
- 不消退
- 若受到伤害时未攻击则 -1（首版简化：不消退）

**交互**：
- 与敏捷加成（先加敏捷再加护盾格挡）
- 获得的格挡仍然受回合结束清零规则影响

---

### 2.10 无力（Weak）

| 属性 | 说明 |
|------|------|
| 标识 | `weak` |
| 类型 | Debuff |
| 叠加方式 | 层数 = 持续回合数 |
| 持续时间 | 每回合结束层数 -1，到 0 消失 |
| 获取方式 | 卡牌（破甲击）、敌人行为 |

**效果**：造成的攻击伤害减少 25%（向下取整，最低 1）。

**计算公式**：
```
最终伤害 = floor((基础伤害 + 力量) × 0.75)，最低为 1
```

**示例**：
- 基础伤害 10，力量 0 → 无力时 floor(10×0.75) = 7 伤害
- 基础伤害 8，力量 2 → 无力时 floor(10×0.75) = 7 伤害

**消退规则**：
- 回合结束时层数 -1
- 层数为 0 时移除

**交互**：
- 与易伤互斥计算（同一目标同时有易伤和无力时：先算无力减伤，再算易伤增伤）
- 计算公式：`floor((基础伤害 + 力量) × 0.75) × 1.5`
- 不影响格挡

## 3. 伤害计算完整流程

### 3.1 计算顺序

```
1. 确定基础伤害（卡牌/行动数值）
2. 加上攻击者力量值
3. 若攻击者有无力状态：乘以 0.75（向下取整）
4. 若目标有易伤状态：乘以 1.5（向上取整）
5. 若攻击是多段：对每段独立计算步骤 1~4
6. 扣除目标格挡（穿刺跳过此步）
7. 扣除目标 HP
8. 触发命中后效果（荆棘反弹等）
```

### 3.2 格挡计算流程

```
1. 确定基础格挡值（卡牌/行动数值）
2. 加上敏捷值
3. 若有虚弱状态：乘以 0.75（向下取整）
4. 结果即为最终格挡值
```

## 4. 状态触发时机总表

| 时机 | 触发的状态 | 说明 |
|------|-----------|------|
| 回合开始（玩家/敌人） | 中毒（造成伤害）、生命回复 | 在抽牌前触发 |
| 出牌时 | 力量（影响伤害）、敏捷（影响格挡） | 计算时读取 |
| 被攻击命中后 | 荆棘（反弹伤害） | 攻击结算后触发 |
| 回合结束 | 格挡（清零）、易伤/虚弱/无力（层数-1） | 回合收束阶段 |
| 阶段切换 | 所有状态检查（Boss 阶段切换时敌人清 debuff） | 特殊时机 |

## 5. 状态间交互关系矩阵

### 5.1 Buff 与 Debuff 交互

| ↓ 施加方 \ 接收方 → | 力量 | 敏捷 | 易伤 | 虚弱 | 中毒 | 格挡 | 荆棘 | 无力 |
|---------------------|------|------|------|------|------|------|------|------|
| **力量** | 叠加 | — | — | — | — | — | — | — |
| **敏捷** | — | 叠加 | — | — | — | — | — | — |
| **易伤** | — | — | 叠加 | — | — | — | — | — |
| **虚弱** | — | — | — | 叠加 | — | — | — | — |
| **中毒** | — | — | — | — | 叠加 | — | — | — |

### 5.2 关键交互说明

| 交互 | 规则 |
|------|------|
| 易伤 + 无力（同一目标同时存在） | 无力先生效（×0.75），易伤后生效（×1.5），最终系数约 1.125 |
| 力量 + 多段攻击 | 每段都加力量值 |
| 虚弱 + 格挡 | 格挡值 ×0.75 |
| 中毒 + 格挡 | 中毒无视格挡，直接扣 HP |
| 荆棘 + 力量 | 荆棘伤害不受力量影响 |

## 6. 状态数据结构（技术参考）

```gdscript
# StatusEffect.gd
class_name StatusEffect
extends RefCounted

var id: String              # 状态标识
var stacks: int             # 当前层数
var source: String          # 来源（用于追踪）

# StatusData.gd — 资源定义
class_name StatusData
extends Resource

@export var id: String
@export var status_name: String
@export var description: String
@export var is_debuff: bool
@export var is_permanent: bool         # 是否永久（力量、敏捷）
@export var trigger_timing: String     # "turn_start" / "turn_end" / "on_hit" / "on_attack"
@export var icon: Texture2D            # 状态图标
@export var color: Color               # 状态颜色（Buff 绿色，Debuff 红色）
```

### 状态管理器接口

```gdscript
# StatusManager.gd — 挂载在战斗实体上
func apply_status(status_id: String, stacks: int, source: String = "") -> void
func remove_status(status_id: String) -> void
func get_status_stacks(status_id: String) -> int
func has_status(status_id: String) -> bool
func tick_turn_start() -> void      # 回合开始触发
func tick_turn_end() -> void        # 回合结束触发（层数递减等）
func calculate_damage(base_damage: int, is_player: bool) -> int  # 计算最终伤害
func calculate_block(base_block: int, is_player: bool) -> int    # 计算最终格挡
```
