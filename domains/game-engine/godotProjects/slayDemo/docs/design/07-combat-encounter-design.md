# 战斗遭遇设计

## 1. 遭遇组合规则

### 1.1 基本规则

1. **单敌人 vs 多敌人**：普通战斗可能出现 1~2 个敌人，精英和 Boss 战斗为单敌人
2. **同类型限制**：同一战斗中不会出现完全相同的两个敌人
3. **难度匹配**：敌人组合的总威胁值（HP 总和 + 伤害输出）必须匹配当前楼层的难度区间
4. **意图不重叠**：多敌人战斗中，同一回合不会所有敌人都做同一类型的行为（增加应对多样性）

### 1.2 遭遇生成规则

```
1. 根据当前楼层确定遭遇难度等级（Easy / Medium / Hard）
2. 从对应难度池中随机选择遭遇模板
3. 根据模板生成敌人实例（HP 在范围内随机）
4. 初始化敌人行为状态（每个敌人独立的行为计数器）
5. 进入战斗
```

### 1.3 难度等级定义

| 等级 | 楼层范围 | 敌人 HP 系数 | 说明 |
|------|---------|-------------|------|
| Easy | 层 1~4 | ×0.8 | 入门教学阶段 |
| Medium | 层 5~9 | ×1.0 | 标准难度 |
| Hard | 层 10~14 | ×1.2 | 后期挑战 |

> HP 系数应用于敌人 HP 范围。如绿皮小怪基础 HP 12~17，Easy 阶段为 10~14。

## 2. 普通遭遇组合设计

### 2.1 Easy 遭遇池（层 1~4）

#### 遭遇 E-01：单绿皮小怪

| 属性 | 数值 |
|------|------|
| 敌人数量 | 1 |
| 总 HP | 12~17 |
| 威胁评级 | ★☆☆☆☆ |
| 平均每回合伤害 | 5~8 |

**设计意图**：最简单的遭遇，作为教学关卡。玩家可以自由尝试出牌而不承受压力。

---

#### 遭遇 E-02：双绿皮小怪

| 属性 | 数值 |
|------|------|
| 敌人数量 | 2 |
| 总 HP | 24~34 |
| 威胁评级 | ★★☆☆☆ |
| 平均每回合伤害 | 10~14 |

**设计意图**：引入多敌人概念。两个小怪的伤害叠加后开始有威胁，但血量低可以逐个击杀。测试玩家是否理解"集中火力优先击杀"的策略。

---

#### 遭遇 E-03：单尖刺兽

| 属性 | 数值 |
|------|------|
| 敌人数量 | 1 |
| 总 HP | 20~26（Easy: 16~21） |
| 威胁评级 | ★★☆☆☆ |
| 平均每回合伤害 | 6~8 |

**设计意图**：第一个"有机制"的敌人。力量叠加让战斗拖长后更困难，鼓励快速击杀。

---

#### 遭遇 E-04：绿皮小怪 + 暗影法师

| 属性 | 数值 |
|------|------|
| 敌人数量 | 2 |
| 总 HP | 30~39（Easy: 24~31） |
| 威胁评级 | ★★★☆☆ |
| 平均每回合伤害 | 8~14 |

**设计意图**：经典的"肉盾 + 辅助"组合。暗影法师施加虚弱后，绿皮小怪的伤害不变但玩家的格挡效率下降。考验优先目标选择——先杀法师还是先杀小怪？

**推荐策略**：优先击杀暗影法师（HP 低，威胁大），然后处理绿皮小怪。

### 2.2 Medium 遭遇池（层 5~9）

#### 遭遇 M-01：暗影法师 + 尖刺兽

| 属性 | 数值 |
|------|------|
| 敌人数量 | 2 |
| 总 HP | 38~48 |
| 威胁评级 | ★★★☆☆ |
| 平均每回合伤害 | 10~16 |

**设计意图**：中期标准组合。暗影法师施加虚弱降低玩家防御，尖刺兽提供稳定输出。如果忽视暗影法师的强化仪式，后续尖刺兽会变得非常危险。

**推荐策略**：优先暗影法师，同时准备防御尖刺兽的蓄力攻击。

---

#### 遭遇 M-02：双石壳龟

| 属性 | 数值 |
|------|------|
| 敌人数量 | 2 |
| 总 HP | 48~60 |
| 威胁评级 | ★★★☆☆ |
| 平均每回合伤害 | 8~13 |

**设计意图**：高血量 + 高格挡的"磨血战"。测试玩家的牌组是否有足够的持续输出能力。如果牌组过度防御，这场战斗会非常漫长。

**推荐策略**：利用穿刺牌绕过格挡，或等待敌人攻击回合打出爆发。

| 威胁评级 | ★★★★☆ |
| 平均每回合伤害 | 10~16 |

**设计意图**：输出 + 坦克组合。尖刺兽提供持续伤害和力量叠加，石壳龟提供肉盾。需要玩家在"快速击杀尖刺兽"和"绕过石壳龟的格挡"之间做选择。

**推荐策略**：AOE 卡牌在此组合中很有价值，可以同时削减两个敌人的 HP。

### 2.3 Hard 遭遇池（层 10~14）

#### 遭遇 H-01：石壳龟 + 暗影法师 + 尖刺兽

| 属性 | 数值 |
|------|------|
| 敌人数量 | 3 |
| 总 HP | 62~78（Hard: 74~94） |
| 威胁评级 | ★★★★☆ |
| 平均每回合伤害 | 14~22 |

**设计意图**：后期高压力组合。三种敌人互补——坦克、辅助、输出。需要成型的牌组才能应对。

**推荐策略**：根据当前手牌决定优先级。通常：暗影法师（消除 Debuff 威胁）→ 尖刺兽（消除伤害输出）→ 石壳龟（最后处理）。

---

#### 遭遇 H-02：双尖刺兽 + 暗影法师

| 属性 | 数值 |
|------|------|
| 敌人数量 | 3 |
| 总 HP | 58~74（Hard: 70~89） |
| 威胁评级 | ★★★★★ |
| 平均每回合伤害 | 16~24 |

**设计意图**：后期最高压力的普通遭遇。两个尖刺兽都可能叠加力量，暗影法师叠加虚弱，伤害曲线急速上升。如果无法在 3~4 回合内击杀至少 1 个敌人，很难存活。

**推荐策略**：必须有爆发手段。易伤 + 高伤卡牌是关键。

## 3. 精英遭遇设计

### 3.1 精英遭遇规则

- 精英战斗为单人战斗（1 个精英敌人）
- 出现在固定楼层（层 7、层 11）
- 可选择绕行
- 击败后高奖励

### 3.2 精英遭遇列表

#### 精英遭遇 X-01：暴怒骑士（层 7）

| 属性 | 数值 |
|------|------|
| 敌人 | 暴怒骑士 ×1 |
| HP | 48~56 |
| 威胁评级 | ★★★★☆ |

**遭遇特点**：
- 固定行为模式，可预测但必须精确应对
- 回合 2（易伤）+ 回合 3（大伤害）是致命组合
- 需要在回合 3 前准备足够格挡（15+）或有能力打断

**检验能力**：牌组是否有足够的防御手段 + 持续输出

---

#### 精英遭遇 X-02：双头蛇（层 11）

| 属性 | 数值 |
|------|------|
| 敌人 | 双头蛇 ×1 |
| HP | 42~50（Hard: 50~60） |
| 威胁评级 | ★★★★★ |

**遭遇特点**：
- 中毒持续叠加，不打断会越来越痛
- 蜕皮再生拖延战斗节奏
- 需要在中毒叠加到危险水平前击杀

**检验能力**：牌组爆发输出能力 + HP 管理

## 4. Boss 战特殊规则

### 4.1 Boss 遭遇：深渊领主

| 属性 | 数值 |
|------|------|
| 敌人 | 深渊领主 ×1 |
| HP | 120~140 |
| 威胁评级 | ★★★★★ |

### 4.2 Boss 战特殊规则

#### 规则 1：阶段切换

Boss 有 3 个阶段（HP 100%→60%→30%→0%）。阶段切换时：

1. 播放阶段切换动画（Boss 变身/咆哮，持续约 1 秒）
2. Boss 清除所有 Debuff（易伤、中毒、虚弱、无力全部移除）
3. Boss 获得 5 点格挡
4. 切换到下一阶段的行为模式
5. 当前回合不中断，继续执行

#### 规则 2：意图预告

Boss 的意图比普通敌人更早显示（进入回合时立即显示，而非玩家回合开始时）。这给玩家更多时间规划，因为 Boss 的伤害数值更高，容错率更低。

#### 规则 3：不可逃跑

Boss 战不允许逃跑（首版不做逃跑机制，但 Boss 战特别标注）。

#### 规则 4：药水使用

Boss 战中允许使用药水，但格挡药水只在当回合有效。

### 4.3 Boss 战阶段详解

**第一阶段（100%~60% HP）**：

| 回合 | 意图 | 数值 | 应对策略 |
|------|------|------|---------|
| 1 | 攻击 | 10 伤害 | 轻松防御 |
| 2 | 攻击+防御 | 8 伤害 + 12 格挡 | 可以利用此回合积攒 |
| 3 | Debuff | 2 易伤 + 1 虚弱 | 准备防御 |
| 4 | 攻击 | 15 伤害 | 需要足够格挡 |

**设计意图**：建立节奏。回合 3 的 Debuff 预示回合 4 的高伤害，类似精英怪的套路但数值更高。

**第二阶段（60%~30% HP）**：

| 回合 | 意图 | 数值 | 应对策略 |
|------|------|------|---------|
| 1 | Buff | +3 力量 | 警告！下一回合伤害大增 |
| 2 | 攻击（强化） | 2x10 伤害（共 20） | 必须有 20+ 格挡 |
| 3 | Debuff | 3 易伤 | 紧急防御 |
| 4 | 攻击+防御 | 12 伤害 + 15 格挡 | 持续压力 |
| 5 | 攻击（强化） | 25 伤害 | 致命一击 |

**设计意图**：加大压力。力量 + 多段攻击让伤害翻倍。回合 1 的 Buff 是"预警"，如果玩家无法在回合 2 前消除力量或防御足够，将承受巨大伤害。

**第三阶段（30%~0% HP）**：

| 回合 | 意图 | 数值 | 应对策略 |
|------|------|------|---------|
| 1 | 特殊 | 2 易伤 + 2 虚弱 | 全面削弱 |
| 2 | 攻击（终极） | 30 伤害 | 必须完美防御或击杀 |
| 3 | 攻击+防御 | 15 伤害 + 20 格挡 | 持续施压 |

**设计意图**：最终考验。30 伤害是本 Demo 最高单次伤害，配合易伤和虚弱，防御难度极大。设计意图是让玩家在这个阶段全力输出，争取在回合 2 之前击杀 Boss。

### 4.4 Boss 战时长预估

| 阶段 | 预估回合数 | 预期伤害承受 | 说明 |
|------|-----------|-------------|------|
| 第一阶段 | 3~5 回合 | 15~30 HP | 稳定推进 |
| 第二阶段 | 4~6 回合 | 30~50 HP | 需要防御和输出平衡 |
| 第三阶段 | 2~4 回合 | 15~30 HP | 全力输出 |
| **总计** | **9~15 回合** | **60~110 HP** | 需要休息点回血和药水辅助 |

## 5. 遭遇数据结构（技术参考）

```gdscript
# EncounterData.gd
class_name EncounterData
extends Resource

@export var id: String                     # 遭遇唯一标识
@export var encounter_name: String         # 遭遇名称（调试用）
@export var difficulty: String             # "easy" / "medium" / "hard"
@export var enemies: Array[EnemySpawn]     # 敌人列表
@export var min_floor: int                 # 最低出现楼层
@export var max_floor: int                 # 最高出现楼层
@export var weight: int = 100              # 选取权重

# EnemySpawn.gd
class_name EnemySpawn
extends Resource

@export var enemy_data: EnemyData          # 敌人数据
@export var hp_override_min: int = -1      # 覆盖 HP 范围（-1 使用默认值）
@export var hp_override_max: int = -1
@export var position_offset: Vector2       # 在战斗场景中的位置偏移
```
