## 二、功能模块关系图

```
                    ┌────────────────┐
                    │   DataLoader   │  ← JSON 配置（cards/relics/potions/enemies）
                    │   (autoload)   │
                    └───────┬────────┘
                            │ 提供数据
              ┌─────────────┼────────────────┐
              ▼             ▼                ▼
       ┌──────────┐  ┌──────────────┐  ┌──────────────┐
       │GameState │  │ RunController│  │ SceneRouter  │
       │(状态持久化)│  │(流程控制器)  │  │(场景路由)    │
       └────┬─────┘  └──────┬───────┘  └──────┬───────┘
            │               │                  │
            │ 读写           │ 驱动             │ 切换
            ▼               ▼                  ▼
       ┌─────────────────────────────────────────────┐
       │              Scene Layer                     │
       │  battle / map / shop / reward / rest / ...   │
       └──────────────┬──────────────────────────────┘
                      │ 调用
          ┌───────────┼──────────────┐
          ▼           ▼              ▼
   ┌────────────┐ ┌────────┐ ┌────────────┐
   │BattleCtrl  │ │MapGen  │ │ShopService │
   │EffectRunner│ │RewardSvc│ │EventService│
   │StatusMgr   │ │RelicSvc │ │PotionSvc  │
   └────────────┘ └────────┘ └────────────┘
          │
          ▼
   ┌────────────────────────────────┐
   │  AudioManager / VFXManager    │
   │  (解耦，任意场景可调用)          │
   └────────────────────────────────┘
```

**关键依赖关系**：
- `RunController` 是最重要的流程控制器，管理战斗结束→奖励→地图→下一节点的全部状态流转
- `GameState` 是数据中心，所有场景都从它读取状态，不直接相互通信
- `DataLoader` 在游戏启动时 `load_all()`，后续为只读，任何系统均可查询

## 三、当前可玩性评估

### 3.1 可玩闭环完整度：85%

**可以玩通的部分**：
- 从主菜单开始 → 随机地图 → 战斗 → 奖励/商店/休息/事件 → Boss → 结算
- 存档继续游戏
- 多种卡组构建路径（力量流、能量流）
- 精英/Boss 多阶段战斗

**影响可玩性的缺口**：
- 商店删牌无确认弹窗（误操作风险）
- 遗物无图标（视觉辨识度低）
- 部分卡牌描述与实际效果有出入（腐化、双重点击）
- 没有新手引导

### 3.2 风险评估

| 风险 | 等级 | 说明 |
|------|------|------|
| **rare 卡描述与实现完全不符** | 🔴 高 | `腐化`描述"技能0费"实际是"力量+3"；`双重点击`描述"攻击再触发"实际是"抽1张"。玩家遇到后严重失去信任 |
| 遗物图标覆盖率仅 31% | 🔴 高 | 16 个遗物只有 5 个有图标，boss 遗物全无图标 |
| 商店误操作 | 🟡 中 | 删错牌影响本局体验，可能劝退 |
| 复玩性不足 | 🟡 中 | 内容量达到 1~2 局后玩家流失 |
| 敌人图片语义错位 | 🟡 中 | 史莱姆王显示蘑菇、盾卫显示骷髅 |
| 技术债（seed 非确定性）| 🟢 低 | 不影响玩家，影响测试稳定性 |
