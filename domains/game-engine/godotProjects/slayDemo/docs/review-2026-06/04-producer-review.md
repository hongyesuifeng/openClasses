## 二、功能模块关系图

```
                    ┌────────────────┐
                    │   DataLoader   │  ← JSON 配置（cards/relics/potions/enemies）
                    │   (autoload)   │
                    └───────┬────────┘
                            │ 提供数据
              ┌─────────────┼────────────────┐
              ▼             ▼                ▼
       ┌──────────┐  ┌──────────────┐  ┌──────────────┐
       │GameState │  │ RunController│  │ SceneRouter  │
       │(状态持久化)│  │(流程控制器)  │  │(场景路由)    │
       └────┬─────┘  └──────┬───────┘  └──────┬───────┘
            │               │                  │
            │ 读写           │ 驱动             │ 切换
            ▼               ▼                  ▼
       ┌─────────────────────────────────────────────┐
       │              Scene Layer                     │
       │  battle / map / shop / reward / rest / ...   │
       └──────────────┬──────────────────────────────┘
                      │ 调用
          ┌───────────┼──────────────┐
          ▼           ▼              ▼
   ┌────────────┐ ┌────────┐ ┌────────────┐
   │BattleCtrl  │ │MapGen  │ │ShopService │
   │EffectRunner│ │RewardSvc│ │EventService│
   │StatusMgr   │ │RelicSvc │ │PotionSvc  │
   └────────────┘ └────────┘ └────────────┘
          │
          ▼
   ┌────────────────────────────────┐
   │  AudioManager / VFXManager    │
   │  (解耦，任意场景可调用)          │
   └────────────────────────────────┘
```

**关键依赖关系**：
- `RunController` 是最重要的流程控制器，管理战斗结束→奖励→地图→下一节点的全部状态流转
- `GameState` 是数据中心，所有场景都从它读取状态，不直接相互通信
- `DataLoader` 在游戏启动时 `load_all()`，后续为只读，任何系统均可查询
