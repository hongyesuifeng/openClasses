> 日期：2026-06  版本：当前主分支

## 一、核心玩法闭环评估

### 1.1 已实现的核心循环

```
主菜单 → 地图选择 → 战斗 → 奖励（牌/遗物/药水）→ 地图 → 商店/休息/事件/宝箱 → Boss → 结算
```

这条主循环**完全可跑通**，玩家从开始到结束有完整的体验路径。关键决策点已全部实现：

| 决策点 | 实现状态 | 说明 |
|--------|---------|------|
| 卡牌选择（战斗奖励） | ✅ 完整 | 3选1 + 跳过，支持升级模式 |
| 地图路线选择 | ✅ 完整 | DAG 随机地图，可见分支 |
| 休息点选择 | ✅ 完整 | 回血 vs 升级牌 |
| 商店购买/删牌 | ✅ 完整 | 含遗物/药水商品 |
| 事件选择 | ✅ 完整 | 支持选牌子流程（移除/升级/变换） |
| 药水使用时机 | ✅ 完整 | 战斗中主动使用 |

### 1.2 战斗系统深度

**状态系统（11 种）**

| 分类 | 状态 | 机制 |
|------|------|------|
| 增益（永久）| 力量、敏捷、堡垒 | 回合不递减 |
| 增益（触发）| 再生、仪式、金属化 | 回合开始/结束触发 |
| 减益（递减）| 易伤、无力、虚弱 | 回合结束 -1 层 |
| 毒伤（递减）| 中毒 | 回合开始 -HP，层数 -1 |
| 被动反伤 | 荆棘 | 被攻击触发 |

**效果类型（13 种）**：damage / block / draw / gain_strength / apply_status / gain_barricade / heal / multi_damage / aoe_damage / gain_energy / exhaust / summon / lose_hp

**缺失的重要机制**：
- **卡牌描述与实际效果严重不符**（高风险）：
  - `腐化`：描述"技能牌费用变为 0，打出后消耗"，实际效果是 `gain_strength 3`（增加 3 层力量）
  - `双重点击`：描述"本回合第一张攻击牌额外触发一次"，实际效果是 `draw 1`（抽 1 张牌）
  - 这两张牌是 rare 卡，玩家会频繁获得，描述与效果的错位严重影响信任度
- 连击计数（如双重点击的"再次触发"语义）需要 effect_runner 新增 `repeat` 触发机制才能真正实现
- 腐化牌（技能牌 0 费但出牌消耗）需要 BattleController 层的卡牌费用动态修改机制

## 二、内容规模评估

### 2.1 卡牌池（52 张）

```
攻击牌 21 张 | 技能牌 26 张 | 力量牌 5 张
starter 3 | common 20 | uncommon 18 | rare 11
```

**优点**：
- 稀有度分布合理，uncommon 最多（18），rare 适中（11）
- 攻击/技能/力量比例接近原作战士牌组风格
- 全部 52 张牌都有升级版本

**不足**：
- 当前 52 张卡几乎全是"战士"风格，**缺乏差异化定位**——没有"毒流"、"格挡流"、"手牌流"等特定方向的卡组核心
- 毒系仅 2 张（poison_dart、venomous_stab），不足以构成独立流派
- 5 张 Power 牌偏少，Power 牌是杀戮尖塔构建卡组策略的核心，目前玩家很难围绕 Power 牌构建

### 2.2 遗物池（16 个）

```
common 5 | uncommon 3 | rare 3 | boss 4 | starter 1
```

**已实现效果类型**：battle_start_block / first_turn_energy / max_hp / card_gain_heal / battle_win_gold / draw_per_turn

**不足**：
- 遗物效果类型只有 6 种，与卡牌的 13 种效果类型完全脱节——没有"减少特定卡牌费用"、"手牌上限增加"、"打出攻击牌触发"等互动性遗物
- Boss 遗物 4 个全是数值加成，缺乏改变玩法规则的遗物（如杀戮尖塔的"冰火交融"）
- philosopher_stone 的设计（敌人获得力量）有惩罚感，但目前补偿（+1 抽牌）较弱

### 2.3 敌人池（14 种）

```
normal 8 | elite 4 | boss 2
```

**优点**：
- 精英和 Boss 全部有两阶段 AI，战斗有张力
- 敌人类型有差异：召唤流（史莱姆王）、格挡流（石像哨兵）、减益流（诅咒法师）

**不足**：
- 普通敌人（8种）行为模式偏简单，多数为单纯攻击
- 没有"意图欺骗"类敌人（声称防御实际攻击）
- Boss 只有 2 个，玩家每次都遇到相同 Boss，复玩性低

## 三、玩法深度与构建多样性

### 3.1 当前可行的卡组流派

根据现有卡牌/遗物，玩家理论上可以构建的流派：

| 流派 | 核心牌 | 核心遗物 | 可行性 |
|------|--------|---------|--------|
| 力量叠加流 | 燃起斗志+大屠杀+重锤 | 战鼓+水晶球 | ✅ 可行 |
| 格挡反弹流 | 堡垒+铁甲防御+强化 | 符文穹顶 | ⚠️ 弱 |
| 能量爆发流 | 献祭+肾上腺素+旋风斩 | 灯笼 | ✅ 可行 |
| **毒流** | **剧毒针+毒雾弥漫+淬毒+毒镖** | 无专属 | ✅ 可行（V1.0新增）|
| 仪式缓速流 | 仪式+金属化+哨兵 | 燃烧之血 | ⚠️ 弱 |

**主要问题**：流派差异化不足，大多数胜利路径都是"积累力量+大伤害"，缺乏多样化的获胜条件。

### 3.2 复玩性评估

- 地图随机生成：✅ 每局路线不同
- 初始遗物随机：✅ burning_blood starter 遗物
- 卡牌奖励随机：✅ 按稀有度权重
- 事件随机：⚠️ 只有固定的 run_config 事件节点，地图事件不随机
- 敌人遭遇随机：✅ 10 种普通遭遇随机分配
- **问题**：没有角色选择、没有詛咒系统、没有成就解锁内容，长期复玩动力不足

### 4.1 反馈层

| 反馈类型 | 状态 |
|---------|------|
| 伤害数字飘字 | ✅ 已实现（红/绿/蓝区分） |
| 卡牌打出动画 | ✅ 飞出+渐隐 |
| 卡牌悬浮放大 | ✅ 已实现 |
| 敌人受击晃动 | ✅ 已实现 |
| 回合切换横幅 | ✅ 淡入淡出横幅 |
| VFX 特效 | ✅ slash/fire/poison/magic 四种 |
| BGM 场景切换 | ✅ 全 9 个场景覆盖 |
| SFX | ✅ 战斗/商店/事件/休息全覆盖 |

**评估**：反馈层已相当完善，战斗过程有视觉和听觉层次感。

### 4.2 信息传达问题

- **卡牌描述不规范**：部分描述用中文括号，部分用英文括号；"打出后消耗"等关键词没有统一标注格式
- **状态 tooltip**：已实现，但部分状态描述偏短（如"格挡 +{stacks}"没有解释"每次获得格挡时生效"）
- **遗物没有图标资源**：UI 显示为纯文字，缺乏视觉辨识度
- **商店删牌无二次确认**：误操作风险高
- **升级对比缺失**：升级前后效果需要玩家自行记忆，没有 Before/After 对比

## 六、最终游戏形态愿景

**目标定位**：单机卡牌 Roguelike，类杀戮尖塔，移动端优先（竖屏友好），单局 30-60 分钟

**内容规模目标**：
- 卡牌：3 个角色各 75+ 张（含升级版）
- 遗物：60+ 个，每类稀有度 15+
- Act：3 个，每 Act 3 个 Boss
- 敌人：每 Act 15+ 种
- 状态/诅咒：各 15+ 种

**差异化特色**：
- 引入"遗物互动组合"作为构建乐趣核心（而非只有卡牌之间的组合）
- 每局开局遗物选择（3选1）替代固定 starter 遗物
- 动态事件分支（事件结果影响后续事件出现概率）
