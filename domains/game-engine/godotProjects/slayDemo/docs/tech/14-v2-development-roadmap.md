## 二、下一阶段：地图路线系统

目标是把固定节点数组推进为可选择路线的 Act 1 地图。首版先做静态配置地图，后续再做随机生成。

### 2.1 首版范围

```text
Act 1 地图
├── 多层节点
├── 普通战斗 / 精英 / 商店 / 休息 / Boss
├── 节点之间用 next_nodes 限定路线
├── 玩家只能选择已解锁节点
├── 完成节点后返回地图
└── Boss 完成后进入结算
```

首版不做:

- 随机地图生成
- 事件节点
- 宝箱节点
- 路线预览动画
- 遗物/药水奖励

### 2.2 需要新增或修改的模块

| 文件 | 变更 |
|------|------|
| `data/run_v1.json` | 增加 `act1_map_run` 与 `map_nodes` |
| `GameState` | 保存地图节点、已完成节点、可选节点、当前地图节点 |
| `RunController` | 支持开始地图 run、选择地图节点、完成节点后返回地图 |
| `SceneRouter` | 新增 `map` 场景 |
| `MapScene` | 展示地图节点并处理选择 |
| `DataLoader` | 校验 map 节点引用 |
| 测试 | 增加地图路线单元/集成测试 |

## 三、后续路线

### P1：遗物系统

首版 5 个以内:

- 战斗开始获得格挡
- 第一回合 +1 能量
- 获得卡牌时回血
- 击败敌人获得金币
- 最大 HP +10

### P1：事件与宝箱

事件首版:

- 扣血换金币
- 扣血删牌
- 获得随机卡
- 升级随机卡

宝箱首版:

- 给金币
- 给遗物
- 给稀有卡

### P2：经济曲线

- 战斗胜利掉金币
- 精英/Boss 奖励差异
- 商店价格按层数和稀有度调整
- 删牌价格递增持久化

### P3：表现与体验

- 主菜单正式化
- 地图节点图标与路径线
- 状态 tooltip
- 战斗动画继续细化
- 音效与背景音乐
