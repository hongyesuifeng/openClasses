## 二、V2 开发阶段规划

### 阶段 1: 核心战斗完善 (优先级 P1)

**目标**: 让战斗体验完整、流畅

#### 1.1 状态效果系统完善

```
待完成项:
├── 补充护盾(Shield)效果 - 回合结束获得格挡
├── 补充敏捷(Dexterity)效果 - 格挡加成（已定义未使用）
├── 状态UI显示 - 敌人/玩家状态图标和层数
└── 状态触发日志优化
```

**涉及文件**:
- `status_manager.gd` - 补充护盾逻辑
- `battle_scene.gd` - 状态UI渲染

### 阶段 2: 内容扩展 (优先级 P2)

**目标**: 丰富游戏内容，提升可玩性

#### 2.1 卡牌扩展

**当前**: 10张卡牌
**目标**: 30+张卡牌

```
卡牌分类扩展:
├── 攻击牌 (15张)
│   ├── 基础: 打击、重击、痛击、铁波
│   ├── 多段: 连击(2x3)、暴风雪(3x2)
│   └── 特殊: 穿刺(无视格挡)、处决(低血量加成)
│
├── 技能牌 (12张)
│   ├── 防御: 防御、快速格挡、耸肩无视、铁壁
│   ├── 过牌: 战斗专注、战术翻滚
│   └── 增益: 燃起斗志、蓄力、战斗怒吼
│
└── 能力牌 (3张) - Power卡
    ├── 恶魔形态: 回合开始+2力量
    ├── 金属化: 回合结束获得格挡
    └── 狂暴: 受伤时获得力量
```
