# GodotProjects 多角色 Agent 系统

本目录下的游戏开发项目使用多角色 Agent 系统支持学习和实践。该系统帮助用户从不同专业视角理解游戏开发。

---

## 角色概览

| 角色 | 英文名 | 核心职责 | 关注领域 |
|------|--------|---------|---------|
| 游戏制作人 | Producer | 项目把控、里程碑管理、跨角色协调 | 进度、范围、风险 |
| 游戏开发工程师 | Developer | 技术架构、代码实现、性能优化 | 技术、架构、工具 |
| 游戏美术 | Artist | 视觉风格、资源管理、UI设计 | 美术、视觉、资源 |
| 游戏策划 | Designer | 玩法设计、数值平衡、内容创作 | 机制、数值、体验 |

---

## 视角切换机制

### 使用方式

**Claude Code**: 使用 `/role-switch <角色名>` 命令
**OpenCode**: 使用 MCP 工具调用
**飞书 Agent**: 直接询问"从XX视角分析..."

### 输出结构

每个角色在分析问题时，会按以下结构输出：

```markdown
## {角色名}视角: {问题}

### 我看到了什么
- 从这个角色视角观察到的事物

### 我关心什么
- 这个角色视角的优先级和关注点

### 我会怎么做
- 这个角色视角的建议行动

### 为什么（我的视角）
- 这个角色视角的理由和依据

### 其他角色可能怎么看
- 制作人: {...}
- 开发者: {...}
- 美术: {...}
- 策划: {...}
```

## 多工具兼容

本系统支持多个 Coding Agent 工具：

| 工具 | 配置位置 | 使用方式 |
|------|---------|---------|
| Claude Code | `CLAUDE.md` + `.claude/commands/` | `/role-switch <角色>` |
| OpenCode | `.opencode/opencode.json` | MCP 工具调用 |
| 飞书 Agent | 读取 `.agents/roles/` | 直接询问视角 |

## 学习进度模型

```
Level 1: 观察者 - 看着 Agent 输出视角分析，理解差异
Level 2: 参与者 - 自己先试着分析，再对比 Agent 的输出
Level 3: 协作者 - 在实际工作中切换视角，发现盲区
Level 4: 内化者 - 已掌握多视角思维，能主动切换
```

---

## 与飞书协调 Agent 的协作

```
飞书协调 Agent（进度跟踪、视角调度）
        ↓
    读取角色定义
        ↓
本地 Coding Agent（代码实现、工具集成）
```

- 飞书 Agent 负责协调和视角分析，不写代码
- 本地 Coding Agent 负责具体实现和执行
