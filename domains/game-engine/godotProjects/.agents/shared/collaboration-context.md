## 协作流程

### 视角切换请求

当需要某个角色的视角分析时：

```markdown
## 视角请求

**请求角色**: {producer|developer|artist|designer}
**问题描述**: {具体问题}
**请求方**: {用户/飞书Agent/其他角色}
**时间**: {时间戳}
```

### 跨角色评审请求

当需要其他角色评审工作时：

```markdown
## 评审请求

**请求方角色**: {角色}
**目标角色**: {角色}
**评审内容**: {文件路径或描述}
**截止时间**: {时间}
**状态**: {待评审/评审中/已完成}
```

### 决策记录

所有跨角色决策都应在此记录：

```markdown
## 决策记录

**日期**: {日期}
**决策内容**: {描述}
**参与角色**: {角色列表}
**决策理由**: {为什么}
**影响范围**: {哪些内容受影响}
```

## 协作规范

### 1. 角色边界
- 每个角色只在自己职责范围内做决策
- 跨边界决策需要相关角色参与
- 冲突由制作人裁决

### 2. 信息同步
- 所有决策记录在本文件
- 任务更新同步到对应的 task-{role}.md
- 学习收获记录到 knowledge-base/

### 3. 飞书 Agent 交互
- 飞书 Agent 读取角色定义提供视角分析
- 飞书 Agent 不直接修改代码
- 具体实现交给本地 Coding Agent
