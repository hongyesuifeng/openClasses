# 第四讲：Transformer 架构详解

> 对应视频：第四讲、第五讲 - 语言模型内部运作机制 / Transformer 架构详解

## 本章概要

Transformer 是现代大语言模型的基石。本章将深入剖析 Transformer 的架构设计和工作原理。

---

## 1. Transformer 的诞生

### 1.1 历史背景

```
序列模型演进
────────────────────────────────────────────────────────►

RNN (1986)        LSTM (1997)       Transformer (2017)

• 顺序处理         • 门控机制         • 并行处理
• 梯度消失         • 长期依赖         • 全局注意力
• 无法并行         • 仍顺序处理        • 可扩展性强

关键突破：Attention Is All You Need (2017)
Google 论文，彻底改变了 NLP 领域
```

### 1.2 核心创新

| 创新 | 描述 |
|------|------|
| **Self-Attention** | 自注意力机制，捕获序列内关系 |
| **Positional Encoding** | 位置编码，保留位置信息 |
| **并行计算** | 取消循环，支持完全并行 |
| **残差连接** | 解决深层网络训练问题 |

## 3. Self-Attention 机制

### 3.1 核心思想

**Self-Attention（自注意力）**：序列中每个位置都能关注到其他所有位置。

```
自注意力示例
────────────────────────────────────────────────────────

句子: "The cat sat on the mat"

处理 "sat" 时，模型可以同时关注：
• "cat" - 谁在坐？
• "mat" - 坐在哪里？
• "The" - 定冠词信息

┌─────────────────────────────────────────────────────┐
│                                                     │
│   The    cat    sat    on    the    mat            │
│    │      │      │      │      │      │            │
│    └──────┴──────┼──────┴──────┴──────┘            │
│                  │                                  │
│            sat 关注的所有位置                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 3.2 Query, Key, Value

```
QKV 机制
────────────────────────────────────────────────────────

输入 X ──┬──→ 线性变换 ──→ Query (Q)  "我在找什么？"
         │
         ├──→ 线性变换 ──→ Key (K)    "我是什么？"
         │
         └──→ 线性变换 ──→ Value (V)  "我的内容是什么？"

计算过程：
┌─────────────────────────────────────────────────────┐
│                                                     │
│  1. Q × Kᵀ = Attention Scores (注意力分数)         │
│                                                     │
│  2. Scores / √dₖ = 缩放（防止梯度消失）             │
│                                                     │
│  3. Softmax = Attention Weights (注意力权重)        │
│                                                     │
│  4. Weights × V = Output (加权求和)                 │
│                                                     │
└─────────────────────────────────────────────────────┘

公式：
Attention(Q, K, V) = softmax(QKᵀ / √dₖ) × V
```

### 3.3 计算示例

```
简化示例：2 个 token
────────────────────────────────────────────────────────

输入: "I love"
X = [[1, 0], [0, 1]]  # 简化的 embedding

Wq = [[1, 0], [0, 1]]
Wk = [[1, 0], [0, 1]]
Wv = [[1, 0], [0, 1]]

Q = X × Wq = [[1, 0], [0, 1]]
K = X × Wk = [[1, 0], [0, 1]]
V = X × Wv = [[1, 0], [0, 1]]

Scores = Q × Kᵀ = [[1, 0], [0, 1]]
Weights = softmax(Scores) = [[0.73, 0.27], [0.27, 0.73]]
Output = Weights × V = [[0.73, 0.27], [0.27, 0.73]]
```

### 3.4 Multi-Head Attention

```
多头注意力
────────────────────────────────────────────────────────

为什么要多头？
• 不同的头关注不同的特征
• 类似 CNN 的多个卷积核

┌─────────────────────────────────────────────────────┐
│                                                     │
│   Input                                             │
│     │                                               │
│     ├──────┬──────┬──────┬──────┐                  │
│     ↓      ↓      ↓      ↓      │                  │
│   Head1  Head2  Head3  Head4   ...                 │
│     │      │      │      │       │                  │
│     └──────┴──────┴──────┴──────┘                  │
│                   │                                 │
│              Concat + Linear                        │
│                   │                                 │
│               Output                               │
│                                                     │
└─────────────────────────────────────────────────────┘

每个头学习不同的注意力模式：
• Head 1: 语法关系
• Head 2: 语义关系
• Head 3: 位置关系
• ...
```

## 4. 位置编码（Positional Encoding）

### 4.1 为什么需要位置编码？

```
问题：Self-Attention 是位置无关的
────────────────────────────────────────────────────────

句子 A: "狗咬人"
句子 B: "人咬狗"

对 Self-Attention 来说，这两种输入的表示是一样的！
因为它不知道词的顺序。

解决方案：给每个位置加一个独特的编码
```

### 4.2 正弦位置编码

```
Positional Encoding 公式
────────────────────────────────────────────────────────

PE(pos, 2i)   = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

其中：
• pos: 位置 (0, 1, 2, ...)
• i: 维度索引
• d: embedding 维度

特点：
• 每个位置有唯一的编码
• 相对位置可学习
• 可泛化到任意长度
```

### 4.3 可视化

```
位置编码热力图（简化）
────────────────────────────────────────────────────────

位置\维度  0    1    2    3    4    5    6    7
────────────────────────────────────────────────
   0     █░   ░█   █░   ░█   █░   ░█   █░   ░█
   1     ██   ░░   █░   ░█   █░   ░█   █░   ░█
   2     ██   ██   █░   ░█   █░   ░█   █░   ░█
   3     ░█   ██   ██   ░█   █░   ░█   █░   ░█
   4     ░░   ░█   ██   ██   █░   ░█   █░   ░█
   ...

不同维度捕获不同频率的位置信息
```

## 5. Feed Forward Network

### 5.1 结构

```
FFN 结构
────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────┐
│                                                     │
│   Input (d_model)                                   │
│        │                                            │
│        ↓                                            │
│   Linear(d_model → d_ff)    ← 通常 d_ff = 4 × d    │
│        │                                            │
│        ↓                                            │
│   Activation (ReLU/GELU)                            │
│        │                                            │
│        ↓                                            │
│   Linear(d_ff → d_model)                            │
│        │                                            │
│        ↓                                            │
│   Output (d_model)                                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 5.2 作用

```
FFN 的作用
────────────────────────────────────────────────────────

Self-Attention: 信息聚合（词与词之间的关系）
FFN:           信息变换（对每个位置独立处理）

类比：
• Attention = 通信（不同位置交换信息）
• FFN = 思考（每个位置独立处理信息）

组合使用：
Attention → FFN → Attention → FFN → ...
```

## 6. 残差连接与 Layer Norm

### 6.1 残差连接（Residual Connection）

```
残差连接
────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────┐
│                                                     │
│   x ───────────────────────────┐                   │
│   │                            │                   │
│   ↓                            │                   │
│   Layer(x)                     │                   │
│   │                            │                   │
│   ↓                            ↓                   │
│   +  ←─────────────────────────┘                   │
│   │                                                │
│   ↓                                                │
│   Output = x + Layer(x)                            │
│                                                     │
└─────────────────────────────────────────────────────┘

作用：
• 缓解梯度消失
• 允许训练更深的网络
• 保留原始信息
```

### 6.2 Layer Normalization

```
LayerNorm
────────────────────────────────────────────────────────

对每个样本的所有特征进行归一化：

Input: [x₁, x₂, x₃, ..., xₐ]

μ = mean(x₁, x₂, ..., xₐ)
σ = std(x₁, x₂, ..., xₐ)

Output: [(x₁-μ)/σ, (x₂-μ)/σ, ..., (xₐ-μ)/σ] × γ + β

作用：
• 稳定训练
• 加速收敛
• 减少对初始化的敏感度
```

### 6.3 完整的 Transformer Block

```
Transformer Block
────────────────────────────────────────────────────────

┌─────────────────────────────────────────────────────┐
│                                                     │
│   x ─────────────────────────────────┐             │
│   │                                  │             │
│   ↓                                  │             │
│   LayerNorm                          │             │
│   │                                  │             │
│   ↓                                  │             │
│   Self-Attention                     │             │
│   │                                  │             │
│   ↓                                  ↓             │
│   +  ←───────────────────────────────┘             │
│   │                                                │
│   │  ─────────────────────────────────┐            │
│   │                                  │            │
│   ↓                                  │            │
│   LayerNorm                          │            │
│   │                                  │            │
│   ↓                                  │            │
│   FFN                                │            │
│   │                                  │            │
│   ↓                                  ↓            │
│   +  ←───────────────────────────────┘            │
│   │                                                │
│   ↓                                                │
│   Output                                           │
│                                                     │
└─────────────────────────────────────────────────────┘

Pre-Norm vs Post-Norm：
• Pre-Norm: LN 在 Attention/FFN 之前（现代做法）
• Post-Norm: LN 在之后（原始论文）
```

### 7.2 Masked Self-Attention

```
为什么需要 Mask？
────────────────────────────────────────────────────────

生成任务：只能看到当前位置之前的内容

句子: "The cat sat on the mat"

处理 "sat" 时：
✅ 可以看到: "The", "cat"
❌ 不能看到: "on", "the", "mat"

实现方式：
在 Attention Scores 上加负无穷大的 mask

原始 Scores:
     The  cat  sat  on  the  mat
The [1.0, 0.5, 0.3, 0.2, 0.1, 0.1]
cat [0.5, 1.0, 0.4, 0.3, 0.2, 0.1]
sat [0.3, 0.4, 1.0, 0.5, 0.3, 0.2]
on  [0.2, 0.3, 0.5, 1.0, 0.4, 0.3]
the [0.1, 0.2, 0.3, 0.4, 1.0, 0.5]
mat [0.1, 0.1, 0.2, 0.3, 0.5, 1.0]

Masked (上三角设为 -∞):
     The  cat  sat  on  the  mat
The [1.0, -∞,  -∞,  -∞,  -∞,  -∞ ]
cat [0.5, 1.0, -∞,  -∞,  -∞,  -∞ ]
sat [0.3, 0.4, 1.0, -∞,  -∞,  -∞ ]
...

Softmax 后，-∞ 变为 0
```

自回归生成

## 8. 模型规模与参数

### 8.1 参数计算

```
参数量计算
────────────────────────────────────────────────────────

假设：
• d_model = 12288 (隐藏维度)
• n_heads = 96 (注意力头数)
• n_layers = 96 (层数)
• vocab_size = 50257 (词表大小)

每层参数：
• QKV 投影: 3 × d_model × d_model = 3 × 12288²
• Output 投影: d_model × d_model = 12288²
• FFN: 2 × d_model × 4×d_model = 8 × 12288²
• LayerNorm: ~0

每层总计 ≈ 12 × d_model² ≈ 1.8B 参数

总参数 ≈ n_layers × 12 × d_model²
      ≈ 96 × 1.8B
      ≈ 175B 参数 (GPT-3 规模)
```

### 8.2 各代模型对比

| 模型 | 参数量 | 层数 | 隐藏维度 | 注意力头 |
|------|--------|------|----------|----------|
| GPT-1 | 117M | 12 | 768 | 12 |
| GPT-2 | 1.5B | 48 | 1600 | 25 |
| GPT-3 | 175B | 96 | 12288 | 96 |
| GPT-4 | ~1.8T(估计) | ~120 | ~20000(估计) | ~160 |

## 关键要点总结

1. **Transformer 核心**：Self-Attention + FFN + 残差连接 + LayerNorm
2. **Self-Attention**：Query-Key-Value 机制，捕获全局依赖
3. **位置编码**：为序列添加位置信息
4. **GPT**：Decoder-only 架构，Masked Self-Attention，自回归生成
5. **规模定律**：参数量 ↑ → 能力 ↑
