## 1. 语言模型是什么？

### 1.1 定义

**语言模型（Language Model）** 是一种能够**理解和生成人类语言**的统计模型。

```
┌─────────────────────────────────────────────────────────┐
│                    语言模型本质                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   输入：前面的文字                                       │
│         "今天天气真"                                     │
│              ↓                                          │
│         ┌─────────┐                                    │
│         │ 语言模型 │                                    │
│         └─────────┘                                    │
│              ↓                                          │
│   输出：下一个词的概率分布                               │
│         好: 0.35                                        │
│         不错: 0.25                                      │
│         热: 0.15                                        │
│         冷: 0.10                                        │
│         ...                                             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.2 核心任务：下一个词预测

语言模型的核心能力是**预测下一个词**：

```
输入序列          预测
──────────────────────────────
"今天"         →  "天气"
"今天天气"      →  "真"
"今天天气真"    →  "好"
"今天天气真好"  →  "！"
```

### 1.3 从 N-gram 到神经网络

```
语言模型演进历程
────────────────────────────────────────────────────►

N-gram 模型          神经网络模型          大语言模型
(统计方法)           (RNN/LSTM)           (Transformer)

• 简单高效           • 能捕获长距离依赖    • 超大规模参数
• 无法理解上下文     • 训练较慢           • 涌现能力
• 数据稀疏问题       • 并行困难           • 通用能力强

1980s-2000s          2010s                2017-至今
```

## 2. Tokenization：文本的数字化

### 2.1 什么是 Token？

**Token（词元）** 是语言模型处理文本的基本单位。

```
原始文本：
"Hello, World!"

Tokenization 过程：
┌────────────────────────────────────────────────────────┐
│                                                        │
│   "Hello, World!"                                      │
│         ↓                                              │
│   ["Hello", ",", " World", "!"]                       │
│         ↓                                              │
│   [15496, 11, 2159, 0]                                │
│         ↓                                              │
│   模型处理                                              │
│                                                        │
└────────────────────────────────────────────────────────┘
```

### 2.2 Tokenization 方法

| 方法 | 描述 | 例子 |
|------|------|------|
| **字符级** | 每个字符一个 Token | "hello" → ["h","e","l","l","o"] |
| **词级** | 每个词一个 Token | "hello world" → ["hello", "world"] |
| **子词级** | 常用子单元 | "unhappiness" → ["un", "happy", "ness"] |

### 2.3 BPE（Byte Pair Encoding）

最常用的 Tokenization 方法：

```
BPE 算法过程：
─────────────────────────────────────────────
1. 从字符级开始
   ["h", "e", "l", "l", "o"]

2. 合并最高频的相邻对
   ["he", "l", "l", "o"]

3. 继续合并
   ["hel", "l", "o"]

4. 最终
   ["hello"]

优点：
• 能处理未知词
• 词表大小可控
• 适合多语言
```

### 2.4 Token 与成本

```
Token 数量计算示例（英文）：
─────────────────────────────────────────────
"Hello, World!"           ≈ 4 tokens
"The quick brown fox..."  ≈ 20 tokens

Token 数量计算示例（中文）：
─────────────────────────────────────────────
"你好世界"                 ≈ 4-8 tokens
"今天天气真好"             ≈ 6-10 tokens

经验法则：
• 英文：1 token ≈ 4 字符 ≈ 0.75 词
• 中文：1 token ≈ 1-2 汉字
```

## 3. 语言模型如何学习

### 3.1 训练数据

```
训练数据来源
────────────────────────────────────────────────────────
┌─────────────────┐  ┌─────────────────┐  ┌────────────┐
│    互联网文本    │  │    书籍文档     │  │  代码仓库  │
│                 │  │                 │  │            │
│ • 网页内容      │  │ • 图书         │  │ • GitHub   │
│ • 新闻文章      │  │ • 论文         │  │ • 代码     │
│ • 博客论坛      │  │ • 文档         │  │ • 注释     │
└─────────────────┘  └─────────────────┘  └────────────┘

数据规模：万亿级别 Token
```

### 3.2 训练过程

```
自监督学习：下一个词预测
────────────────────────────────────────────────────────

训练样本：
输入: "The cat sat on the"
目标: "mat"

步骤：
1. 将输入转为 Token IDs
2. 输入模型，得到预测分布
3. 与真实目标比较，计算损失
4. 反向传播，更新参数
5. 重复数万亿词

损失函数：Cross-Entropy Loss
L = -log(P(正确词))
```

### 3.3 训练规模

```
模型规模演进
────────────────────────────────────────────────────────►

GPT-1 (2018)      GPT-2 (2019)      GPT-3 (2020)
1.17 亿参数       15 亿参数         1750 亿参数

训练数据量：
• GPT-2: ~40 GB 文本
• GPT-3: ~570 GB 文本
• GPT-4: 数 TB 级别

计算资源：
• 数千张 GPU
• 训练费用：数百万美元
```

## 4. 语言模型的能力

### 4.1 基础能力

| 能力 | 描述 | 例子 |
|------|------|------|
| **文本生成** | 生成连贯的文本 | 写文章、故事 |
| **文本理解** | 理解文本含义 | 阅读理解 |
| **翻译** | 语言间转换 | 中译英 |
| **摘要** | 提取要点 | 文章总结 |
| **问答** | 回答问题 | 知识问答 |

### 4.2 涌现能力（Emergent Abilities）

当模型规模超过一定阈值后，会出现**涌现能力**：

```
模型规模与能力涌现
────────────────────────────────────────────────────────

能力
  │
  │                          ┌─────────────────┐
  │                    ┌─────┤  逻辑推理       │
  │              ┌─────┤     └─────────────────┘
  │        ┌─────┤     │     ┌─────────────────┐
  │  ┌─────┤     │     └─────┤  代码生成       │
  │  │     │     └───────────┤ ───────────────  │
  │  │     └─────────────────┤  数学推理       │
  │  └───────────────────────┤ ───────────────  │
  └──┴──────────┴───────────┴─────────────────┴──► 规模
    1B        10B       100B      1T      参数

涌现能力包括：
• Few-shot Learning（少样本学习）
• Chain of Thought（思维链）
• Instruction Following（指令遵循）
```

## 5. 大语言模型的局限性

### 5.1 幻觉问题（Hallucination）

```
幻觉：模型生成看似合理但实际错误的内容
────────────────────────────────────────────────────────

用户：请介绍一下《三体》的作者刘慈欣获得的诺贝尔奖

模型：刘慈欣在 2015 年获得了诺贝尔文学奖...
      ↑
      错误！刘慈欣获得的是雨果奖，不是诺贝尔奖
```

### 5.2 知识截止

```
模型知识有时间限制
────────────────────────────────────────────────────────

训练数据截止日期：2023年1月

用户：2023年世界杯谁赢了？

模型：抱歉，我的知识截止于 2023 年 1 月，
      无法回答这个问题。
```

### 5.3 上下文长度限制

```
上下文窗口（Context Window）限制
────────────────────────────────────────────────────────

模型类型          上下文长度
─────────────────────────────
GPT-3            4K tokens
GPT-4            8K-128K tokens
Claude 3         200K tokens

超出限制的处理：
• 截断早期内容
• 分段处理
• 使用 RAG 等技术
```

### 5.4 计算成本

```
推理成本估算
────────────────────────────────────────────────────────

模型         输入价格          输出价格
──────────────────────────────────────────
GPT-4        $0.03/1K tokens   $0.06/1K tokens
Claude 3     $0.015/1K tokens  $0.075/1K tokens

示例成本：
处理 100 万字中文 ≈ 500K tokens ≈ $15-30
```

## 7. 在 OpenClaw 中配置 LLM

### 7.1 配置方式

```bash
# .env 文件配置

# 方式一：使用 Claude API
LLM_PROVIDER=anthropic
ANTHROPIC_API_KEY=your_key_here
ANTHROPIC_MODEL=claude-3-opus-20240229

# 方式二：使用 OpenAI API
LLM_PROVIDER=openai
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-4-turbo

# 方式三：使用本地 Ollama
LLM_PROVIDER=ollama
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3

# 方式四：使用 DeepSeek
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=your_key_here
```

### 7.2 模型选择建议

```
场景                    推荐模型
────────────────────────────────────────────────────────
通用对话                 Claude 3 / GPT-4
长文档处理               Claude 3（200K 上下文）
代码生成                 GPT-4 / Claude 3
成本敏感                 DeepSeek / 通义千问
隐私要求高               本地 Ollama + Llama 3
中文场景                 Qwen / 通义千问
```

## 关键要点总结

1. **语言模型本质**：预测下一个词的概率分布
2. **Tokenization**：文本 → Token → ID 的转换过程
3. **训练方式**：自监督学习，从海量文本中学习
4. **涌现能力**：模型规模足够大时出现的意外能力
5. **局限性**：幻觉、知识截止、上下文限制、成本
