# TypeScript 游戏引擎从零到一

## 项目概述

**目标**: 使用 TypeScript 从零构建一个 2D/3D 游戏引擎，深入理解游戏引擎架构

**引擎名称**: NovaEngine

**学习周期**: 16 周

**技术栈**:
- 语言: TypeScript
- 渲染: WebGL 2.0
- 构建工具: Vite + pnpm (Monorepo)
- 运行时: 浏览器

## 核心学习目标

1. **掌握现代游戏引擎架构** - ECS、场景图、渲染管线
2. **深入理解 WebGL2** - 底层渲染原理
3. **数据导向设计** - 性能优化思维
4. **软件工程实践** - 模块化、测试、文档

## 阶段划分

| 阶段 | 周次 | 主题 | 产出 |
|------|------|------|------|
| 一 | 1-3 | 基础设施 | 数学库、核心系统、渲染基础 |
| 二 | 4-6 | 2D 渲染引擎 | ECS、场景管理、Sprite 系统 |
| 三 | 7-9 | 2D 游戏完善 | 物理、输入、音频、动画 |
| 四 | 10-12 | 高级 2D + 3D 入门 | UI 系统、3D 渲染 |
| 五 | 13-16 | 完善与项目 | 编辑器、优化、最终项目 |
