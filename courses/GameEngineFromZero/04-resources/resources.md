## :star: 重点参考项目

### TypeScript 游戏引擎

| 项目 | GitHub | 特点 | 学习重点 |
|------|--------|------|----------|
| **bitECS** | [NateTheGreatt/bitECS](https://github.com/NateTheGreatt/bitECS) | ~5kb 极简 ECS，SoA/AoS 双模式 | ECS 架构设计、查询优化 |

## 学习路径建议

### 阶段一：基础 (1-3周)
1. 3Blue1Brown 线性代数本质
2. WebGL2 Fundamentals 基础章节
3. GAMES104 前 2 周内容

### 阶段二：2D 引擎 (4-6周)
1. Travis Vroman 教程 - TypeScript WebGL 引擎
2. bitECS 源码阅读
3. PixiJS Sprite Batching 实现

### 阶段三：游戏开发 (7-9周)
1. Excalibur.js 示例代码
2. Phaser 3 物理系统
3. 碰撞检测算法 (Real-Time Collision Detection 相关章节)

### 阶段四：高级特性 (10-12周)
1. LearnOpenGL 光照章节
2. PixiJS 后处理实现
3. Web Audio API 高级用法

### 阶段五：完善 (13-16周)
1. 《游戏引擎架构》工具链章节
2. 性能优化技术
3. 编辑器开发 (Dear ImGui 风格)
