## 按需复盘字段

这些字段供资料追踪和问题定位使用，不要求学习者填写；实验版本与运行证据由 Agent 维护。

| 项目 | 实际填写内容 |
| --- | --- |
| 学习问题与时间 | 日期、实际投入、要回答的问题 |
| 资料阅读 | 资料编号与 URL、版本、实际章节／页码、停止位置；个人用时和自测状态按需补充 |
| 实验与环境 | 实验编号、代码版本、浏览器、设备、分辨率与依赖版本 |
| 输入与预期 | 参数、初始状态、判定条件 |
| 过程与结果 | 中间数据、实际输出、失败与复现步骤 |
| 理解与迁移 | 自测答案、Cocos 对应机制、差异与适用边界 |
| 后续调整 | 待补知识、下一问题与预算调整 |
